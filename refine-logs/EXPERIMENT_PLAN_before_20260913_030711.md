# 机制到方法：逐项收敛实验计划

日期：2026-09-13。主线 graph，机制 reanchor。既有输出、分支、未跟踪文件均保留。

## 问题锚点

对冻结LLM，在不以幻觉标签训练的条件下，测量来源和历史的信息实际传递、聚合与输出采纳；区分疑似错误被继续沿用、被反对/纠正以及新陈述开始。事实区间和影响范围分别评价，熵只提供候选起点。

## 主张与证据门槛

| 主张 | 当前证据 | 尚需的决定性证据 |
|---|---|---|
| C1：适用约束与有符号输出采纳可以分开测量 | O4 两阶段世界 native 4/4、E/X 分离；O5 单点/联合路由作用；末层弱干预局部闭合 | 缺失约束、多词事实、独立来源读出；真实有限干预校验方向 |
| C2：该关系敏感表征支持无幻觉标签训练的风险及后续 span 定位 | 尚无新自然检测证据 | 来源独立、冻结方法、连续错误/纠正/换题评价，并超过同输入非图 |

两项作为完整方法主张仍未支持。反解释包括词形/数值身份、强度代替真值、强制前缀先承诺时长、事后选层、将同源构造条件当独立错误。
主文必须先有独立关系/缺失判别和来源隔离检测；单例层扫描只支持诊断。不为图结构先加 Adapter 或 GNN。

## 三个核心块

### B1：适用约束、缺失与采纳（MUST）

- 已完成：O1–O3 数值身份；O4 四世界/160 条件，native 4/4，N/A/G 3/4、2/4、2/4；O5 167 条件。
- 下一项 O6：先在尚未给定时长的前缀，比较双阶段有时长、仅另一阶段有时长、当前阶段有时长、全缺失；自然来源单独保留。
- 数据：source14375 仅作发现，不能冒充自然全量；迁移验证须选不共享来源的条件并冻结清单。当前官方 QA test 已查看，不作新的盲测。
- 系统/设置：冻结现有 Llama3.1，实际 Q/K/V/O、MLP、完整上下文；节点读出、连接读出、真实有限干预三类对照，不训练幻觉标签。
- 首要指标：当前动作的适用依据/缺失区分、无候选限制续写、真实干预的方向与局部近似误差。候选句打分辅助，不把单个 unknown token 当无依据事件。
- 门槛：冻结读出在独立来源/两个方向转移；依赖强度与支持/反对方向分开。仅识别有无数字或只在一个来源能拟合为失败。
- 当前实施状态：O6 DESIGN，未实现/执行；输入对齐、续写判据和预算 smoke 完成后另冻协议。细节 docs/MISSING_CONSTRAINT_PLAN_20260913.md。
- 预算：行为阶段最多 40 组合×64 新 token，初估 5–20 GPU 分钟，真实 smoke 后更新；机制干预另预算。
- 目标图表：适用/其它阶段/缺失 × 承诺前/后决策矩阵，含失败例和完整输出。

### B2：单点/联合回看与完整图分组（MUST，B1 后）

- O5 已知窗口中只有 t131 单 query E 充分；t0…130 联合 E 同样充分。不能把充分点当唯一最早/必需点。
- 固定来源总量正增量 top8 对单 query E 充分集合召回 0/1；这是该供体/干预的覆盖，不是通用回看真值。
- 下一版候选依赖来源内部连接对应/消息组成的变化，保留候选位置组；固定 8/16/32、因果标点分组作为对照，均保留全部可见上下文和跨 span 边。
- 数据/评价：多个独立来源上的正常动作切换、同句约束切换与错误窗口；因果扫描的单点充分、联合充分、去组检验分别报告。已查看单例不用于选阈值后自证。
- 指标：固定查询预算下覆盖、候选数、漏检、单点与联合干预效应。语义边界与干预影响端点独立评估。
- 失败解释：候选只落标点、名词碎片或数值端点；去最终点后仍翻转则保留分布式解释，不硬找唯一节点。
- 状态：自动候选新版/图分段模块未实现，预算待来源清单和组检验数冻结；不是正在跑的作业。

### B3：连续错误、纠正及图必要性（MUST，B1/B2 后）

- 目标：区分错误延续、同话题纠正、正常换题、换题后新错误。强历史依赖可能用于纠正，不能把依赖后代全部标错。
- 首先测真实有符号有限干预，再评估多层/多词近似；保留正证据量、负证据量和总质量，竞争比例不替代绝对量。
- 最简比较：同属性输入的线性/MLP 或 DeepSets，与关系消息读出。只有需要时才用自监督图模型预测真实干预结果，标明监督来自构造干预而非自然幻觉标签。
- 图增益门槛：相同输入/规模/训练预算，保留节点而改端点对应后增益消失，并在新来源有稳定改进；重构好不代表真实。
- 自然指标：固定误报预算的首错/连续错误覆盖、纠正误报、恢复延迟，按 source 聚合不确定性；RAGTruth 标注边界不是因果影响真值。
- 状态：完整检测器、影响终点真值和图增益均未实现/验证；不扩训复杂模型。预计预算在 B1/B2 通过后制定，不先申请长时 GPU。
