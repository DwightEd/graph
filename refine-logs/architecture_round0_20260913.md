# 方法初稿：约束对齐与干预蒸馏的双视图图检测器

2026-09-13。方法初稿，待审查；不是已验证方法。停止旧 O6 单例行为实验路线，转为完整主线模型设计。

## 问题锚点

对冻结LLM，在不以幻觉标签训练的条件下，测量来源和历史的信息实际传递、聚合与输出采纳；区分疑似错误被继续沿用、被反对/纠正以及新陈述开始。事实区间和影响范围分别评价，熵只提供候选起点。

用户新增的收敛要求：不要再证明关系会影响输出。必须具体解决适用证据、自动回看、错误路由及其衍生 span；先设计完整模型，验证只能面向模型的这些能力。
训练监督边界需要清楚：不使用 RAGTruth 自然幻觉标注训练、选层、定阈值或早停；允许来源恢复/删除的自监督和模型生成的来源归属弱监督，但须单独标明弱监督，不能宣传成没有任何语义监督。若要求严格不使用任何语义弱监督，归属头退化版是另一对照，不能保证同等能力。

## 一句话主线

学习“当前陈述在来源中需要且获得的证据”与“生成计算实际采用的消息”两种对应关系；只有前者判定不支持、后者又显示错误证据的正向采纳，才称为路由衍生幻觉。对齐头给事实区间，干预蒸馏头自动搜索有实测支持的回看位置组；定位不确定不阻断检测。

主贡献是一种有明确训练目标的双视图对齐，而不是新的通用 GNN、知识图谱提取器或解码修复框架。最多两个训练模块：语义对齐图头与干预效应图头，LLM 冻结。默认采用 learned graph，删边同输入 MLP 是必要比较。

## 为什么不照搬现有结构

MiniCheck 的可复用部分是多事实支持/必要证据删除的训练构造，不是让 attention 充当真值。GraphCheck 的两个全图 soft token 不输出需要的局部对应。ALTI 非负归一化丢失支持/反对方向。IRIS/RAUQ 的不确定性不能监督正确归属。

## 数据与两个视图

输入仅为 task、全部 source 文本及完整 response。token/字符对齐贯穿流程，不给自然真值、人工数值候选或错误位置。

语义视图：来源 token 的冻结表示只读取来源和任务，不读取 response；另对 response 文本做一次冻结的“阅读”前向，得到文本表示。它不接收原生成 logits、熵、实际 source attention 或干预结果。防止把实际选择训练成正确归属。
计算视图：本地 Llama3.1 在原 prompt/response 上 replay，保存逐层实际 residual、post-attention、MLP、Q/K/V 和 source/history 连接因子。RAGTruth 原生成器不等于 replay 模型，因果描述只归于 observer；需要原生内部机制结论时使用自己的 Llama 生成回答。

图的底层节点是完整 token，保留来源内、回答历史、来源到回答、残差和层更新；高维状态共同投影到 d=256。投影按层共享，32个层编号保留，不在读出前对层/头求一个平均值。
来源句/分句仅作为可重叠的计算块：保留原 token 索引、父句及邻近指代上下文。不存在通过窗口裁剪来源或回答历史。长图按 query block 流式计算，未命中的边不等于不存在。

## 模块一：语义对齐图头

一个两层、4-head、d=256 的 cross-graph transformer。两个方向共享 token 投影，但来源更新不看 response；回答 token 可读取全部来源 token 和已出现回答 token。来源内部边显式加到注意力 bias，回答/来源交叉边由 trainable pair scorer 计算，**不使用实际生成的 attention 作为归属标签**。

对每个候选回答 span c=[a,b]，由端点与 attention pooling 得到表示。跨来源的多头读出保留四个 d=64 的证据通道，不立即全图池化。pair MLP 输入 [c,e,c⊙e,c−e,层/位置编码]，输出：

- applicability(c,e)：证据与该陈述涉及的对象/动作/阶段/地点相关的概率；
- support/contradict/insufficient(c,Source)：针对整条陈述、全部来源的三类 logits；
- membership(c,e)：非互斥的证据成员分数，允许需要多条事实，另有 NULL。

NULL 表示没有完整支持集；contradict 表示存在相关的反驳证据；抽取/结构不可靠记 abstain，而不是当真值缺失。
不能用 max_e entailment 代替多事实合取；整 span 分类头读取多通道证据并用“删除一个必要事实即不充分”的训练对约束。阶段/否定等不单独靠手写词表，保存在句级上下文与同来源困难负例中。

自适应 span 与对齐同时估计：候选所有词边界、最长64词，结构化半马尔可夫层对分段及 support/contradict/insufficient 状态联合打分。长于64词可继续同状态相邻块，输出合并时保留原边；64是动态规划计算块，不是上下文截断。
跨度得分为整体三类 logit、证据集一致性与长度偏置；邻接跨度共享同证据时偏好继续，对应改变时允许新段。边界不依赖熵阈值或标点硬切。训练由来源派生陈述的已知字符映射与可用的弱边界监督；未知边界求和边缘化，使用 log-sum-exp DP。
输出每 token 的不支持后验、span边界后验及每 span 的证据集合，不只是一个回答分数。

## 模块二：干预效应图头

另一个两层 d=256 图头，输入原生计算视图及模块一选出的待解释 span；语义对齐头停止梯度，且不反向吸收 native confidence。
对当前 span 的目标取 F_c=|c|^−1 Σ_{t∈c} log p(y_t|prompt,y_<t)。同一完整词表、同一实际token序列；所有干预比较同一个 F_c，所以没有不同长度候选句的似然偏差。F_c是生成支持度，不是事实正确性。

训练时在来源句组、历史span组与query组上做真实有限消息 gate，保存 ΔF_c=F_c(base)−F_c(attenuated)。正号说明该消息支持当前文本的生成，负号说明它抑制当前文本；保留负值、不做abs归一化、不把竞争比例当正确性。
训练目标预测 **任意输入mask下的联合 ΔF**，而不是把每条边的梯度机械相加。输入mask的节点/边在图头中显式可见，含全层消息削弱与跨组组合；sham为0锚点。用 Huber(预测ΔF,实测ΔF)，同时预测零效应/误差尺度供弃权。
末层局部梯度只作初始化或 cheap feature；精确符号以完整剩余网络的有限前向为准。QK路由与V消息分开记录。若用全链导数，必须保留 downstream RMSNorm/MLP/QK；路由方向包含 softmax 竞争项 A_ij gᵀW_O(v_j−Σ_k A_ikv_k)，不是 A_ij gᵀW_O v_j。

### 自动回看位置组

不先用 entropy/top8硬筛。对所有可见query形成多尺度嵌套组，并允许两个非相邻组的组合；这只改变干预mask，完整前向上下文保持。
学生头预测按组保留/削弱的联合效应，beam search在固定预算中搜索最小组G，使来源错误归属通路的 ΔF 超过预注册效应门槛。每个最终返回组都通过一次真实干预验证，去组后复测；失败返回 unresolved。
返回的是与给定span及给定干预对应的充分位置组和未排除位置，不是假设唯一事件，更不把单点充分当必要。主指标固定调用预算下实测目标达成率、组大小和未覆盖率，不是与attention峰位置的一致性。

### 错误衍生与纠正

每个回答span独立有来源支持判断。对历史span h→当前span c 的正/负 ΔF形成有符号依赖边。只有 h/c 均不支持且相关证据归属持续一致、边对当前错误表达为正，才标候选错误延续。
当前 c 已被来源支持，即使强依赖此前错误，也不继承错误标签；对错误命题的否定/纠正由语义对齐分类和文本关系共同识别。换话题允许图边仍存在，但不同陈述的事实区间独立，不能因依赖存在延长幻觉标注。
影响结束与错误结束分别输出。前者是相应有限干预效应衰减区间，后者由不支持后验决定；无法证明无影响时记未确定。

## 训练协议

仅从官方train来源准备数据，按source ID先拆分80/10/10；已看过的QA test只作探索性最终诊断，不能用于选模型。
T0：源句/多句组合→忠实改写及可定位的来源provenance。冻结Qwen3-8B仅作离线数据构造与限定条件核对；Llama验证器独立复核。保存两个判断、引用原文及弃权。模型一致不等于真值，抽检错误率单列。
T1：必要证据移除、同来源另一动作/阶段/角色关系替换、其它来源无关负例。每个变换重新核对支持关系；删除/置换本身不能直接生成“幻觉”标签。将constructive availability监督与模型语义弱监督分开存储，可分别消融。
T2：同一来源生成包含正确改写、错误绑定、纠正、正常换题的文本，以已知编辑映射监督弱边界；不把所有扰动后的续写自动标错。沿用训练来源，不混test。
T3：每条训练轨迹抽样4个真实组gate（含组合）+sham，得到无需人类幻觉标签的 ΔF监督。各原子和联合条件均见过；小组shuffle作为分布外测试。
总损失 L=L_semantic + L_provenance + L_segment + λ L_intervention。对齐/干预两头分别优化，native分支梯度不进入语义头。损失权重由各任务初始梯度规模固定；早停只用来源派生dev与干预预测误差，不读自然幻觉标签。

第一版预算：256个train来源，每源最多8条派生陈述/短回答，共≤2048条；先冻结清单。teacher与observer在一张4090上顺序加载，不同时驻留。语义与native特征按batch流式计算；必要缓存仅投影特征/边因子并记录投影版本，不能假称保存了完整高维图。第一版估计6–16 GPU小时，需按真实batch计时后修正，不先扩17790条训练。

## 推理与输出契约

1. 自动token/字符映射，生成两视图。
2. 结构化对齐头解码完整回答，输出所有token不支持后验和span/证据集合，包括NULL/abstain。
3. 干预头预测每个风险span的来源及历史正负贡献；需要宣称路由原因时做固定预算的真实联合mask核验。
4. 输出 {char_start,char_end,unsupported_score,evidence_ids,null_score,positive/negative_adoption,lookback_groups,causal_verified,history_links,abstain_reason}。

默认完整回答后的审计，定位到先前query。在线模式只能使用当前前缀，span结束前概率可修订，不能把完整回答推断冒称提前检测。先交付离线完整方法；在线是同结构的因果运行方式，不宣称已经实现或同等性能。

## 仅三个决定性验证块

1. 主线自然检测：冻结结构/训练/阈值后，在未用于设计的来源/任务上评价token/span AUPRC、固定误报预算召回、边界和恢复延迟；比较同监督语义非图模型、固定entropy/RAUQ。不能只比较弱旧residual。
2. 归属与因果覆盖：自动证据集对照人工核对但不参与训练的最小证据集合；联合回看返回组必须实测，报告预算/弃权/召回。若语义归属失败，不能以效应头成功掩盖。
3. 结构必要性：同节点/相同监督的非图、去native头、破坏对应但保留节点的图；同时看纠正误报。图无增益则删图，不扩Adapter。

## 当前主要风险

语义弱监督的可靠性和分段迁移是最危险部分；2048条是否足够未知。NULL不能靠人为absence模板轻易学会。两头因果含义不同不可合并成真假概率。单GPU exact因果验证吞吐较低，学生预测未经复测只能叫估计。当前结构和所有训练数字是计划，不是结果。
