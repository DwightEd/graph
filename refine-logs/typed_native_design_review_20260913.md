# Typed native design review — 2026-09-13

## Verdict

The typed-hours provider supplies the missing prerequisite that surface v1 lacked: an exact original-token B/A event, an explicit all-seven-days source proof for the edited opening or closing endpoint A, preserved WiFi conjunct, and no reader/label dependency. This is sufficient to measure a **conditional correct-source A position/origin path** even when no source occurrence contains the original wrong B value.

It is not sufficient to claim wrong-owner routing: that claim still needs a separately frozen inapplicable B occurrence and its one-way B→A/U destination contrast. Do not invent B from an end-time, history, or a same-type source string.

The minimal next runner should always preserve useful raw native measurements, but issue a stronger certificate only when its pre-frozen schema controls and exact checks are available. This avoids the previous native=0 failure without silently turning an uncontrolled effect into adoption, routing, or error detection.

## Fixed estimand and baseline-independent direction

For the existing complete events, retain:

    F = logP(B complete continuation) - logP(A complete continuation)
    delta(G) = F_base - F_G

A correct-A content/V path that favors the typed supported A has the preregistered direction delta <= -0.5: removing/attenuating it raises F toward B. This direction remains meaningful in all three baseline buckets:

- F_base >= +0.5: observer prefers B; a certified A path is a conditional source counter-path to B preference.
- F_base <= -0.5: observer already prefers A; the same effect is a correct-source contribution aligned with its A preference, **not** an error repair.
- otherwise: near-tied event preference; record the path effect but do not call either branch adopted.

No sample is discarded or re-searched because its baseline favors A. Save F, per-event token log probabilities, target-slot/context partition, and the baseline bucket before any intervention.

## Primary source object and no semantic B substitution

The primary A is the immutable union of all seven typed source spans for the edited endpoint (opening or closing), with its seven occurrence IDs, field paths, source SHA, token mappings and quantified-day proof. The all-day union is the semantic source object. A search child that contains a day subset may be reported as a localization measurement, but cannot replace A as the all-seven-days source proof or create a new semantic contrast.

No exact B occurrence is expected in this schema. The opposite endpoint, day names, business identity, WiFi, history, or a model-generated alternative are not B. They may serve only as explicitly named schema-excluded structural controls, never as a wrong owner or an error source.

## Automatic full-prefix query × layer localization

Current propose_native_groups preserves the valuable all-query/all-layer root and bisects keys/queries, but leaves layers fixed. Extend its **search record**, not its conclusion, with a deterministic three-stage tree for the fixed full A key set.

1. Measure and retain the root G0=(A keys, all shared-prefix queries, all model layers), first for content attenuation. This is the all-layer joint result.
2. From every retained parent, bisect its contiguous layer set into left/right child layer bands while holding its key and query sets fixed. Measure both under the fixed priority/budget rule. Retain parents even when both children are weak: a joint parent can reflect cross-layer dependence.
3. For each predeclared number of highest-priority measured layer groups, bisect the full shared query set. Permit the existing deterministic non-adjacent query unions only among same-key, same-layer measurements. Do not restrict the root to punctuation, entropy peaks, answer tokens, or a local response window.

All nodes record keys, query set, layers, parent IDs, axis, rank priority, exact measurement key, call/token cost, invalid status and pending/unsearched descendants. Priority may use a parent's absolute effect to spend a fixed search budget, but it is an adaptive bounded search, not a unique-node estimator. The output must say:

    searched_joint_groups
    searched_single_layer_groups
    unsearched_layer_children
    unsearched_query_children
    nonadjacent_query_unions
    localization_scope = bounded effect ranking; no unique lookback claim

A compact 64-forward search allocation is practical: two baseline forwards and at most 31 cached-or-new two-branch group measurements, with the root always first. Query refinement must reserve its own fixed slice before layer effects are known; otherwise interesting layer groups consume all query coverage. Save the complete tree when a budget/invalidity ends the search.

The existing key bisection remains optional descriptive heterogeneity for A's seven occurrences. It must not be used to choose a more favorable day after effects, nor to redefine the quantified all-days fact.

## Conditional A-source V adoption measurement

For every final localization candidate L×Q, define the same group for both position and origin:

    selected V receiver keys = A keys
    input origin = A keys
    query/layer = the frozen L×Q candidate

Position content attenuation tests whether current A messages affect F. Origin tests use raw input scaling of A and branch-matched captured V at that same A receiver address; recipient donor replacement uses the existing provenance, GQA, dynamic-current-values, future-mask, full-shape sham and hook-cleanup contracts.

Use these fixed checks:

| Measurement | Required result for a strict A-path certificate |
| --- | --- |
| content sham (strength=1) | exact branch replay |
| content full, half, repeat | delta<=-.5; half same direction and bounded; repeat exact |
| A-origin donor sham (input scale=1) | exact donor/baseline replay |
| A-origin full, half, repeat | delta<=-.5; half/repeat rules as above |
| source controls | two pre-frozen schema controls for both position and raw-origin comparisons, with selectivity margin |
| all branches | finite tensors, source/token/typed-proof/model identity and hashes unchanged |

If content and origin pass in the same L×Q scope, call the result:

    conditional_typed_correct_source_V_contribution

It means: under the typed all-days assumption, A's raw source input contributes through the fixed selected V messages to the observer's B-vs-A event preference. With B-preferred baseline it may additionally be described as a counter-path. It does not prove abstract ownership, source retrieval in the original generator, an error decision, or MLP aggregation.

If only origin passes, report raw_origin_mediated_A_effect. If only content passes, report A_position_effect. If checks or controls are unavailable, preserve numerical deltas, shams and failure status as raw_native_measurements_uncontrolled; do not erase them and do not upgrade them.

A multi-layer G may also receive the same raw-origin procedure and be reported as joint_multilayer_A_V_effect. It is not an individual layer localization. A single-layer L is required only for a layer-specific claim or any future route destination test.

## Schema-backed control census

Controls must be chosen before any source-A effect or localization measurement. The typed provider, not a reader, should enumerate every source span with a declared role:

    target_start_endpoint
    closing_endpoint
    day_key
    business_identity
    wifi_attribute
    unsupported_or_unknown

For an A-origin/control trial, freeze candidate control groups and their exact field paths, occurrence IDs, token keys, target exclusion rationale, counts, embedding norms, causal visibility and baseline receiving-mass profile. Select a deterministic maximum of two controls only after fixed structural matching, and save all rejected/unused candidates.

There are two legitimate control grades:

1. **Schema-unrelated controls**: the provider explicitly establishes that the field cannot determine the edited endpoint under its stated algebra. These can enter the strict two-control selectivity check if they also meet the structural match.
2. **Schema-excluded-but-related controls**, such as the opposite endpoint: these are excluded from the edited slot but remain part of business-hours facts. They can bound a generic source/typed-field effect, but cannot by themselves justify the word “unrelated” or a strict source-adoption certificate.

If fewer than two grade-1 matched controls exist, return schema_controls_unresolved. Still run the raw A position/origin trials within the preallocated raw budget. Do not backfill with reader guesses, history text, same-type values, or post-effect choices.

This explicitly permits the expected sparse-control outcome instead of making it native=0, while preserving the difference between a limited mechanism measurement and a controlled certificate.

## Budget and sequence

Use a fixed per-contrast native budget of 128 actual forwards, not a data-dependent extension:

| Block | Cap |
| --- | ---: |
| B/A baseline | 2 |
| root + layer/query/unions search | 64 |
| final single/joint A position: sham/full/half/2 controls/repeat | 12 |
| A raw-origin: sham/full/half/2 controls/repeat | 24 |
| accounting, invalid attempts and reserve | 26 |
| Total | 128 |

Each CausalOracle group call costs two branch forwards; each mediated origin trial costs two donor plus two recipient forwards. If a block cannot fit, mark it budget_unresolved and retain the preallocated later blocks only if their reservation was made before search. Cache reuse is reported, never treated as zero experimental work.

No source-B route certificate is budget-reserved when the frozen typed roster has no B. No MLP interaction is budget-reserved for this first typed runner: an MLP four-state effect without an independently controlled arriving A message cannot answer the unmet aggregation question.

## Required implementation boundaries

1. Freeze the typed contrast, all-seven-day A roster, control census, search allocation and baseline bucket before native effects. Verify the typed proof, original observer IDs, alignment, model/code identity and all artifact hashes on resume.
2. Extend the search output with layer-tree and query-tree provenance, all parent/child measurements and unsearched groups. Do not report a highest-effect leaf as unique or exhaustive.
3. Keep all-layer joint effects separate from single-layer results. Only the latter may use same-input B→destination language in a future source-competitor run.
4. Enforce the two control grades and explicit statuses above. A raw measurement may be published in the run artifact without grade-1 controls, but no selective/adoption certificate may be emitted.
5. Keep MLP fields absent or aggregation_unresolved. No raw A effect, attention mass, or broad MLP interaction can fill that conclusion.

This is a direct natural typed-hours mechanism measurement on frozen observer B/A decisions. It is neither a toy relation example nor evidence that the general semantic graph now works.
