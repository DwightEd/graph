# 从适用约束到输出采纳：当前研究方案

2026-09-13。状态：机制仪器和整样本属性图已实现，新图→自动风险主线尚未收敛。
本轮 O4/O5 已执行；原默认路径 residual 不变，失败的新读出不接入默认算法。

## 问题锚点

对冻结LLM，在不以幻觉标签训练的条件下，测量来源和历史的信息实际传递、聚合与输出采纳；区分疑似错误被继续沿用、被反对/纠正以及新陈述开始。事实区间和影响范围分别评价，熵只提供候选起点。

## 当前证据改变了哪些设计

O1–O3 数值身份实验中 X 内容替换可改变选择；O4 数值/位置固定、只换 Before/After 后，最终 query E 连接替换4/4翻转，X0/4。模型在这四个构造世界使用了关系，但 N/A/G 仅3/4、2/4、2/4，自动归属未读出。
O5 只有 t131 单点 E 充分，而此前所有 query 联合 E 也充分；32个单层均不充分。当前没有唯一必需的回看节点证据，source-rise top8覆盖失败（0/1，干预定义集合）。
因此不再把注意力总质量或 query 余弦当作采纳，不假定每个错误必有一个单独可翻转的前置节点。
原洋葱动作没有唯一来源时长；12改14不是自然修复。下一项先查缺失适用约束和开始说时长之前的决定。

## 表征：已实现的部分

每个 prompt–response 是完整属性图。token节点保留逐层4096维残差、Q/K/V及MLP状态；边保存层、头、端点、attention及真实 V/O 消息，区分来源、历史、残差和分支更新。
整样本图捕获已保留 prompt 内部边；00012/00013原始图有730/681位置、32层/32头。O4另捕获关系世界的真实 Q/K（RoPE前）和消息因子。
窗口只用于分组，全部可见上下文及跨组边保留。当前没有自动语义分组算法，不以缓存成功当成方法有效。
全量通用扫描为节约存储只保存紧凑统计/效应，不能宣称已缓存17790条完整高维图。

## 待读出：适用性、采纳方向和后续作用

第一步判断当前对象、动作、位置和阶段是否有适用依据，区分支持、反对与缺失；不能限定为两个已有数字二选一。
第二步测量消息对当前输出候选的有符号作用。JS给依赖强度，有限消息干预下候选差给相对支持方向，两者都不直接给事实正误。
第三步根据后续陈述对这些消息的支持/反对/无关作用分组，区分沿用错误和引用错误以纠正。换句边界与影响结束分别评价。
这些是当前待验证设计，尚非已完成三阶段检测器。

局部末层1%干预已有0.8%–3.4%近似误差证据；多层、多词竞争及全量删除的方向不能沿用线性结论。
E干预涉及已生成的attention，不能由此指认Q或K单侧因果；下一轮Q/K分开实验须处理RoPE和精确位置对应。

## 回看候选与图的必要性

改为检查来源内部对应/消息组成变化并保留位置组，分别检验单点充分、联合充分和去组效应；不从一个同源案例学习“选t131”。
候选覆盖需在独立来源、固定查询预算下评价，包含正常动作切换；没有100%识别保证。
先比较同输入的线性/MLP或DeepSets与消息关系读出；若简单读出够用，不增加GNN。
如果需要学习，优先自监督预测真实干预的方向和跨世界关系变化。它有构造干预监督，不能宣传为完全没有监督信号；不使用自然幻觉标签训练。
图模型只有超过同输入/同规模非图，并通过固定节点、改变端点对应的独立对照后，才构成图必要性证据。
