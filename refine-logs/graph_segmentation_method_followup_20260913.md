# 图分段方法精读：可借鉴的结构与不能混用的目标

2026-09-13。针对已观察到的地址单元切句、不完整角色anchor和整句风险涂到所有词的问题补读。没有新增玩具GPU实验；本次设计不改变冻结soft_graph_v1。

**GraphSeg（2016），§3。** 先以内容词向量余弦建立句间词对齐，用Hungarian匹配和信息量权重计算句间相关度；阈值成图后求极大团，合并相邻句与过小段。可以借鉴“先有完整句节点，再按关系图分组”；其主题相关边与最小段长合并规则不保证事实复用，更不定位幻觉。[论文](https://aclanthology.org/S16-2016.pdf)

**Meta-Chunking v3，§3.1。** PPL方案从完整句出发，用前文条件下的句级不确定性局部极小值提出边界；MSP直接比较merge/split两个选项的概率差，以历史margin均值更新阈值。后续还训练改写和摘要补全。我们的借鉴限于完整句基础与有限选项接口：原始回答不可被改写为检测输入，低PPL的错误续写也不能由此判定为正确或同一事实。[论文](https://arxiv.org/html/2410.12788v3#S3.SS1)

**Ltri-LLM，§3.2–3.3。** 对attention中三角区间做减阈值后的累积打分，再以NMS去掉重叠跨度；key索引数依span与邻域attention比值动态分配。这为利用真实计算关系提出跨度提供可实现参考，但其目标是KV检索保真，attention密集区域不是已验证的事实单位或错误传播区间。[论文](https://arxiv.org/html/2412.04757v1#S3.SS2)

**UPS（NAACL 2025），§3.3–3.4。** 无监督分支只用同对话和下一话语两类自监督关系任务，训练domain adapter与prompt，使用二元交叉熵；不使用分段标注微调。它说明关系读出可以从原始次序/来源自监督学习，但“相邻/同对话”没有教会模型区分事实沿用、否定、纠正与换owner，不能直接作为本项目的传错标签。[论文](https://aclanthology.org/2025.naacl-long.252.pdf)

## 本项目据此作出的实现决定

`next_iteration/graph_boundaries.py` 先构造原文完整句envelope；128-token地址边界和Qwen event endpoints均不能切开它。角色/事件指针作为嵌套候选保留。句内安全clause尚未自动识别时保持整句，报告未拆分，不声称已恢复精确事实边界。

图分组只使用明确的前向事实复用/同事实关系；纠正、引用、换题形成阻断。非相邻连接保存原始节点span列表，不用首尾包围区间覆盖中间无关文本。这是条件关系图分组，不自动分配词级错误风险。

同一base上的全来源C/N仅表示至少一个断言未获支持。它作为 `base_bag_risk` 单列；`localized_risk` 只来自已绑定具体slot且完成局部scope验证的判断或单槽位bridge，其他词为 `unknown_within_base`、数值0.5，继续留在评价分母。相互冲突的局部判断也回到未知，不通过max聚合消除异议。

这是最小结构修订，不引入新的边界网络。自然数据的分段/slot覆盖和检测效益仍须在完整下一版检验；上述论文的主题或检索结果不能代替本项目的机制证据。
