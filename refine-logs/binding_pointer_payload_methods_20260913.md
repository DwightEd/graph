# 绑定机制方法精读与当前实现的差距（2026-09-13）

研究锚点仍是自然 RAGTruth 回答中的约束归属、决策窗口、路由与采纳，以及错误延续范围。下面只提取能改变模型设计的细节，不新增实体列表或关系翻转演示。当前 soft_graph_v1 正在执行，本文不改其冻结代码或阈值。

## 原论文实际做了什么

**Mixing Mechanisms, §§3–4、附录 D.2。** 论文将位置、词汇和直接指针机制放进同一个可学习混合模型，用干预后的输出分布拟合混合权重。§3.4 让反事实答案在原输入中不存在：中间层的指针无法解引用该答案，后一层的答案内容却能被复制。D.2 据此选择模型各自的检索前层。文中的约 95% 是分布一致性，不是自然文本回看定位准确率。[原文](https://arxiv.org/html/2510.06182v2#S3.SS4)

**Language Models Use Lookbacks to Track Beliefs, §§3–5、附录 F。** 绑定回看先由角色/对象地址得到状态地址，答案回看再由状态地址取得值。实现用残差交换及 SVD 基底上的稀疏掩码；掩码训练目标来自指定高层因果模型的反事实输出。它依赖受控任务与正确回答子集，既不是无标签自然归属读出，也不能直接迁移论文层号。[原文](https://arxiv.org/html/2505.14685v2#S4)

**Do Language Models Track Entities Across State Changes?, §§3–4、附录 H.6。** 方法区分面向当前查询的局部对象状态和全局世界状态；REMOVE 另训练不存在/存在/已移除三类探针，并用探针零空间投影检查行为影响。对象 token 尚未看到操作目标时，状态本来就不可判定。探针使用构造任务标签，不能称为我们的无监督模型。[原文](https://arxiv.org/html/2605.30233v1#S4.SS2)

## 对本项目的设计推论（不是论文已经替我们验证的结论）

1. **依赖、归属、指针是三件不同的事。** `log P(原回答)` 的变化只支持依赖判断。输入原始位置扰动后，仅将指定 V 消息传入接收计算，能定位一条输入来源路径；这条路径仍可能携带答案内容，不能仅凭该测试宣称读出了 binding pointer。
2. **正误比较先要有可审查的两个完整事件。** 用冻结来源节点的原文片段或可安全解码的标量，确定性替换回答的一个角色。有限 reader 只判断原事件是否缺乏支持、改后事件是否支持、选定来源记录是否适用，以及非目标条件是否保留。不要再让 reader 自由生成“正确答案”。
3. **回看定位以查询位置集合为输出。** 联合组足够、任一单点不够时，报告联合组和未搜索范围；不能把最大效应点包装成唯一必需节点。当前 v1 只搜三个层位，不能报告全层准确率。
4. **同一个正误事件差上区分路径。** 采用 `F=log P(原事件)-log P(来源支持的替代事件)`，记录来源与历史消息分别推动哪一分支。保持质量的历史→来源路由转移与证据×MLP 的四状态交互才有共同解释目标；若只有原事件依赖，二者不产生错误机制证书。
5. **延续边需要事实角色和时间方向。** 同主题相似不能当作前错传递。当前 span 必须复用先前具体事实，并保留角色/事件作用域；修正、引用和换题阻断风险传递。信息尚未出现在自回归前缀时，应标为不可判定，而不是模型漏用证据。

## 实现顺序与边界

soft_graph_v1 的全词四版本比较先完成，用同一 reader 检查图及内部信号是否带来增益。单槽位来源对照器暂放 `next_iteration/`，避免改变该批的 47 份执行快照。它复用现有 `ContinuationContrast`、`CausalOracle` 和 slot/context 分解，不训练额外网络。

第一版只开放 object/quantity/time/location/duration/attribute/origin/destination；subject、谓词、条件、否定、bool、None 和需要自由改写的情况显式拒绝。多角色错误、全事件虚构、纯来源缺失仍由软检测器预测，不能伪造可干预的“正确分支”。有限 reader 结果是条件判断，独立标注仅在预测冻结后用于评价。

若来源对照器在自然样本仍无覆盖，下一步应依据保留的失败类别修候选/表征；不以降低语义门槛或删除弃权样本获得机制成功率。高维特征与关系图本身可运行，不等于约束归属已经被内部状态自动识别。
