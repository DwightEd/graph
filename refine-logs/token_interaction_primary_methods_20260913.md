# Token interaction methods: targeted reading after SourceRel failure

[ColBERT, SIGIR 2020](https://arxiv.org/html/2004.12832), §§3.2–3.3: query/document keep token vectors, linearly project and L2-normalize them; each query vector takes its maximum dot product against document vectors, then these maxima sum. Query and document encoding are separate; BERT and projection are trained with positive/negative ranking triples. This is not an untrained causal last-token recipe. Applicability: preserve fine-grained contextual matches within a single owner candidate. Limitation: independent MaxSim terms do not themselves certify role binding, entailment or quantifier completeness; allowing a document to mix unrelated source records can create spurious joint matches. Do not copy truncation/query augmentation into a native trace claim.

[Duet, WWW 2017](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/10/Duet.pdf), §3 (primary method excerpt read): a local exact-match interaction matrix and a learned distributed matching network contribute separate scores, trained jointly. Applicability: lexical record identifiers and semantic relation matching may need distinct channels; our source validation already shows their complementarity. This motivates a design comparison, not proof that a Duet head solves natural constraint ownership. Its fixed query/document truncation is not adopted.

[ColBERTv2, NAACL 2022](https://aclanthology.org/2022.naacl-main.272.pdf): primary PDF retrieved; detailed supervision/compression sections still pending. No claims based on unread sections.

Current inference, not a paper result: repairing the candidate graph is necessary before another interaction model can help. Missing address components, long review evidence, unknown-valued owner fields and all-week bundles cannot be recovered by re-ranking an incomplete pool. Mask-centered role context and separately retained record identity need natural-input-matched validation before more GPU training.
