# 标注起点与连续性：本轮实际审计结果

2026-09-20。输入是既有 CHARM/LDA 冻结逐 token 分数、原校准阈值、官方字符标注和已固定的正常对照。
本轮实际重算了全部可用 QA 回答的起点统计。没有重新训练模型，没有全量自然 attention 缓存，
所以本报告**不能回答“幻觉前是否都有明显 attention 重锚”**。此前两个案例的路径干预也不能回答。

## 1. 总体成绩确实高度受持续部分影响

这批数据有 149 个回答、149 个 source、30,619 个 token、2,307 个幻觉 token。
85 个原字符标注映射并合并 token 重叠后有 84 个标注片段；相邻片段保留，连续正标签游程是 79 个。
52 个回答含幻觉。**2,223/2,307 = 96.36% 的幻觉 token 是标注片段的后续 token。**
这不是“所有幻觉按整句标注”的证据，也不是“97% 都在第二个 span”：第二及后续标注片段仅占 32.47%。

以下为现存 `../continuity_units_20260920/{charm,lda}/token_rankings.csv` 的相同有限行口径。
历史比较去掉每答第一个无历史 token，因此为 30,470 行、2,306 个阳性。

| AUROC | CHARM | LDA |
|---|---:|---:|
| 当前分数，总体 | 0.8842 | 0.8425 |
| 仅过去分数，总体 | 0.8824（过去 EWMA） | 0.8656（过去 10 步均分） |
| 当前−过去 10 步均分，总体 | 0.6189 | 0.5343 |
| 当前分数，回答首错对正常 | 0.7947 | 0.7327 |
| 仅过去分数，回答首错对正常 | 0.6259 | 0.5793 |
| 当前−过去均分，回答首错对正常 | 0.8096 | 0.7340 |

这支持：**持续性可以替代大量总体排序信号，首错处仍有新增判别信息。**
不能把 AUROC 的差或比值解释为模型“多少百分比学到了连续性”。
历史分数来自已监督训练的评分器，平滑并没有把它变成无监督方法。

固定同回答×前一个 token 标签后，既有条件 AUROC：CHARM 当前 0.7991、过去 EWMA 0.6109；
LDA full 当前 0.7575、history_mean 0.5536。
其来源分别为 `../continuity_units_20260920/prior_history/conditional_ranking.csv` 和
`../continuity_units_20260920/prior_lda/conditional_ranking.csv`。这是混合条件单元内的 source 汇总，
不要与 pooled AUROC 直接相减。上一 token 金标只用于诊断分层，不是可部署输入。

## 2. 本轮补算：什么时候才越过原阈值？

两模型沿用各自独立正常校准集约 5% token FPR 的原阈值；未在 test 重新选阈值。
CHARM 阈值 0.8048235774，LDA full 阈值 0.2768766398（两者分数单位不同）。
表中多步窗口为“至少一步报警”，不是每个 token 都检出，也不保证窗口级 5% FPR。

**每个回答第一次幻觉：**

| 观察范围 | CHARM | LDA |
|---|---:|---:|
| 严格在首错前 8 步 | 0/50 | 6/50 |
| 首错这一步 | 0/52 | 6/52 |
| 从首错起前 4 个 token | 10/51 | 22/51 |
| 整个首错标注片段内 | 30/52 | 44/52 |

两个回答首错前不足 8 步，不能补零计作未报警。一个首错片段不足 4 个 token，不能扩入段外凑数。
**全部 84 个标注片段：**前 8 步 CHARM 10/82、LDA 19/82；起点 5/84、12/84；
前 4 个 token 22/83、38/83；整段 51/84、70/84。
其中一些起点前已有别的标注错误；`*_incidence.csv` 已另列 clean_before、answer_first、run_onsets。

## 3. 同样观察正常片段，会不会也越过阈值？

使用既有固定的 50 对 cluster 匹配片段、40 个 source，不重新选择有利对照。
错误与正常使用同一长度、同一观察位置及同一阈值。

| 观察范围 | CHARM 错误/正常报警 | LDA 错误/正常报警 |
|---|---:|---:|
| 片段前 8 步 | 4/50 对 4/50 | 12/50 对 9/50 |
| 起点 | 2/50 对 0/50 | 7/50 对 0/50 |
| 前 4 个 token | 9/49 对 2/49 | 21/49 对 3/49 |
| 整个片段 | 26/50 对 4/50 | 40/50 对 7/50 |

按 source 聚合后的错误−正常报警率差，2,000 次 source bootstrap：

| 范围 | CHARM 差 [95% CI] | LDA 差 [95% CI] |
|---|---:|---:|
| 前 8 步 | +0.0167 [−0.0417, 0.0875] | +0.0333 [−0.0875, 0.1500] |
| 前 4 个 token | +0.1538 [0.0513, 0.2692] | +0.3974 [0.2436, 0.5385] |

片段前的阈值报警差没有明确证据；错误开始并持续几步后，差异更明显。
但“没有越阈”不等于完全不可区分：起点的成对分数胜率为 CHARM 0.86、LDA 0.76；
source 等权后为 0.8667、0.7833。**有相对排序差异，与达到低假阳性率阈值，是两个问题。**
这些是匹配子集结果，不能外推至没有正常对照的回答。
前 8 步的既有对照未专门重新匹配整个先前标签状态，不能解释为控制了所有历史混杂。

## 4. LDA 学到了什么，现在能说到哪一步？

输入为当前 token 的逐 head 特征时，LDA 学的是当前特征的线性判别方向；没有显式的标签序列模型。
当前 Transformer 特征本身可以携带历史状态，连续标注又会反复贡献同一段内的相近状态。
所以“线性可分”和“持续性贡献很大”兼容，但不等于 LDA 直接识别了标签连续出现。
打乱独立 token 的训练顺序也不会消除已经编码在当前特征里的历史。

现有证据未将训练所得分解为“历史可预测部分”和“当前新增部分”的因果贡献。
已有 `state_context_audit.py` 实现 FIT-only 历史回归后的当前残差再训练；本轮附件没有 FIT 原始特征，
因此没有声称已重跑该实验，或把当前−过去标量分数冒充该实验。

## 5. 真正的重锚发生率审计已改到全量起点

运行说明：`experiments/unsupervised_token_graph/span_audit/ONSET_AUDIT.md`。
入口 `python -m experiments.unsupervised_token_graph.span_audit.onset_run`。
排除 observer tokenizer 的全部特殊 token；保留每个标注起点、每个物理 head；
分别测严格早于起点和起点决策行，使用同一旧来源集合比较 attention 增量。
总体多头、多步最大值与正常窗口的同类最大值比较；输出阳性、阴性、缺测及官方总体缓存覆盖。
这只检验结构回看是否异常，不把读取到某来源解释为读取到正确证据。

实际验证：46 项 CPU 测试通过，包括特殊 token 排除、q→q+1、无未来行、距离边界不造变化、
多头正常比较、缺测分母及完整输出流程。**这些是软件验证，不是自然 attention 发生率。**

原始逐起点计数看 `charm_onsets.csv` / `lda_onsets.csv`；对照细节看 `*_pairs.csv`；
分组汇总与置信区间看 `*_incidence.csv` / `*_pair_summary.csv`；输入来源看 `protocol.json`。
冻结分数若含图上的后文信息，起点前分数也不能直接称为在线预警；本轮未新增 prefix 因果性验证。
