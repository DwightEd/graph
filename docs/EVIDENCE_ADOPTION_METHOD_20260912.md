# 从消息传递到证据采纳：新的问题定义与方法

日期：2026-09-12。设计状态：机制探针已实现，效果和完整检测器尚待验证。
用户本轮明确扩展目标，要求识别首错之后的延续和影响范围；旧实验负结果不变。

## 先澄清要识别什么

熵可用于提出疑似起点，但没有证明它能可靠识别每个首错。旧完整样本的
first-error AUROC 为0.8442；在冻结阈值、过去8步命中窗口下只命中24/59。
因此不能把“起点已知”暗中带入最终自动系统。机制阶段可提供人工种子，
但必须标记为 oracle-seed 诊断，与自动起点结果分列。

三个目标分开：

- **事实错误区间**：当前陈述与给定可靠来源矛盾或缺乏支持。
- **种子的影响范围**：该段历史的特定消息被削弱后，哪些后续预测改变。
- **话题/陈述切换**：新内容开始。换句号不等于不再依赖旧内容；同话题内也可纠正。

例如“烤香肠10–14分钟；因此洋葱也煮10–14分钟；不对，洋葱应另按配方处理”：
最后的纠正仍可能高度依赖错误句。把所有依赖后代都标错会把纠正误判。
若下一句开始谈烤箱温度，则旧错误影响可能减弱，但温度陈述本身仍需独立核验。

## 主线：带方向的信息采纳，而非注意力质量

原默认图方法用注意力传播候选方向上的隐藏状态投影，再做来源隔离的异常评分；
之前的两层G读出只测source上下文兼容度。两者均不测实际V/O消息经过下游计算
后对输出造成的贡献，因此不能用它们证明“看到了却没有采纳”。

新路线采用三个相连、可分别证伪的量：

1. **传到了什么**：实际消息 `m[l,h,j->q]=A[l,h,q,j] W_O[l,h] V[l,h,j]`。
   输入层归一化已包含在V中，GQA显式复制共享value头；先保留头，再分析正负。
2. **支持了哪个输出**：对固定候选差 `d=z(c)-z(k)`，记录组消息的局部贡献
   `a[g,c,k]=∇_r d · sum_(h,j in g) m[h,j->q]`。梯度穿过下游MLP/残差/RMSNorm。
   与实际削弱消息后差值的变化比较，不能把线性近似叫作精确因果效应。
3. **之后是否继续采用**：对疑似历史段S做预声明访问干预，记录
   `I[S,t]=JS(p_t, p_t^(cut S))`，以及特定候选差的带符号变化。
   JS只表示依赖；方向才区分继续支持某假设和反对/纠正它。

对固定候选差，设正向质量P、反向质量N分别为各组贡献正/负部分之和：
`competition=2 min(P,N)/(P+N)`。同时报告P、N和P+N；零质量不可判定。
只有标量比例而没有证据量，会把极小噪声抵消误称为强竞争。结果依赖分组
粒度，必须固定分组；头内、来源句间、来源与历史间的抵消是不同诊断。

例：一组贡献+3、另一组-2，竞争度0.8，净作用+1。两组均为+3和+2时竞争度0。
这个量是“候选差上的相反计算作用”，尚不等于两条语义事实互相矛盾。不同
正确措辞也可能竞争。不能直接将其归一化后当幻觉概率。

## 当前最小实现与尚未实现部分

已实现：`route_graph/adoption.py` 提供真实末层消息分解、包含末层MLP的fp32后缀、
所有候选差的导数、各头/各组带符号贡献、0.1/1.0削弱对照、固定后文的访问干预
与全词表JS。`reanchor/src/decoding/adoption_probe.py` 负责已存自然样本重放。
两者不改动默认检测器，不以新分数冒充自然检测性能。

候选目前为原生top8加source中全部非特殊、有字母数字的唯一token。相比仅top4，
它避免某个source数值因不在原生top4中而完全缺席，但仍是词元而非事实假设；
多词关系、分词边界和等义词尚需命题级对照。分句也仅为因果标点分组，不是
由真值实体关系构建的图。

末层选择用于低成本检查“方向贡献是否可信”，不是从自然标签选出的最优层。
前面31层已发生的证据聚合被压缩在输入残差中，本探针不能重新归属这些信息。
bf16真实输出与fp32后缀存在数值差别，要逐查询报告，特别检查候选次序翻转。
固定后文访问干预也没有删除该事件的全部语义信息，更不等价于自由生成的总效应。

下一步才扩展为多层有向计算图：节点是(层、位置、attention前/后或MLP后)状态，
边是实际attention消息、残差连接和MLP更新。时间/层方向取自计算过程，无需真值
标签，也无需先搭一个跨样本知识图谱。语义句组是图的读出单位，不能抹去层方向。

数据使用层次：原生logits给候选及熵；A/QK给访问和竞争门控；V/O给传递内容；
残差/MLP前后状态给聚合与转换；梯度及干预给输出采用；过去句组给时间范围。
不会把“所有FFN都是参数知识、所有attention都是外部证据”当作已知，因为二者
的输入均可携带混合信息。先保存可解释的量，再检验是否存在额外互补信号。

## 如果直接读出不够：自监督学习干预结果

冻结LLM，收集不含幻觉标签的自然前缀以及组消息削弱/替换后的真实输出变化。
两层小GNN预测被留出的干预效果：候选差变化与JS，使用Huber等回归损失。
训练目标来自模型计算而非人工真值，这叫自监督机制蒸馏；不是无需训练。
先预测可观测干预，再检验这些表示对事实错误是否有额外价值，不能只做自编码
重构并假定低密度样本就是错误。

同输入、近似参数量的MLP/DeepSets是必需对照。还要断边/换边而保留节点信息；
只有连接结构在来源隔离验证中额外改善干预预测和连续错误检测，才保留GNN。
训练标签不得利用幻觉标注，测试标签只在冻结分数之后用于评价；含监督训练的
NLI/事实核查基线若使用，须另列监督来源，不能混入严格无幻觉标签条件。

持续跟踪器应保留“仍在沿用/开始反对/证据切换/不可判定”等计算状态。低影响
且新陈述读取另一组证据，可以提出影响结束候选；是否恢复正确仍靠来源支持
验证。阈值在独立校准来源固定，并单列未定位起点、同话题纠正、跨句错误延续、
话题转换后新错误。当前没有实现或验证这个完整跟踪器。

| 方法 | 可利用内容 | 当前不能据此推出的结论 |
|---|---|---|
| [ALTI, EMNLP2022](https://aclanthology.org/2022.emnlp-main.595.pdf) | 把消息、残差、归一化一起考虑 | 注意力或上下文混合比例就是证据采纳/事实真值 |
| [DecompX, ACL2023](https://aclanthology.org/2023.acl-long.149/) | 跨组件传播词元分解，考虑FFN及输出端 | 编码器分解可原样精确搬到Llama；本探针已完整实现DecompX |
| [Information Flow Routes, EMNLP2024](https://arxiv.org/html/2403.00824v2) | 由真实attention/FFN/残差构建单样本计算图 | 计算图本身是新意；非负重要性就能表征抑制方向 |
| [ReDeEP, ICLR2025](https://arxiv.org/html/2410.11414) | 关注外部上下文保留与FFN前后变化，直接相关基线 | 原论文分析/回归可自动视为完全无监督；两分数已实现严格解耦 |
| [GLEM, ICLR2023](https://arxiv.org/html/2210.14709) | 文本和图两路表征、互教思路 | 已有标签节点分类和伪标签结果就是连续幻觉检测 |
| [GraphAdapter, WWW2024](https://arxiv.org/html/2402.12984) | 冻结主干、瓶颈融合、缓存表示 | 官方实现是在LLM每层注入图残差；修改生成器就能解释原生成器 |
| [GraphPrompt, WWW2023](https://arxiv.org/html/2302.08043v2) | 子图读出与少量可训练提示 | 原论文是LLM图序列化零样本SOTA；其下游少样本标签可忽略 |
| [GraphCLIP, WWW2025](https://arxiv.org/html/2410.10329v4) | 图—文本对齐；可探索与干预预测共享表示 | 语义相似等于被实际采纳；完整预训练保证单3090可复现 |
| [Semantic Entropy Probes](https://arxiv.org/abs/2406.15927) | 用可计算但昂贵的信号教轻量探针 | 预测不确定性等于事实或影响范围标签 |
| [Mu-SHROOM, SemEval2025](https://aclanthology.org/2025.semeval-1.322/) | 多语言幻觉跨度评测的参照 | 幻觉跨度标注就是某错误的因果影响标签 |

更聚焦的待证贡献是“用输出方向与干预校准的信息流，区分错误持续采用和证据
切换”，不是“LLM+GNN”这一组合。它是否足够新、是否优于现有方法，尚未得到
研究审稿或自然检测实验支持。外部研究审稿后端不可用，不伪造通过状态。
