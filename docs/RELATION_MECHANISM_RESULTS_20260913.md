# O4–O5：阶段关系、路由与回看定位

2026-09-13。这是一个来源上的受控机制结果，不是全量幻觉检测结果。
主线算子在 graph，执行在 reanchor；全量 RAGTruth 使用原冻结代码继续运行。

## 这次解决了什么

在数字、数字位置和生成前缀固定时，仅交换来源中的 Before/After，模型能在两种查询下随关系改变选择。
这个对照主要通过来源连接权重 E 的替换改变输出；只替换来源 V 内容 X 不足以在最终 query 改变选择。
因此，原先对数值身份的 X 干预结论不能直接迁移成动作/阶段归属机制。

但目前的无标签读出没有成功：预先固定的节点 N、注意力 A、消息兼容度 G 在四个条件中分别选对 3、2、2 个，A/G 总选 14。
“内部计算使用了关系”和“我们能自动从图读出正确归属”仍是两件不同的事。新读出不接入默认检测器。

## 输入、变量与评价边界

- 使用真实 source14375 / response00012，保留原始完整回答前缀。实际回答是从 **grill** 取出香肠后煮洋葱；原来源中的 12 对应从 **beer mixture** 取出之前。原案例同时有动作/地点/阶段差别。
- O4 在两个来源世界都写明 from the grill，加入两条明确阶段规则：Before 对应 10–12，After 对应 10–14；另一个世界只互换 Before/After。
- 两个关系词改变，token 多重集合、数值、数值位置完全一致；prompt 长度 549，数值 12/14 在 89/114，关系词在 67/92。
- 查询为真实 after 前缀和构造 before 对照，各两个世界。目标数值前预测步分别 t=131/132；真正计算该预测的 query 位置为 P+t−1。
- X 替换来源 V；E 替换来源内连接分布并恢复当前接收状态每头的来源总质量，V 保持当前值；XE 同时替换。逐层重新前向，后续层使用受干预后的接收状态。
- E 是对已形成的 attention 路由做干预，不隔离 Q 与 K 的成因。当前结果不能写成“已证明 K 独立承担绑定”。
- 每世界保存真实 Q/K（RoPE 前）、V、A、query 残差及 MLP、逐层 N/A/G 和完整词表 logits。N/A/G 固定平均全部 32 层，不按结果挑层或头。
- N 为 query 与候选 V 经 O 投影后的余弦；A 为候选端点平均头权重；G 为实际 A×V 经 O 投影后在 query 方向的兼容度。G 不是对目标答案的有符号输出贡献。N 也含上游上下文，不能把 N/A/G 当作完整 GNN 与无上下文模型对比。

构造预期值仅用于独立评价；数值端点本身预先指定，尚非自动候选发现。四个条件共享一个来源，不能计算成四个独立自然错误。
尤其原来源没有为当前洋葱阶段提供唯一时长；添加规则后的二选一成功不能说明原始幻觉已被修复。

## O5：E 的位置与层扫描

O4 出现 E/X 差异后，另行冻结 O5 协议，复用 after/world0 接收世界与 world1 供体。
覆盖 t=0…131 每个单 query 的全部层 E、最终 query 的 32 个单层 E，以及全 query、去最终 query、同世界 sham，共 167 条件。
这不是按 O5 结果选择“最好”的扫描区间：完整范围和 top-8 候选在查看 O5 结果前已固定。

| 干预 | 原生 top-1 | margin | 说明 |
|---|---:|---:|---|
| baseline / sham | 14 | +1.250 | sham 全 query logits 精确相同 |
| 仅 t=131，全部层 E | 12 | −0.875 | 唯一能单 query 翻转的扫描位置 |
| 仅 t=119，全部层 E | 14 | +0.125 | 接近翻转，但仍唯一选 14 |
| t=0…131 联合 E | 12 | −1.125 | 联合充分 |
| t=0…130 联合 E | 12 | −0.250 | 最终 query 保持原生，联合仍充分 |
| t=131 任一单层 E | 全为 14 | 最小 +0.500 | 32 个单层均未翻转 |

t=119 的 query token 是 ` and`，正在预测 ` cook`，位于“取出香肠，然后煮洋葱”的动作衔接处。
t=131 的 query token 是空格，已强制给定 `... for 10 to `，正在预测上界数值。
这两个位置说明动作衔接与数值落地可能在不同步起作用；目前只有这个案例，不能据此硬编码分段规则。

**充分和必要必须分开。** t=131 单独 E 充分；但 t=0…130 联合 E 也充分，因此 t=131 不是本组联合供体替换所必需的补丁位置。
这个实验并没有删除模型的 t=131 计算，所以不能进一步声称原生最终 query 计算不必要。
结果也不能排除更早的分布式路由、冗余通路和非线性累积。

**当前自动候选规则未通过。** 冻结“来源注意力总量正增量”top-8 为
`[11, 36, 16, 31, 94, 2, 115, 88]`，未覆盖 t=131；对“单 query E 使原生唯一选择变成 12”的集合，召回 0/1。
这只是该供体、该干预定义下的候选覆盖，不是通用回看真值上的召回估计。
熵或来源总量都没有得到 100% 定位保证。下一版候选应检查来源内部对应关系的改变，并保留联合位置组；不能在本例上把 t=131 补入后宣称验证通过。

O5 runner 55.74 秒，峰值 allocated 15.37 GiB；175/175 文件哈希、167 个完整词表端点通过。
基线完整复现 O4，最终 E 端点逐值复现 −0.875 的原始 logits。前缀误差与 sham 误差均为零。
来源质量保持的最大浮点误差 2.98e−7。

## 方法取舍与下一项实验

1. 保留完整高维属性图和真实消息算子；拒绝把全层平均余弦/attention 质量当成已有效的归属风险分数。
2. 将“约束是否适用于当前动作/阶段”与“消息是否向某个输出候选提供支持”分别建模；高依赖不等于支持，高支持也不等于有来源依据。
3. 回看研究对象扩展为可联合起作用的位置组；分别验证单点充分、联合充分和去掉某点后的条件性变化，不假定唯一节点。
4. 优先补“没有适用约束”与**开始补出具体时长之前**的决策。当前强制 `for 10 to` 的二选一不能回答这个问题。下一项设计见 [O6 准备方案](MISSING_CONSTRAINT_PLAN_20260913.md)。
5. 随后才进入错误延续/纠正/换题、保留跨 span 边的自适应分组，以及同输入非图对照。尚无自动图→风险实现、自然连续错误检测结果或 GNN 增益。
