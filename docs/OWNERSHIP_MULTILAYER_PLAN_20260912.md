## 固定矩阵

1. 层组：{7,15,23,31} 与全部零基层 0–31。

   E 继续保持接收条件每 head/query 的 source 总质量，不测总读取量效应。
4. 两层组×两窗口×三位置范围×四因子=48 条件；两层组各 XE/MLP 同世界
   全查询替换共 4 个 sham。多层干预每层以当前实际 A/V 为接收基准。
5. 全 32 层 X：每个窗口内逐个 query 单独替换，以及窗口整体减去该 query，
   共 (7+13)×2=40 条件。逐项保留结果，不把最大值命名为唯一“回看真值”。
   only-one 的充分性和 leave-one-out 的条件必要性分开解释，不假定可加性。
6. 拓扑压力对照：保持原始 source V，仅将各层当前 A 在 source token 76/341

   它保持每 head/query 的 source 权重多重集合和总量（浮点归一化容差内），破坏两端点对应。
   这是已知端点的机制干预，不能视为无标签检测器或完整图必要性验证。

## 可证伪解释与边界

- 若 final-query 跨层 X 即能转移数值偏好，来源数值可在最终查询多层累积进入；
  不必先假定存在一个更早且唯一的筛选节点。
- 若仅 all-history 有较大效应，优先检验中继；若 window 已足够，再看逐节点作用。
- 若 E 捐赠弱但端点置换强，只能说明本次来源值交换主要改变内容、原连接对应仍重要；
  不能用弱 E 捐赠反推拓扑无用，也不能把任意扰动有效当成图模型优于非图。
- MLP 捐赠是分支输出反事实，不等同参数知识、错误归属标签或自然修复。
- 仍只有一个来源、一个实际错误数值窗口；所有统计为配对干预描述，不报检测准确率、
  p 值、跨来源泛化或100%定位。独立科学审稿后端不可用，REVIEW_UNAVAILABLE。
