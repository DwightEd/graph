## 后续核验前必须保持的区分

1. 来源是否明确给出当前对象/动作的某个约束，还是仅出现其他动作的相似数值。
2. 模型内部是否保留了不同归属的可辨信息，及输出是否采用正确归属，是两个问题。
3. “检测器读不出来”和“信息不存在”不等价；反之，监督诊断probe可读也不等价于
   无监督方法已成立。诊断监督、检测训练和最终评价须分别记录。
4. 回看候选点的定位须有独立干预依据；熵峰、attention变化和分隔token不能自动
   作为真值。真实语义决策也可能早于数字输出（例如先决定补上某个未给出的时长）。
