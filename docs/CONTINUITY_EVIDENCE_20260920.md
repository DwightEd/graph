# 连续性、当前判别信息与句子级检测：证据复核

2026-09-20。结论：**持续性能够替代大量总体 token 排序信号，尤其在片段后段；现有证据不支持“监督检测只学到了持续错误”，也不能给出一个可信的“训练贡献百分比”。** 句子级检测值得作为独立终点继续验证，但需要明确等待成本，并保留起点和短错误的评价。

本轮实际操作：下载官方 RAGTruth 数据；读取已上传 CHARM、LDA 原始逐 token 分数；重算标注分母、评价重加权、句子聚合与固定配对延迟。不重新训练分类器，不运行生成 LLM。另修复用户新机制审计的汇总布尔计数。两套工作不能混称为同一新实验结果。

## 1. 用户新贴的机制摘要说明什么

原摘要为 2 sources、2 pairs、16 measured phases、1120 effects、448 interactions，adaptation/persistence 失败数为 -64/-80。

| 字段 | 可以解释的内容 | 不能据此解释的内容 |
|---|---|---|
| sources=2、pairs=2 | 两个独立来源、两个局部声明配对的 pilot | 广泛幻觉机制、稳定检测成绩 |
| measured_phases=16 | 与 2 配对 × 正负侧 × 4 阶段一致 | 各阶段存在显著差异 |
| finite_effect_rows=1120 | 已保存 effects 行数，含多个头、来源组、剂量及随机控制 | 1120 个独立样本；1120 个非零或通过数值控制的效应 |
| interaction_rows=448 | 已记录联合实验行数 | 448 次协同或冲突 |
| minimum_effect_nats=.05 | 描述性效应分类门槛 | p 值、显著性水平或检测阈值 |
| purpose | 标签辅助机制审计 | 盲测、无监督检测验证 |

负数的代码原因已复现：空阶段 CSV 与非空表合并可能使 `numeric_ok` 成为 object 列；此时 Python 布尔取反得到 `~True=-2`、`~False=-1`。因此旧 `(~flags).sum()` 不再数失败。-64/-80 与 32/40 行全 True 相容，但仍应从原表重算，不直接宣布所有控制通过。

修复：读取时指定 nullable boolean，忽略零行阶段表，用 `eq(True/False)` 分别计数；新增 `control_rows` 的总行数、通过、失败和缺测。缺测不被当成通过。无需重跑 GPU：

```bash
python -u main.py flow --stage report
```

本次未取得用户这轮的 `paired_review.tar.gz`；不能从摘要填造单头作用、条件反转或持续性结果。应读取以下量：

| 研究问题 | 先读哪些表/字段 | 判断约束 |
|---|---|---|
| 单头帮助哪一侧 | effects：support、source_group、dose、selection | 先通过 sham；onset 的 D=F完整−F删除，正值维护 supported-vs-unsupported margin；其他阶段的正值只维护实际下一 token 的概率 |
| 冲突、依赖、冗余 | interactions：左右单独作用、左右条件作用、joint_support、interaction | J 的正负不能单独叫协同/抑制；检查单独与条件作用是否反向，以及小单独作用/大联合作用 |
| 下游补偿或传递 | adaptation：deletion_support、restoration_gain、sham_error | 恢复后是接近还是远离完整 readout；正 gain 不自动等于补偿，也不自动是中介比例 |
| 作用是否留到后续 | persistence：support、null_error、phase | 固定 teacher-forcing 文本下的跨位置效应，不是自由生成重复犯错的证明 |
| 幻觉与正常有何不同 | paired_*：同物理 head、同阶段、同来源组的正负侧差 | 正负自然历史不同；非 onset 两侧实际 token 可能不同；不能拼成同尺度事实曲线 |

头是由这两个配对的梯度挑选的，当前审计主要用于发现候选模式。指针、地址、载荷的语义命名还需要独立交换实验；本摘要并不提供这些证据。

## 2. RAGTruth 标注单位及真正的连续性分母

官方提供的是回答中的**幻觉字符区间**，保存 `start/end/text/label_type`；不是规定把整句话都标错。项目通过原字符位置映射到模型 token。一个标注区间可以是短语，也可以跨多句。`implicit_true` 表示缺少上下文支持但可能符合外部事实的情况，因此这里的标签不是“世界知识真假”的同义词。[官方数据说明](https://github.com/ParticleMedia/RAGTruth)、[论文 §3 与附录](https://arxiv.org/html/2401.00396v2)。

### 2.1 本轮官方全量统计

实读 17,790 回答、2,965 来源、14,289 原始标注区间、7,664 含错误回答。全部标注的 `response[start:end]` 与 `text` 一致，0 个不匹配。

为了检验“整句标注”的假设，用已有、与标签无关的标点分句规则；完整覆盖定义为句中所有字母/数字字符都落入标注并集。该规则是可复现的文本代理，编号、缩写和列表仍影响分句，不冒充人工句子标注。

| 官方任务 | 含标注内容的标点句 | 内容完全覆盖 | 只有部分内容覆盖的比例 | 跨标点句的原始 span |
|---|---:|---:|---:|---:|
| QA | 4,831 | 3,330 | 31.07% | 913 / 2,927 |
| Data2txt | 7,847 | 502 | 93.60% | 34 / 9,290 |
| Summary | 2,037 | 454 | 77.71% | 37 / 2,072 |
| 合计 | 14,715 | 4,286 | 70.87% | 984 / 14,289 |

这说明任务差异很大：QA 的长跨度标注确实大量覆盖完整句子；不能把这个特点推广到整个 RAGTruth。全量脚本另报词法单词统计，明确**不是模型 token 数**；本轮未为全量官方数据重新运行观察器 tokenizer。

### 2.2 当前 CHARM/LDA 测试集：真实模型 token 统计

同一批 149 QA 回答、149 来源、30,619 token、2,307 幻觉 token。原始 85 个字符标注映射并合并重叠后为 **84 个 token span**；相邻但不重叠仍保持独立，所以连续正标签游程为 **79**，不能混成同一种 span。

| “后续”具体指什么 | 分子/幻觉 token 总数 | 比例 |
|---|---:|---:|
| 所在标注 span 内，除首 token 外的续错 | 2,223 / 2,307 | **96.36%** |
| 回答首个错误 token 之后的所有错误 token | 2,255 / 2,307 | **97.75%** |
| 回答中第二个及以后标注 span 的错误 token | 749 / 2,307 | **32.47%** |
| 各标注 span 后半段的错误 token | 1,174 / 2,307 | **50.89%** |

平均 span 长度 27.46 token，中位数 20，最长 261。后半段约占一半主要来自划分定义，本身不是持续机制证据。96.36% 是该 QA 子集的结果，不能写成全 RAGTruth 的比例。

## 3. 哪些证据支持连续性贡献很大

### 3.1 用过去的监督分数替换当前分数

CHARM 旧分数在共同有效的 30,470 token 上比较，缺少过去分数的每答首 token 一律排除：

| 人群 | 当前分数 | 过去 EWMA | 当前减过去十词均值 |
|---|---:|---:|---:|
| 全体，AUROC | 0.884152 | **0.882432** | 0.618871 |
| 回答首错 vs 正常，51 个可测首错 | **0.794699** | 0.625853 | **0.809631** |
| span 续错 vs 正常 | 0.885701 | **0.888420** | 0.613358 |

LDA 同样在人群完全一致时：当前 0.842472，过去十词均值 **0.865594**，当前增量 0.534348。过去分数能维护总体排序，并不意味着不需要监督学习：这些历史分数本身来自监督分类器。

而且“变换只看过去分数”不保证整个系统在线因果。若底层 CHARM 的完整图评分使用了未来节点，过去分数仍可能含未来信息。必须另做逐前缀回放；现有分数审计没有替代这个验证。

### 3.2 相似正常窗口下，后段尤其容易由历史解释

固定原 50 对、40 来源、两侧各 904 token 的 cluster 匹配，不按分数重挑正常对照。CHARM 来源平衡配对 AUROC：

| 分数 | 前半段 | 后半段 |
|---|---:|---:|
| 当前 | 0.842071 | 0.813371 |
| 过去 EWMA | 0.792694 | **0.845138** |
| 过去十词均值 | 0.764838 | **0.843513** |
| 当前增量 | 0.737829 | 0.600103 |

历史积累在后段的替代能力更强。原当前分数的错误减正常间隔在后半段增加 0.066569，但 AUROC 变化为 -0.028700，探索区间跨 0。**分数升高、越阈值召回增加、相对正常的可分性增加，是三个不同结论。**

### 3.3 本轮新增：减少长 span 的评价权重

不改变模型，把每个正 span 的评价总权重调成相等，再归一化保持共同覆盖中的正例总权重。正常 token 权重仍为 1：

| 模型/分数 | 原 token AUROC | 正 span 等权 AUROC |
|---|---:|---:|
| CHARM 当前 | 0.884152 | 0.874476 |
| CHARM 过去 EWMA | 0.882432 | 0.865854 |
| LDA 当前 | 0.842472 | **0.842758** |
| LDA 过去均值 | 0.865594 | **0.840874** |

LDA 的过去均值优势在这个评价口径下消失，而当前判别力基本保持。这支持“长片段加权特别有利于历史分数”，也限制了“当前分类器高分完全来自长片段”的解释。**这只是评价重加权，不是训练损失干预。**

## 4. 哪些证据说明不只是重复、持续状态

### 4.1 同模式正常片段依然可区分，但并非全部检出

原 cluster 配对控制同回答、长度、粗相对位置、首词表面类别、重复率及七项粗结构描述量。它不保证语义、逐头向量和精细拓扑相同；严格逐头匹配实际为 0 对。

- 50 对的 CHARM 配对等权 AUROC 0.821668；按来源等权为 **0.831864**。LDA 来源等权为 **0.788988**。
- 原 CHARM 阈值下：26/50 错误窗口至少有一个报警；46/50 正常窗口完全没有报警；同时满足两者只有 **23/50**。
- 仅 2/50 错误窗口达到 80% token 覆盖，0/50 全覆盖。不能把一次报警扩展成整个 span 全对。
- 首词分数 43/50 高于正常伙伴，但只有 2/50 过阈值。低首错召回不能直接解释为首错没有排序信号。

### 4.2 固定历史条件之后，当前信息仍有效

CHARM 在“同回答 × 上一个真实标签”条件格内，来源平衡 AUROC：当前 **0.799128**，过去 EWMA 0.610899，过去均值 0.555264，当前增量 **0.798404**。金标只用于分组，不能作为部署输入。

LDA 旧完整条件表的覆盖并不一致：context 下 full 有 1,591 token，history/increment 只有 1,586。本轮重新使用六种评分共同有效的位置计算，108 个混合格、51 来源：full 0.805381、history 0.566957、increment 0.753512、prompt-only 0.753997。与前一份证据台账一致，保存为 `lda/conditional_common_coverage.csv`；不能混用不同分母的小数。

特别是“前一个标签已经错误”的分支，LDA 历史均值 AUROC 仅 0.481234，当前增量 **0.748569**。历史分数难区分继续错和转回正常，当前变化能提供退出信息。

### 4.3 剩余判别力目前可定位到什么

LDA 使用类标签估计均值差与类内协方差，是 **Linear Discriminant Analysis，有监督**。无监督表示后接 LDA，整条检测管线仍有监督；不能与无标签混合模型合并报成绩。

原 LDA 全流结果：full 0.842735；只用协方差对角项 0.761742；保留层内块 0.817908；去掉 head 身份 0.800295；head contrast 0.841358。这些模型的输入本来都是各 head 的 attention 对角线，**协方差对角消融不是“只用 self attention”的另一种说法**。

在同 50 对上，full 相对协方差对角项增益 0.055117，探索区间 [0.025744, 0.084212]；相对层内块仅 0.005253，区间跨 0。支持保留头身份、相对强弱和协方差；跨层协方差不可替代性尚未证明。

prompt-only 全流 AUROC 0.869236；对 self 向量回归掉可由 prompt 向量线性预测的部分，再训练 LDA，降至 0.564530；self+prompt 0.871994。说明信号存在很大统计重叠，不表示“多少百分比的幻觉因果由 prompt 引起”。

已有节点网络白盒记录：监督投影主方向在 50 对上的排序近乎保持（0.804638 → 0.804678），删除该方向为 0.516331；不同 head 可以通过相反符号共同增加风险。该结果来自旧自然实验及已核对台账，本轮不宣称重跑 SVD/积分干预。

已有无标签双高斯复核：两成分错误率接近，成分后验的真假 AUROC 0.498806；成分内部 LDA 仍约 0.843。这说明密度聚类方向没有对准监督判别方向，不证明所有无监督方案无效。

这些证据尚不能把余下判别力命名为原 LLM 的“事实绑定头”“信念状态”或“证据冲突”。位置、词法、句式、置信度、上下文关联仍可能参与。需要新的自然来源和独立原生干预来识别具体功能。

## 5. 本轮实际新增的句子级与延迟实验

### 5.1 完整句子检测

利用原 token 文本精确拼回官方 response 后建立字符坐标；全部 149 测试和 82 校准回答均精确一致。分句不读取标签；句子标签定义为“含至少一个标注 token”，评分采用预设的均值/最大值/top4 均值三种聚合，全部报告，未选出一个所谓新最优模型。

共 1,706 个有分数的句子，163 阳性、1,543 阴性。79 个标错空白/非文本 token 没有句子归属，明确保留在 token 统计中。每个句子内，各评分只聚合同一组有限值位置；句子标签使用整个句子，不因历史首值缺测而改标签。

LDA 使用独立的 82 回答校准集；按 957 个正常句子的 95% 分位数分别设阈值，不用 test 调阈值：

| LDA 分数/聚合 | 句子 AUROC | AP | 测试 recall | 测试 FPR |
|---|---:|---:|---:|---:|
| 当前 full，均值 | **0.881770** | 0.606433 | 41.72% | 1.62% |
| 当前 full，最大值 | 0.877396 | 0.553172 | 42.33% | 2.46% |
| 历史十词均值，句内均值 | 0.840825 | 0.525776 | 27.61% | 1.10% |
| prompt-only，句内均值 | 0.885626 | 0.616608 | 39.26% | 1.17% |
| prompt-only，最大值 | 0.895320 | 0.625747 | 43.56% | 1.23% |

CHARM 当前最大值/均值 AUROC 为 0.890425/0.880219；过去 EWMA 最大值/均值为 0.879646/0.872132。本次取得的 CHARM 包没有独立 calibration 分数，所以**不报告新句子阈值下的召回/FPR**。

同回答、相同 token 长度对数桶内的混合标签格，有 69 格、375 句、44 来源；来源均衡条件 AUROC：LDA 当前均值 0.834151、历史均值 0.777258；CHARM 当前均值 0.876047。控制句长和回答身份后仍保留信号；不是同语义句子配对。

换单位会改变标签占比及问题难度，不能把 token 与 sentence AUROC 的差直接写成算法提升。均值还可能稀释短错误，最大值易受长度影响，二者必须继续共同报告。

### 5.2 等几个 token 是否必然更清楚

同一组 43 个长度至少 8 的配对、36 来源，固定伙伴并要求全部 k 可测。k=1 表示已观察第一个标错 token，k=8 表示再等 7 个；不将这里的金标起点输入部署检测器。

下面是每对错误分数高于正常分数的来源平衡胜率，**不是 pooled token AUROC**：

| 分数，取第 k 个位置 | k=1 | k=2 | k=4 | k=8 |
|---|---:|---:|---:|---:|
| CHARM 当前 | 0.8935 | 0.8519 | 0.8380 | 0.7870 |
| CHARM 过去 EWMA | 0.7269 | 0.8796 | 0.8657 | 0.8148 |
| LDA 当前 | 0.8009 | 0.8380 | 0.6852 | 0.8287 |
| LDA 过去十词均值 | 0.6435 | 0.6713 | 0.8796 | 0.8935 |

历史评分随错误 token 被纳入过去而变强，符合持续性解释；当前评分没有一致的单调改善。区间很宽，不能据此声称某个 k 全局最佳。完整表另保留每个 k 全部合格配对，避免把短 span 退出队列造成的样本变化叫“越等越准”。

若等到句末，163 个错误句从其首个错误 token 到末 token 的额外等待：中位数 **12**，均值 13.82，四分位数 3.5–22，最大 39。这里是一句内部等待，不是自由生成系统的实际告警时延。

## 6. 下一步收敛设计及尚缺实验

不立刻把每个 token 的两个量解释成模型原生的“历史状态/新注入状态”。先保留两个可验证的评分通道：当前输入证据与过去评分趋势；检验融合是否在固定误报下改善**起点、续错、恢复**。其中“创新量=当前−过去”只是统计残差式对照，不自动具有新证据语义。

句子级可作为完成后筛查的主要产品终点，同时保留 token/起点报告。在线短延迟方案应按每一步前缀重新计算底层分数，再报告无金标重置的告警及正常句的误报。不能把当前金标配对延迟表当在线检测成绩。标注起点也未必等于一个事实首次可判定的时刻：若整段起始于功能词，判别可能要等关键实体/谓词出现；后续应独立核验这种语义可判定位置，而不是默认每个金标首 token 都应该能提前识别。

| 要确认的命题 | 已有证据 | 尚缺的决定性实验 |
|---|---|---|
| 长 span 在训练中被过度计权 | 正例频数、评价重加权、历史替换 | 同初始化/来源划分的 token、span_equal、onset_half、random_onset_half 多 seed 重训；比较固定校准 FPR 下首错、续错、退出 |
| 历史错误使当前正确内容也高风险 | 条件排名、错误后正常处历史评分误报 | “此前独立事实正确/错误 × 当前命题有/无支持”的四世界，固定措辞位置，重算原 LLM 输入；缓存置换不能替代 |
| 当前增量是真实证据支持性 | 同历史格和同粗结构配对仍有区分 | 语义核验的正常/错误配对，控制复现、句法、长度、置信度与观察时刻，独立来源验证 |
| head 协作发生功能转变 | 旧有限干预及新 pilot 已运行摘要 | 先取得新完整表，核查单独/条件作用和数值控制，再冻结选择规则扩展来源；指针/地址/载荷要独立交换 |
| 句子级适合延迟检测 | 本轮实际句子评分、独立 LDA 阈值 | 独立新测试来源；前缀因果性；固定误报下的真实首报警时延和短错误检出；不由测试集挑池化规则 |

逐 token 独立的 node_only 模型没有显式标签转移状态；固定输入和标签共同打乱不会改变其确定性风险。因此“它直接记住了标签排列”不是准确解释。更合理的竞争解释是：LLM 输入已经携带上下文状态，标签的连续扩展又使这些状态在训练目标与评价中获得较高权重。

原连续性重训入口已经存在，当前可访问材料未找到完整自然重训结果；本轮没有 FIT 图缓存，不伪造重训结论：

```bash
python -u -m experiments.charm_structure_audit.main --mode continuity \
  --continuity-stage train --models node_only --continuity-seeds 0 1 2
```

该实验保存 loss 和 logit 梯度大小诊断；它们不等于参数梯度贡献。不能从“96.36% 续错 token”推出“96.36% 学习来自连续性”，也不能把 AUROC 差比值解释成因果解释比例。
