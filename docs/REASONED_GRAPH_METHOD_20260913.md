# 粗粒度来源结构上的外部语义参考与原生采用图

## 问题锚点

对冻结LLM，在不以幻觉标签训练的条件下，测量来源和历史的信息实际传递、聚合与输出采纳；区分疑似错误被继续沿用、被反对/纠正以及新陈述开始。事实区间和影响范围分别评价，熵只提供候选起点。

主线在 graph，机制和旧全量在 reanchor。本文只定义一个 **external semantic reference**：冻结语义模型给出可评估的事实/证据/修订预测，供后续内部联合模型和原生因果测量对照使用。它不是核心 internal-only ownership model，也不能把语义预测当作内部归属成功。软件实现、预测质量和机制识别必须分别报告，当前不声称完整方法有效。

## 为什么改结构

SourceRel 的来源字段重建验证 top1=95.40%，但自然回答出现地点→name、overall rating→review rating，地址数字甚至不在候选池。完整库存现已修复：2965来源、17790响应引用、1241059组件，unknown3049、长文本字段4083均保留。库存完整只解决可寻址性。

不再把下一个训练任务设成来源JSON字段重建，也不先运行未训练 token MaxSim。它们仍不能输出适用性与支持性。采用一个**冻结的、允许推理的语义预测器**，共同读取完整原文和显式来源结构，预测事实成员、证据集合、条件适用性及 S/C/N/U。这些是方法输出，不能充当训练或评价真值。

MiniCheck、AlignScore 的跨编码与语义监督说明相似检索和蕴含判定是不同目标；不能把它们的效果归给无训练余弦。本轮不引入其已接受事实监督的权重作为无监督主线。[MiniCheck](https://aclanthology.org/2024.emnlp-main.499/)、[AlignScore §3](https://aclanthology.org/2023.acl-long.634.pdf)。InPars/Promptagator 的自然查询合成可用于后续检索加速，但不是当前缺失的语义模块。[InPars §3–4](https://arxiv.org/html/2202.05144)、[Promptagator §3](https://arxiv.org/html/2209.11755)。

## 模型结构

```text
完整 prompt / response
  ├─ 完整来源库存：field/context/component + record/bundle 包含边（保留在inventory）
  ├─ Qwen渲染：完整原文 + 粗粒度field/record或text-context拓扑
  ├─ 回答词坐标：全部词保留，词面边界不等于事实边界
  └─ 冻结 Qwen3 联合编码、推理与结构解码
       ├─ 重叠事实成员 / 当前被判断的 target 成员
       ├─ 来源证据集合 + 条件解释 + S/C/N/U 分布预测
       ├─ 具体历史成员的 reuse/correction/quote/new 关系预测
       └─ 可选精确 B→A 单段修改预测
                 ↓ 冻结全部预测，原始坐标重建
       原始 Llama observer 消息图 + 同目标干预
                 ↓
       回看位置集合、来源/历史采用效应、未决路由/聚合状态
```

使用已在本地的 Qwen3-8B，主干冻结、无新增训练头。原文完整序列化进入 Qwen 的上下文，并只附加粗粒度的可观察结构：Data2txt 的 field/record/weekday-source-key 关系，或非字面来源的 text-context 关系。完整 component 图继续保留在 inventory，供内部联合模型或后续细粒度模块使用；本 external semantic reference 不把重叠 component 拓扑序列化给 Qwen。辅助Qwen表示、原始Llama replay隐藏状态、干预超边分开标注，不能混称原生成轨迹。

保留每个来源出现位置，不合并同值节点。Data2txt字段字面路径、真实父记录、unknown值作为观察信息；QA/Summary保留全部原文上下文。七天键集合只表示源侧库存。当前回答是否说“每天”、对应哪项评分等，由预测器解释，程序不先提供正确角色桶。

## 预测接口与计分

一次处理完整回答，避免重复给每个词建立开放问答。回答词有固定编号；预测器输出可重叠的事实成员区间及其 target 区间。成员用于保留关系与条件，target用于风险定位：同句里的评分错误不能自动涂抹WiFi描述。坐标合法不代表语义分解正确。

每个事实输出 `p=[P(S),P(C),P(N),P(U)]`，它是模型显式估计而非校准概率；`risk=P(C)+P(N)+0.5P(U)`。全体回答词都输出分数，未覆盖/解析失败为0.5且明确标注，不能删除；重叠target用算术均值，避免拆出更多重复事实后风险必然升高。源指针不合法只使该证据/机制入口不可用，保留该事实的原始语义预测与错误原因，不再以多门全弃权隐藏模型错误。

来源证据可以是多个字段/原文区间共同组成的集合，不能先top5截成单字段。N是“模型预测全文不支持”，不是严格缺失证明。输出的条件解释、owner、history关系均为预测，没有程序语法检查能替代其独立正确性评价。

冻结同源同回答的两个版本：`flat`保留相同完整原文和位置标记；`graph`额外提供 coarse field/record 或 text-context provenance，且明确不包含完整 component topology。共享模型、预算、解码设置、词坐标、输出格式及分母。这个对照只回答粗粒度显式结构是否帮助外部语义预测；不是核心内部模型结果，也不是把两次不同reader或候选集的增益归给图。

Qwen使用thinking=True，固定每请求随机种子，temperature=.6/top_p=.95/top_k=20。这是作者建议的推理解码设置，尚无本任务改进保证。[Qwen3官方模型卡](https://huggingface.co/Qwen/Qwen3-8B#best-practices)。生成达到预算仍保留原始输出和失败状态，禁止人工补造JSON/证据后算成功。

## 正误决策与准确回看

语义预测与机制目标分开。若存在明确的单段替代A，保留原回答B、全部非目标字符、完整句末后缀和原始token化，定义 `F=logP(B后缀)-logP(A后缀)`。A的语义正确性仍是预测条件；现有typed-hours能提供更窄的程序语义支持，二者分别统计。

从完整共享prefix的 query/layer/source-history组搜索实际F效应；不得先以attention峰值硬选一个“回看节点”。现有CausalOracle可执行联合干预，保存父组、子组、补集、未搜索前沿和原始高维h。定位输出是条件性影响集合，不保证唯一点、不保证100%。不能把有引用的语义节点直接称作模型已经回看。

没有A时，仍输出事实风险与结构预测；可用原始目标logP测依赖，但必须标为target-dependence，不声称已测正误选择。语义分数不因native效应大而变成真值。

## 路由与聚合的可识别边界

适用证据A由语义分支提出；实际采用证据由原生消息图提出。竞争证据不能仅按词相似度归一化：分别保留A与候选B在固定目标F上的方向、原输入→V介导、同位置控制调整效应与未测质量。没有真正可用的B，路由比较就是未决。

路由检验在固定层/query、固定移出质量下比较 B→A 和 B→无关控制，并保持消息内容定义。聚合检验要求A内容可从输入介导到目标，以及下游组合干预可选择性改变F；仅有A的attention或MLP大效应不够。若两类操作交互、剂量方向不稳、控制不足，报告混合或未决，不能强制二选一。

## 连续span与自适应范围

事实图允许非连续/重叠成员。跨span边连接具体历史值/关系的复用目标，而不是连接相邻句或同主题。语义reuse先给候选；再测历史原输入→当前目标的有符号影响。纠正、引用与复用分开；缺边只表示没检出依赖，不证明错误影响已结束。

事实错误范围来自逐target预测及独立span评价；影响范围来自有方向的历史路径，两者分别输出。图诱导的分段只改变聚合成员，全prompt和长距离边始终保留。首错后entropy全量AUROC仅约.548，不能作为连续错误主信号。

## 三个收敛关口与当前实现

1. **自然语义入口**：先完整旧36开发回答，flat/graph同预算；冻结后才评价RAGTruth词/span指标和错误实例。解析率、源指针合法率不是准确率。完成后在官方留出集评价，旧36不当最终证据。不读官方test作为接口调参集。
2. **真实决策定位**：冻结语义预测生成全部可构造B/A，分别报告观察者原本偏好、自动位置覆盖、控制和输入介导。只在可识别部分论断回看/路由/聚合。
3. **连续影响与图增量**：语义单独、显式拓扑、加入已测采用/历史边分别输出；评价首错后、纠正/新陈述、span边界及成本。若无增量就保留负结果，不能凭故事增加GNN。

库存已实际完成并独立审计。新的语义graph编译/运行器正在实现；本设计尚无新GPU结果。严格机制代码继续复用，原冻结产物不改。一次方法迭代必须交付完整预测分母及错误分析，不再把候选产出视为方法收敛。
