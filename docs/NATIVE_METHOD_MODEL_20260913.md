## 样本怎样成为图

输入是一个完整的 prompt、response 及原始 observer token 坐标。图包含两个相互映射的层次：

- 文本层节点：来源文本单元、回答中的事实断言、具体答案槽位及其条件问题；保存精确字符和 token 区间。
- 计算层节点：各层、各 query/key 位置及其分组；高维内容来自冻结 Llama 的实际 V、注意力聚合消息和 MLP 输出。它们不由关键词或手工标量替代。
- 计算层边：实际注意力权重 A 与实际向量 V 形成的消息；保留 source、history 角色、query/key/layer 坐标及因果可见性。文本节点通过精确坐标映射到这些边。
- 跨断言边：只有特定输入槽位经实际 V 消息影响当前决策且语义槽位对应成立时，才升级为带机制见证的历史依赖。

这里的图承担候选搜索、对照匹配和消息干预。额外加一个可训练 Graph Adapter 并不能自行解决“这条约束属于谁”的监督来源问题，因此当前先检验上述图审计器能否生成可靠的归属与采纳证据。

## 约束归属怎样得到

v3沿用Qwen3-8B抽取一个谓词事件的角色框架：主体、谓词、客体、起点/终点、阶段时间、条件、数量单位等均绑定原文最小跨度。指代另外绑定先前原文，不把补全内容当事实证据。Python编译器逐个遮蔽原句中的目标角色，保留其余完整原文条件；非目标指代在问题副本中展开为已绑定的先前原文。没有被角色抽取覆盖的字词仍作为显式条件，不能当作无关修饰丢弃；隐藏值和已知指代别名不能出现在条件中。例如隐藏duration时，问题保留subject、predicate与所有其他条件，而不带入错误或正确的duration候选。

这些规则受到[FActScore](https://aclanthology.org/2023.emnlp-main.741.pdf)的原子事实分解、[DnDScore](https://arxiv.org/html/2412.13175v1)的目标/去语境条件区分、[D-FActScore](https://aclanthology.org/2024.findings-acl.160.pdf)的同实体联合支持核验启发；具体角色编译与内部消息验证是本项目待测的设计，不是文献保证。

纯角色JSON问题在v2中造成大量自答错位；v3改为完整原句mask加单独条件表。每次来源问答必须按条件角色键逐项返回对应引文。相同文字可位于不同角色，引用绑定原始角色的精确坐标，sidecar摘要与问题哈希均校验。漏项、重复角色、把另一角色的值填进当前角色都降为不确定。非目标前提尚未成立时，不能把整个事件不匹配简化为目标值“来源未说明”。自问自答仍独立检查抽取是否忠实，不能仅凭编译器字符串检查认定语义完整。
再进行两个无会话状态、彼此不看到答案的 source QA：均只能看完整来源与问题。
输出需要给出各项条件到原始证据引文的对应表；仅有相同数字或实体不算覆盖。

随后比较回答答案与来源答案，输出 E/C/N/U 的条件化分数：支持、冲突、未说明、不确定。
这些都是 reader 的估计，不是标注真值。C 的替代答案必须来自精确来源引文；
N 使用固定的两种保留判断表述，不虚构一个“正确答案”。
不完整问题、缺失条件、相互冲突的来源解读、无效编辑都会保留为无法判定。

这一语义层给出“应检验哪个约束”，不决定 native 回看候选的位置。
其最关键的实证问题是覆盖率和误判率；当前没有“内部状态单独足以确定归属”的结论。

## 回看位置怎样自动寻找

对当前答案构造两个完整续写事件：原回答 B，以及只改该槽位的替代 A。
目标是 F = log P(B 完整续写 | 共同前缀) − log P(A 完整续写 | 共同前缀)。
不只比较首 token，也不以平均 log probability 抹去事件长度差异。

仅在两个事件的共同前缀 query 上干预；两个后缀均重新前向计算。
搜索从 source/history 内容、角色路由、MLP 的 native 分组出发，按原生有限效应探索 key/query 二分及非相邻 query 并组。
所有已测父组与失败记录保留；搜索不接收 reader 选出的证据或适用性标签。

因此输出可能是一组 query/key/layer，而非唯一 token。保留未搜索分组数量和预算中止状态；
没有独立的回看节点真值，就不能把效应检出率写成节点定位准确率，更不能承诺 100%。

## 怎样区别关注、传入和采纳

位置效应首先要求：原位 sham 精确相同，完整/半强度方向一致，重复结果一致，
并且效应相对于两个结构匹配且语义无关的固定对照足够大。
对照池在看到对照干预效果之前冻结，失败不能换另一组重试直到通过。

随后验证信息来源：仅缩放某个原始输入片段的 embedding，重新运行 donor，
捕获选定位置的实际 V；recipient 只替换这些选定消息，其他计算重新进行。
这区分“影响来自这个 key 位置”和“原始文本片段的信息确实经这些消息传入”。
对照窗口匹配同角色、长度、embedding 范数及因果可达性；短答案也能有等长对照。

在此基础上分别检查：

- 不适用来源被采纳：该来源属于另一条件，其原始输入经消息介导支持当前错误事件。
- 历史与当前适用证据竞争：固定被移出的历史注意力质量，将目的地换成适用来源，再与无关目的地比较。
- 证据与 MLP 作用相抵：测量 evidence 保留/移除 × MLP 保留/移除的四种状态及交互项；同时分解答案槽位和其余上下文的效应。范围过宽或上下文占主导时降级，不称为局部信息汇聚错误。

“关注较大”“entropy 较大”“单独移除后答案变化”都不能单独成立上述结论。
本方法也不据此声称所有路由已正确或发现唯一原因。

## 连续错误与分段

当前答案槽位必须映射到前一句的某个具体问题与答案槽位，主题相似不够。
历史来源干预对准该先前答案槽位；只有前后均估计为不受来源支持、槽位延续/推导关系成立、
且该先前输入经消息正向支持当前错误事件，才标记为错误延续。

正确恢复样本作为单独控制：后一句可以依赖前一句错误，但本身已经纠正。
未获得槽位对应或输入介导见证的情况仍是普通条件历史依赖。

当前图保留跨 span 边，不把滑动窗口外的信息截断。
但它尚未提供一个经实验验证的任意长度幻觉范围分割器：
不会把两端之间未测的词全部涂成错误，也不会把“没测出依赖”直接视为无关句开始。
需要用自然批次实际观察边覆盖、错误延续漏检与正确恢复误报，再决定分段模块的下一轮结构。

## 已阅读方法对本结构的具体影响

- [QAFactEval](https://aclanthology.org/2022.naacl-main.187.pdf)：把问题生成、来源回答和答案比较分开。当前增加隐藏答案、条件引文表、两次独立来源解读及精确单槽位事件，避免把正确性判别直接变成相似度比较。
- [FactGraph](https://aclanthology.org/2022.naacl-main.236.pdf) 与 [GraphCheck](https://aclanthology.org/2025.acl-long.729.pdf)：事实结构和关系能够组织核验；本实现进一步把文本关系映射回原模型消息，图中的语义边本身不作为内部采纳证据。
- [ALTI](https://aclanthology.org/2022.emnlp-main.595.pdf)、[DecompX](https://aclanthology.org/2023.acl-long.149.pdf)：关注向量变换、残差和完整信息混合，而非把注意力大小直接解释成文本归属。当前最终证据来自实际模型的有限干预与原始输入介导。
- [EAP-IG](https://arxiv.org/html/2403.17806v2) 与 [Attribution Graphs 方法](https://transformer-circuits.pub/2025/attribution-graphs/methods.html)：可用于定位候选计算路径。当前不把候选归因当作有效机制结论，仍保留实际 sham、对照、非线性交互和范围限制。

这些是已阅读文献带来的设计选择；不是“这些论文已经证明本方法有效”，也不是已完成的查新结论。

## v3 解析与覆盖记录

读者原始输出不 strip 或补全。允许完整 JSON 根后的已观察尾部标点或代码围栏，并逐请求记录 strict/recovered；不完整根、重复键、第二根和文本尾巴均失败。达到生成预算或上下文预算一律计为失败，不算恢复成功。A/C 冻结工件和最终 merge 保存请求次数、缓存次数、各种失败数。边界处理不赋予回答真实性。v1/v2 零实际干预已证实语义入口是当前瓶颈；v3 是否突破仍须实测。
