## 1. 现在可以下的结论

**内部存在可判别的逐头模式，但尚未得到能无标签确定真假方向的通用机制。**
问题已经缩小到：候选内容被读取之后，其对象、阶段、范围约束是否一起影响当前选择。
“很少看 prompt”“更多 self”“存在正负竞争”“缺少某个直接条件边”都不足以判错。

## 2. 重采样实例究竟支持什么

原reanchor采样为4题×4seed，共16条Llama-3.1-8B回答；猪里脊题四条拒答，
不是四条正确烹饪推理。后续重点是服饰14315、bratwurst/洋葱14375的局部事实槽位。
两条前缀的正误差异受措辞和历史影响；相同题目不代表相同计算状态。

服饰自然面板，L22H28/L23H6读cap的质量，有依据侧 .63281/.37305，
无依据侧 .04736/.03247；但两头prompt总质量两侧都约 .96–.99。
同次回放的最终单头evidence支持分别为 .71615/.76497 和 .34098/.56054。
这些数字不同于局部lens读数，不能混为一张“因果贡献”表。

定点来源拆分显示，两个中层head联合删除普通帽子描述，对自然面板margin影响
为 -1.4041/-0.8859；只删限定语为 +.0012/+.0258。来源位置的V已经上下文化，
所以“直接删限定语影响小”不能推出模型没有编码限定语。

L31H14在两侧的self attention同为 .99609375。只删self，margin变化为
-1.13639/+1.84030；只删近10词或远历史接近零。当前query是最后一个已经输入的词，
不是即将生成的词；它也可能已经在前层融合过历史。该结果只排除了这个head的
强效应主要来自其当前直接远历史边，不能排除更早写入。

中层两个head联合干预的余项跨四个服饰面板有正有负，未得到稳定协同。
指定下游head恢复未重现大部分中层效应；某些MLP重算具有补偿作用。
无依据自然面板的候选margin没有翻正。单数面板曾出现首子词margin翻转，
但正确候选概率下降、整段margin仍为负；不能称为改对答案。

最新condition/value包实际测试72个head×面板记录（12头×6面板），不是6,144个全部头。
以 |condition|≤.02、value>.02 描述“值位置效应明显而条件位置效应小”，
服饰自然有依据/无依据为1/3个head；单数面板4/1，方向不稳定。
烹饪两侧均0。阈值改变会改变计数。这个直接边现象不是错误专有的“部分绑定”。
condition和value同时正向也不证明语义绑定正确。

## 3. 必须先修正的计算对象

### 当前步互补质量不能作为self动态的独立解释

每个head的互斥分区记为S（source）、P（其他prompt）、H（过去历史）、D（self）。
完整行满足 S+P+H+D=1，因此：

    ΔD = -(ΔS + ΔP + ΔH)

旧回归正是使用右边预测左边。稀疏保留质量为R时，残差额外混入ΔR，
加上量化、正则化、首预测行query与prompt重叠，不能把它解释成事实grounding失配。
这不表示原数据所有残差必然为零，也不推翻其已报告关联；它否定了该目标的机制解释。

已改为只用t-1的逐头路由预测Δself_t，明确降为过去路由预测基线。
新增retained_mass_change供检查；首行query从prompt分区排除；不读取自然错误标签拟合，
先写完所有无标签分数，后追加评价标签。v1模型不允许续跑到v2，新输出单独保存。
这个修正不是一个已验证更强的检测器，本轮没有重跑自然cache拟合。

### 相加必须用同一线性读出方向

原消息保持原模型计算：

    m[l,h,j→q] = W_O[l,h] (A[l,h,q,j] W_V[l,h] LN(x[l-1,j]))

逐head保存route mass、value norm、write norm。W_V/W_O不脱离实际A和输入状态单独当特征。
旧局部lens删除量L(x)-L(x-m)经过norm，不能逐头相加再称精确竞争。
v2新增同一位置的FP32局部lens梯度g，保存 c_h=g·m_h；Σc_h=g·Σm_h。
它是局部一阶方向读数，不是跑完后续网络的最终效应。
原finite-lens字段保留，旧结果报告明确标为不可加。

真正的有限干预用最终M计算 D_A=M_full-M_-A。两头四世界的交互为：

    J_AB = M_full - M_-A - M_-B + M_-A-B = D_A + D_B - D_AB

跨层联合删除时，下游消息在已干预状态重新计算，J包含整个后缀网络的非线性，
不是头之间直接物理相互作用或语义协同的自动证明。不能将D_A简单相加当路径贡献。
每个比较同时保存首子词与整段候选margin，后者仍受候选长度与措辞影响。

## 4. 收敛后的唯一候选检测方向

**检测对象是“候选所依赖的对象—阶段—值绑定，与原证据允许的绑定是否一致”。**
图保留层、位置、head、来源身份和有符号写入；GNN深度不冒充Transformer层。
首错、延续、恢复分别评估，但不根据金标分三套推理流程，也不以高熵筛选检测词。

选择这个方向的依据是：错误可能确实从source复制了值；地址质量、值写入和适用性是不同问题。
它是有针对性的研究假设，现有两题没有证明这一机制普遍发生。

落地顺序只保留四步：

1. **功能测量**：现有native算子取得逐head有符号消息；把condition、value、self、
   近/远历史拆开，先检查同一前缀中的读出及四世界交互。本轮实现到这一步。
2. **适用性读出**：保持值与词面，独立变更对象/阶段/范围，另做只变值的2×2控制。
   学习目标来自程序构造的合法关系，而非自然幻觉标签；称为任务关系自监督，
   不能宣传为完全不使用任何语义监督。需留出模板、实体、措辞和自然来源。
   原生Q/K/V和MLP替换用于检查该读出是否确实随适用性而变，而不只是认出数字。
3. **唯一评分**：从内部状态/消息得到联合绑定分布Q_t(z)，从独立来源关系得到合法集合Ω_t，
   用 -log Q_t(Ω_t) 衡量约束不相容。复用 `binding_detector/projection.py` 的现有投影，
   不再新增一个熵+异常+传播的加权分数。必须使用联合分布检验head关系，不能默认独立相乘。
4. **冻结后自然检测**：合法关系的提取、Q读出和检测阈值冻结后，覆盖完整token流。
   若关系不完整，用已有投影的unknown质量与上下界，不能把未知关系当错，也不能只报告可解样本。

目前步骤2的可靠自然适用关系提取、Q的可迁移联合读出都没有完成。
因此现有`binding_detector`只有评分数学，不能从attention或人工两案例角色表直接变成检测器。
本轮没有伪造source匹配、把测试标签训练的LDA方向转称自监督，也没有启动随机错接任务。
在这两项未解决前，报告应叫机制测量或路由预测基线，不能叫完成的无监督绑定检测。

必要对照固定为：只看值、只看条件、独立head与联合head、去历史、纯过去分数；
同前缀的原样/同世界替换、措辞控制及等范数随机干预继续使用已有focused模块。
先看当前词新增信息、首错召回、恢复误报，再看全词AUROC/AP和图增量。
监督CHARM/LDA只作信息可解码的上界诊断；测试成绩不参与选头、方向或阈值。
混合无标签校准仅给出异常预算，不保证正常token的真实5%FPR。
旧test已反复探索，后续确认需要独立来源。

文献只提供实验范式，不保证此方法有效：[状态追踪](https://arxiv.org/abs/2503.02854)
在受控任务中识别不同内部算法；[潜在算法路由](https://arxiv.org/abs/2607.24471)
用干扰不变性与定向激活干预检验受控模型的路由变量。不能据此声称自然RAG幻觉已被解释。

## 5. 实现与运行

graph负责检测与评价；reanchor负责原始采样、cache及机制输入。共享原始token ID，
不重新生成16条案例，不移动/覆盖已有8B状态或自然结果。

```bash
git pull --ff-only origin main
python -u -m experiments.path_conflict.flow --output outputs/evidence_target_flow_v2
```

默认读既有reanchor样本；v2逐样本保存NPZ并复用完成的干预。
head候选仍由基线局部lens选择，保持可比较；配对从共同线性方向选择，
在干预前写入pair_plan。默认每来源组最多2对，`--pairs-per-group 0`可只跑单头。
这是2题机制实验，不能输出自然检测AUROC。完整候选评分比v1首词评分多运行候选后缀。

仅修正后的CPU路由预测基线（需服务器原attention缓存与tokenizer）：

```bash
python -u main.py population --phase grounding --resume
```

写 `outputs/ragtruth_evidence_flow_v1/past_route_forecast_v2/`；不覆盖旧grounding_dynamics。
population的all只跑screen/confirm/report，不再自动启动另一套无标签回归。
已有熵/复用方法通过 `python main.py unsupervised ...` 显式运行，作为历史基线。
已有HMM通过 `python main.py regime --phase all --resume` 显式运行；算法来自本轮之前的main，
此次仅统一入口，不声称新实现或已有自然成绩。
`python main.py` 现在显示入口，不自动启动大模型或训练。

本轮复算命令（无需GPU）：

```bash
python scripts/review_convergence.py \
  --grounding <旧grounding_dynamics目录> \

  --output outputs/convergence_review.json
```
