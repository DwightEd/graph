# 真实决策窗口：来源归属、跨层采纳与连接对应

2026-09-12。本轮执行三组真实8B实验并据结果追加对照，未训练检测器。
当前可支持的窄结论是：这组实际窗口中的来源数值选择可由内部内容/连接干预定位和
改变，而且单层与跨层的充分性不同。**合法动作归属的自动判别仍未验证。**

## 1. 来源数值与历史分开后，错误跟随哪一处

源位置76是“取出香肠前继续煮10–12分钟”的上界12；位置341是“烤制10–14分钟”
上界14。实际错误回答把10–12附到取出香肠后继续煮洋葱。来源没有给这一动作唯一
合法时长，1–2分钟属于另一种黄油煎洋葱步骤；**12改成14也不是纠错。**

首轮同时交换来源两值S，并独立改此前回答中的14→12（H），共4输入世界、
64单层X/E/XE/MLP条件和4sham。错误窗口来源主效应+17.75、历史+0.875；
正确grill来源−13.125、历史0。此处两来源同时变化尚有混淆，故第三轮将两者独立。

第三轮A只改位置76的12→14；B只改位置341的14→12；H只改各seed已有grill上界。
四个seed各8世界，共32。下表为00012、H保持原文时的固定候选差 z(14)−z(12)：

| 来源条件 | 正确grill t99 | 错误onion t131 |
|---|---:|---:|
| 原始 | +7.125 | −10.375 |
| 只改A：取出前上界12→14 | +7.375 | +9.625 |
| 只改B：烤制上界14→12 | −12.125 | −7.000 |
| A、B同时改 | −6.000 | +7.875 |

错误onion在全部4组A配对中原生首选12→14；B配对与H配对各0/4翻转。
正确grill的B配对在每个seed均4/4翻转，A和未来H各0/4。它们是配对机制计数，
不是正确率；A/B单独编辑会改变数值多重集合，同值条件不具有两值竞争。

错误onion全8世界平均A效应+17.71875、B+0.03125、H−1.65625。
**B均值接近零不代表无作用：**其条件效应范围−3.25到+3.375；H为−5.25到+1.375。
首轮H均值来自A=B子集，与本轮全因子平均不同，不能把历史效应假定为固定方向。
完整分布配对JS平均：A 0.686935 nats，B 0.002213，H 0.002134。

对照没有被隐藏：正确洋葱t126在原始前向中“ in”与“ over”并列最大，来源交换后
“ over”单独最大；这不是数值错误/修复。其A/B/H平均JS分别0.004776/0.004144/
0.007129，均有1/4原生argmax变化。未修改的simmer20和另一grill10在24个对应
来源/历史配对中均无argmax变化；它们的最大JS分别约1.02e−5与8.75e−4。

## 2. 跨层内容有效，不能由单层弱效应否认采纳

第二轮固定两个层组（4层/全部32层）、三个范围（最终query/当前窗口/此前所有
生成query）、四因子，加逐节点only-one和leave-one-out及动态端点交换，共98条件。
下表为全部32层，仍报告同一 z(14)−z(12)：

| 干预 | 正确grill | 错误onion |
|---|---:|---:|
| 原始 | +7.125 | −10.375 |
| 只在最终query换source V（X） | −8.000 | +6.875 |
| 当前窗口所有query换X | −9.000 | +8.125 |
| 此前全部生成query换X | −9.125 | +8.000 |
| 最终query换source内连接E | +7.750 | −10.500 |
| 最终query同时换XE | −3.250 | +5.500 |
| 最终query换MLP更新 | +1.875 | −1.750 |
| 最终query动态交换两个数值端点的A | −6.375 | +7.375 |

X/XE/端点交换改变了原生首选；MLP明显改变候选差但未翻转。E来自仅换数值的
捐赠世界，并保持接收方每head/query总source质量，其弱效应不等于连接无用。
动态端点交换直接改变本次实际A在76/341两端点的对应，V不变、总质量不变，
两窗口都翻转，支持这些端点对应在此计算中的作用；不证明GNN优于非图。

追加对每个零基层0–31各单独做最终query X，两窗口共64条件。**均未翻转**。
最大绝对影响均在第16层：grill候选差改变−3.5，onion+3.125。
结合全32层共同干预可翻转，说明在这套干预下单层不充分、联合充分；不宣称
各层可加、所有层都必要，或所有幻觉都具有相同机制。

## 3. 精确到哪个query，是否已经找到了唯一回看点

00012正确grill上界为预测t99，实际作用于输入query633（response t98）；
错误onion上界为预测t131，作用于query665（response t130）。两者均是“10 to ”
后面的空格状态。空格节点能承载上下文计算，不能仅因词形像分隔符就丢弃。

对各窗口全部7/13个query分别做全层X：仅最终query单独干预能改变最终数值首选。
从完整窗口干预中去掉该query，候选差回到+5.875/−8.750（原首选方向）。其他
query有较小作用，例如t97对grill改变−1.125、t129对onion+1.5，不能说它们无贡献。

这是已知端点、已知捐赠反事实下的局部充分性/条件必要性证据。它表明不必先假定
“唯一更早节点选错，此后只照抄”；不证明最早路由筛选发生在这里，也不排除更早
状态改变了此处query。**自动回看定位和100%定位仍未验证。**

## 4. 对下一版方法的约束

属性图应保留节点高维内容与端点对应，边的消息为逐head的A×V，经O投影后进入
残差，再经MLP和后续层采纳。风险判断需要检查源约束的对象、动作与阶段上下文
是否与当前动作一致，不能只检查数值来自source、attention大或生成低熵。

目前证明了“来源数值身份可干预辨认”，没有完成“合法归属可从图自动读出”。
下一项明确为：**数值保持不变，只交换动作/阶段归属**，保持当前真实查询前缀，
在内部高维关系表示上比较X、E、X+E及保持权重分布的端点置换。它用于分离
“数值复制可辨”和“关系合法性可辨”，本轮未执行。先冻结此读出，再扩至独立来源；
没有这些证据前不训练复杂Graph Adapter、不宣称自监督图已经解决幻觉。

自适应span仍应是完整图上的分组，并保留跨span边；本轮没有评估自动语义分段、
连续错误终点或新的检测性能。旧residual AUROC0.4361 vs entropy0.8442的负结果不变。
