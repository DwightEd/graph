# 目标条件化的 reanchor 审计设计

目的：检验关键事实前是否存在自然回看位置，以及当前所需的值与适用约束是否经该位置进入、传递并影响事实选择。两个重采样问题用于机制试验，不用于报告检测 AUROC。

## 文献采用边界

- [FlowTracer / How Does Reasoning Flow?](https://arxiv.org/html/2606.10646v1) §3.1：反向计算答案可达势 h，再用 W(i,k)h(k)/h(i) 做条件化，最后**前向**传播流。采用目标条件化和中继筛选；不把非负流量命名为事实支持。原论文跨层、跨头聚合后的 token DAG 不是原生逐层计算图。
- [Information Flow Reveals When to Trust Language Models](https://github.com/rxu0112/RAG-information-flow/blob/main/Information_Flow_Reveals_When_to_Trust_Language_Models.pdf)：区分模型实际来源和独立相关性参照。当前先用人工核验的来源角色，不能让 attention 自己定义正确证据。
- [Attention Illuminates LLM Reasoning](https://arxiv.org/html/2510.13554v2)：回看与后续复用用于定位候选；未来影响是回顾性测量，不冒充在线检测。

现有 `experiments/flowtracer/flow.py` 在条件化后从 target 逆向传播，不能直接充当原论文的前向守恒流实现。本轮新增层序明确的审计入口，保留旧模块及历史结果。

## 本轮图与读出

节点是 `(layer, position)`。attention 消息边从 `(l,j)` 到 `(l+1,r)`，保留物理 head；残差另设同位置边。禁止在同层图上反复跳跃。MLP 是逐位置运算，图中没有跨位置 MLP 边，实际有限干预仍执行全部 MLP/norm。

主要路径筛选使用原生 attention 容量，残差容量为 1，所有入边除以 H+1。这个等通道容量是分析约定，不是精确的模型贡献分解。另保存使用 `A*||W_O V||` 和真实残差范数归一化的结果作敏感性对照；两者都不能判定消息的支持或抑制方向。

每层、每头、每 receiver 保存 attention 最大的 k 个来源、原始 route mass、V 能量和 W_O V 范数；同时保存完整 attention 上计算的回看增量。稀疏化不重新分配丢弃质量，报告每行保留比例。该图只能追踪保留的边；不存在保留路径不等于原模型没有路径。

终点是人工核验事实候选出现**之前**的最后输入位置 q 的最后层状态；不把候选 token 自身的表征误作预测它的状态。完整候选概率在原生模型中另行评分。节点与路径选择不使用支持/不支持标签、来源角色或候选梯度，但终点仍为人工声明位置，所以是标签辅助审计。

对于层序图：h[L,q]=1，其余末层势为 0；h[l,j] 为所有保留后继边的容量乘下一层势之和。前向边流为 `f[l,j]*capacity*h[l+1,r]/h[l,j]`。

不能把所有弱来源在条件化后强行放大成同样重要。主分析给所有输入 token 相同先验，再按到终点的势加权，根流为 `h[0]/sum(h[0])`；另计算可达根均匀注入对照，明确它更接近原论文的注入约定。根包含 prompt 和已生成回答，不能预先排除历史根。保留原始势和条件化前的总可达量。

## 回看候选和对照

在每个 head 内，比较 r 与 r-1 对**相同**远端来源集合的读取：集合包含 prompt 和 r-window 之前的历史，排除特殊 token。不会因 local/far 移动边界人为制造增量。

候选为 `receiver < q` 的正回看增量位置的实际跨位置消息，按其到该事实终点的边流排序；这是候选，未经因果检验不叫成功重锚。q 处直接读取作为独立对照。每例保留少量不同 `(layer,head,receiver)`，同时保留相同层/head、接近位置与回看距离的低流对照。匹配失败记缺测，不扩宽条件。

另列最高流但无正回看增量的位置，避免把“存在回看峰”预设为所有中继的必要条件。完整逐位置图、所有候选排序都保存，不能只展示选中的成功例。

来源角色在选取之后附加：`scope`、`supported_value`、`value_source`、其他 prompt、已生成历史及 self。每个被选节点分别检查这些真实来源在相同 head 中的作用，不把 role token 数或话题相似度当作适用性。

## 原生验证

输入消息 E 写入 `(l,r)`；后续候选消息 B 从同一位置 r 的更深层状态读取，且写向 `s>r`，保证是真正跨位置复用。没有这样的保留边则报告该节点的 relay 未测；仍测 E 的单独作用。

所有世界保持同一前缀、候选及 teacher-forcing 文本，分别保存候选逐 token/总和/均值/首词/尾部概率。

| 世界 | 改变什么 |
|---|---|
| full | 原始执行 |
| cut_E | 删除 E，可用 .25 与 1 剂量 |
| cut_B | 删除后续读取边 B |
| cut_E_B | 两者一起删除 |
| restore_R | 删除 E 后，恢复 `(l,r)` 的原层输出 |
| restore_R_cut_B | 删除 E、恢复 R，再删除 B |
| restore_B | 删除 E 后，仅恢复后续消息 B，不恢复其余改变 |
| shams | 原消息、原 R、E+B 联合原消息恢复，各自独立执行 |

恢复 R 是同一 candidate 分支、同一序列形状下的基线，不跨分支复制。恢复紧邻 E 的整个状态应抵消 E 的局部扰动，这是执行控制，本身不是语义机制发现。

记录 `gain_open=F(restore_R)-F(cut_E)` 与 `gain_blocked=F(restore_R_cut_B)-F(cut_E_B)`。由于完整状态恢复的执行恒等式，两者之差在数值误差外必然等于四世界交互 `F(full)-F(cut_E)-F(cut_B)+F(cut_E_B)`；它们不是两条独立的机制证据。更有信息量的补充是 `F(cut_E+restore_B)-F(cut_E)`：入口被切断时，只恢复特定后续消息的条件效应。非零效应也不能证明 B 是唯一中介。另保存 E/B 单独和条件效应以及非加性，不预先命名协同/抑制。

每个候选还删除独立核验的 scope、supported_value、value_source 子消息，以及 scope+supported_value 联合消息。它们跨 head 的信息分布仍需逐头解释。等范数随机方向仅为扰动幅度对照；不充当语义 donor。

## 当前案例的语义限制与下一步

头饰的自然两侧语法、前史不同。洋葱的“低火”与“10–12 分钟”比较不同属性；这两组原候选保留用于复核，输出标明 readout 限制，不称真值检测。

后续语义确认必须固定载荷和句式：普通人/统治者的佩戴范围，以及同一 10–12 分钟属于移除前/后；同关系改写与关系改变分别作对照。不能用自动生成的未核验模板冒充自然正负例。本轮代码先闭合路径筛选及原生切断/恢复试验，语义反事实普遍性仍待新实验。

来源角色与物理 Q/K/V 是两套区分：scope 的文本不自动等同于 K，value_source 的文本也不只进入 V。本轮干预的是该来源在当前 head 的完整 `A·V·W_O` 子消息。下一阶段的 Q/K/V 交叉替换需要同槽位、同载荷且已核验的 donor，才能分开检验寻址改变、载荷改变及二者配合；现有自然两侧不能直接视为这样的 donor。

## 验证门槛

1. 枚举微型图的合法逐层路径，核对 h、边流、末端流与守恒；同层路径、断路和弱根不能伪造贡献。
2. 真实小型 Llama 检验 hook 透明性、GQA、稀疏保留量、候选分支恢复、联合 sham、层末状态恢复，以及最后层过去位置不能直接影响后续位置。
3. 真实上传包只用于输入覆盖与已存结果复核。缺模型权重或 attention 不制造自然图和机制结论。
4. 按 source 报告探索性结果，保留无候选、无中继、控制失败和匹配失败的分母；不训练检测器。

## 代码结构

`experiments/reanchor_audit/`：inputs 读取原配对缓存；capture 逐层采集原生量；graph 做稀疏层序流；selection 选候选、对照及后续读取边；trials 执行缓存化的原生世界；report 导出原表与图；run 顺序串起入口。复用 `path_conflict` 的 native/scoring，不改旧实验协议和缓存。

## 本轮实际执行

- 32 项针对性测试通过：包含微型图独立路径枚举、真实随机初始化 Llama（3 层、4 个 query head、2 个 KV head）的捕获透明性、完整分支恢复、独立联合 sham、后续消息恢复、缓存续跑，以及从发现到图表报告的完整流程。环境为 PyTorch 2.6.0 CPU / Transformers 4.57.1。
- 上传配对缓存预检：2 个 source、4 侧前缀。头饰 prompt/prefix 为 434/469，洋葱为 535/661。候选长度分别为 10/11 与 3/7 token。
- 此环境没有原 8B 权重，上传审阅包也没有新路径所需原始 attention。自然样本的新图数和有限干预数均为 0，4 侧基线检查为未测。没有将软件测试输出当作自然机制证据。
- 本轮没有运行检测训练、RAGTruth 全量泛化检验、干净的语义 donor 或 Q/K/V 交叉替换实验。下一步在原环境运行本入口，按真实图与有限干预结果决定哪些节点值得做语义反事实。
