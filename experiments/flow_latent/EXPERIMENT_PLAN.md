# 实验规划

问题：无监督每 token 的内部表征与真实内容连接是否支持幻觉检测？方法详见先行 METHOD_DESIGN.md。

| 主张 | 最少证据 | 实验 |
|---|---|---|
| C1 真实连接在节点表征之外提供定位信息 | 同数据 node/rewire 对照，两项 source bootstrap ΔAUC CI>0；答内定位不下降 | B2–B4 |
| C2 多跳路径改善错误起点，而非仅延续 | v2与v1首词/正常答报警对照；source CI支持收益 | B3 |

B1 MUST：软件科学契约（因果索引、S+H+O重构、路径逆算子、乱边匹配/质量、EM密度与无标签输入），真实8B canary。通过才训练。
B2 MUST：原17回归答（14旧例+12297/12471/17199）+12旧source隔离reference；另SHA(flow-latent-fit:id)选择train Llama2-7b 8来源/任务=24 fit，长度<=1536且与其它来源互斥。reference用于阈值，不参与拟合；每token全流评分、冻结后只读取17答标签。
B3 MUST：预定 v1→v2→v3，所有版本/失败都保存；三seed42/43/44只改变 EM初始化。reference 无标签条件NLL可诊断数值，不能自然标签选模型。单GPU一次捕获，后续CPU学习。
B4 MUST：AUC/AP、回答内AUC、3任务分开、首错命中、错段token召回、正常答any-alarm、source bootstrap真实图−node/rewire。保留 observer NLL 基线，旧fixed仅能独立注明输入不同，不能混做同输入因果增量。
B5 MUST：数值与标签泄漏核验、逐词可视文本报告；共享tracker/结果/失败下一步。无全量盲测/无论文有效性声明。

预算：53个8B完整前向（+canary若必要），RTX4090单卡，预计<0.5GPU小时，原始向量及完整attention约10–40GB；CPU模型7种×3seed，预计<10分钟。训练来源不保证正常，不读其真假标签。17例已反复研究，只是探索开发回归。

继续门：真实/乱边重构与配对契约通过；条件模型有有限density、nonempty状态且数值目标可解释。检测失败时仍完成预定单次机制修改v2/v3，然后停止本轮加模型复杂度，记录具体漏词与方向缺口。不会反转分数方向寻找成功。

实现顺序：设计→本计划→prepare/capture→模型/科学测试→v1评分冻结与评价→v2冻结评价→v3冻结评价→三seed稳健性→审计交付。阈值、输入、代码哈希存储原始输出；共享文档采用版本化固定别名。无需人工标注/上传。
