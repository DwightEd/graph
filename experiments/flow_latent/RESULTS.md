# Flow latent：实际结果与裁决

2026-10-07。独立子项目已按设计→规划→实现→回归→迭代执行。53个原生8B forward，21次条件密度拟合（每次含node/native/rewired三个模型，共63个模型；审计后追加3个同容量节点历史对照，共69模型（含绑定修正的3次重现）），保留初轮、数学修正和保真度追加结果。未建立有效的无监督幻觉检测主线，完整attention行Dirichlet生成模型仍未实现。

## 数据与边界

24个来源互斥fit回答（4120 token）训练所有PCA/协方差/混合参数；12个reference回答仅用于分任务95百分位阈值；17个旧回归回答用于最终标签评价：QA10、Summary3、Data2txt4，2968有效token、265标注错误token、16个错误起点、6个正常回答。训练不筛选正常文本，reference也不保证全正确。这些例子已被多轮研究，属于探索开发，不能称独立确认。

每个token独立输出风险、4态categorical posterior；修正版还输出各状态下4维（高保真版8维）Gaussian factor posterior。没有组均值风险广播、HMM、真假分类器、按gold挑头/簇/方向。Dirichlet是全局混合权重先验，后验状态不等于真假概率。

## 决定性的结论

1. **相对低参数节点模型的增量有容量混杂，真实端点增量未确认。** 较高保真版三个seed真实图−node的source bootstrap 95%区间分别为[0.02644,0.14789]、[0.00106,0.11909]、[0.00130,0.14130]，但真实图−乱边分别为[−0.01273,0.00956]、[−0.01393,0.00663]、[−0.01380,0.00645]。乱边也保留来源内容/词项/lag/head/质量，因此前者不能证明特定真实连接必要。乱边改变1.90–6.24%attention质量（均值4.21%），阴性对照有可辨性限制。

2. **多跳没有获得明确收益。** 固定低维一致MAP的v2平均AUROC0.558160低于v1的0.561305，首错未改善；不能把路径公式可解称作检测有效。

3. **密度异常仍不是事实错误。** 较高保真版真实图的3seed首错为1/16、1/16、0/16；全部6个标注正常回答均any-alarm。reference token95百分位没有正常回答级FPR承诺。高保真seed42错token召回43/265=16.23%，精度13.35%，回答内AUROC0.591832。

4. **初轮严重压缩，追加版缓解但未解除。** 原随机4坐标仅保留原节点协方差3.09%，后续PCA32保留其43.38%，合计约1.34%原节点方差。逐head fit-only top16保留59.76%，PCA128再保留75.60%，合计约45.18%，以上均为fit来源内方差。冻结节点子空间在reference保留29.61%、regression保留31.01%原方差；消息方差保留率未测。这是协方差方差比例，不能等同语义信息或事实决策信息保留比例；未检验全维似然。
