### Lag-pair causal and capacity contract

`lag_pair` concatenates the complete current predictor with its immediately preceding predictor (`experiments/flow_latent/run.py:19-23`). Thus `t=0` duplicates the prompt-boundary state, `t=1` uses node 0 plus the boundary, and `t>=2` uses nodes `t-1` and `t-2`. It introduces no current/future answer token. The raw width is 32,768, equal to head16 v3 `root+other`; both use PCA128, four mixture components, rank 8, a 128-dimensional regression target, and 30 updates. The exact fitted shapes are coefficients `(4,129,128)`, covariance `(4,128,128)`, loadings `(4,128,8)`, and weights/noise `(4,)` (`outputs/flow_latent_20261007_head16_control_bound_seed43/diagnostics.json:547-564`). The frozen node projection is identical to native.

This is a **parameter-shape-matched** control. Its information content and effective complexity are not matched to `root+other`, and both representations derive from observer attention. Across all comparable transitions, the complete predictor reconstructs the preceding physical node with maximum relative error `3.37e-4`; the persisted four-case witness is approximately `2.14e-4` to `2.21e-4`. The control fixes the major node-only parameter-count confound but cannot by itself isolate native graph causality.

### Exact regression-retention calculation

The persisted calculation is implemented in `experiments/flow_latent/audit.py:126-154` and saved in `experiments/flow_latent/NODE_RETENTION.json:1-26`. For each cohort independently and for every valid token (i):

- (x_i\in\mathbb{R}^{131072}) is the flattened raw node tensor;
- (z_i\in\mathbb{R}^{16384}) is the per-head top-16 projection using the frozen physical-head axes;
- (u_i=z_iP^\top\in\mathbb{R}^{128}) uses the fit-only final node PCA axes, with no whitening.

For any representation (Y=\{y_i\}_{i=1}^N), the audit computes token-weighted, cohort-centered variance

\[
V(Y)=\frac{\sum_i\lVert y_i\rVert_2^2-\lVert\sum_i y_i\rVert_2^2/N}{N},
\]

then reports `head16_fraction = V(z)/V(x)` and `final128_fraction = V(u)/V(x)`. This is held-out regression retention, not fit-only PCA explained variance.

| reference | 944.122084 | 428.255469 / 45.3602% | 279.583773 / 29.6131% |
| regression | 1025.034860 | 479.796021 / 46.8078% | 317.849295 / 31.0086% |

Message, transported-value, and rooted-path retention are unmeasured. Node retention cannot be used as their retention estimate.
