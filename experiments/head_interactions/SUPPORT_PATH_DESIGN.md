# 从消息显著性到来源约束：下一轮实验设计

状态：2026-09-21 研究方案；本文件没有宣称新增检测器已经实现或取得成绩。
已有交叉项结果见 [消融复盘](../unsupervised_token_graph/head_geometry/CROSS_TERMS_REVIEW_20260921.md)。

目标是发现有检测增量的模式：当前事实选择是否依赖适用证据，多头写入是否保留同一证据的
值及限定条件，历史复用是否携带这种约束。无需先给每个 head 命名功能，也不预设混乱就是幻觉。
自然幻觉标签仅用于审计和冻结后评价。

## 1. 先区分可能的错误表现

|待检验表现|需要记录的观测|必须比较的正常情形|
|取到数值/实体，丢失适用条件|同一来源单元的 value 与实体、关系、否定/范围消息对当前选择的作用|正确复制也可能由很少几个头完成，条件不必在每个 token 上显著|
|选错来源或绑定错实体|输出相关消息来自哪些文档/字段/子句；值与限定条件是否来自相容单元|多个来源共同支持，以及检索到无关但词汇重叠的内容|
|存在竞争但错误选择占优|同一目标下头/来源的正负作用，随条件变化是否改变|正常纠错同样可能有强竞争，负贡献可能正是在阻止错误|
|复用缺少证据约束的历史|历史来源消息持续显著，但相关条件的端到端敏感度/配对响应不足|有证据依据的正常复述、长实体延续、语法补全|

这四项是候选解释，不是已有审计结论。特别是“条件没有在答案中出现”不能直接当作
“条件没有被使用”：条件可以只决定一次选择，后面正常地延续这个选择。
之前 L31 单个前缀位置的干预只影响候选首 token，不能用来解释整个事实 span 的支持或丢失。

## 2. 采用显著性思想，但保留目标、符号和 head 身份

[Hallucination Begins Where Saliency Drops](https://arxiv.org/html/2601.20279v1)
用 attention 与损失梯度的乘积绝对值构造显著性，并跨头聚合。
它提供同时读取多头的思路，但绝对值不能区分支持与反对，跨头聚合又丢掉身份。
该文主要研究 LVLM，且承认高显著性的幻觉反例，不能直接当作文字 RAG 的普遍规律。

### 固定读出

对生成的 y_t，输入是截至 t−1 的完整前缀，预测 query 是 q=t−1。
这里 t 是完整序列的绝对位置；若按回答内部编号，须加上 prompt 偏移。
同时保存 answer_index 与 query_position，不能将两种坐标混用。
审计每个指定目标时，保留所有 i≤q 的相关计算，不能只抓最后 query 的头。
主读出预先固定为生成 token 相对原生 top-5 非目标竞争 token 的 logit margin：

\[
F_t=\ell_t(y_t)-\log\sum_{w\in R_t}\exp\ell_t(w).
\]

R_t 在原生 forward 后选定并冻结，选择不经过梯度、不使用幻觉标签；保存具体 token IDs。
这是相对模型候选的读出，不意味着这些候选是事实上的正确答案。
使用 margin 是为了减少 log p 在高置信度时的梯度饱和混杂；
log p(y_t) 作为文献对照，在同一小审计集复核。两者不能按 TEST 成绩择优定向。
语义机制配对另用事先固定的两个候选，属于标签辅助审计，不能搬入无监督检测器。

### 一次反向读取所有消息的局部作用

定义层 l、头 h、query i、key j 的原生 post-softmax 消息：

\[
m_e=a^{l,h}_{ij}W_O^{l,h}v^{l,g(h)}_j,
\qquad e=(l,h,i,j).
\]

g(h) 是 GQA 的 query-head 到 KV-head 映射；v 包含实际模型的输入归一化和 V 投影。
在该消息上放置独立幅度门 α_e，不重新归一化 attention，则：

\[
c_e^{(t)}=\left.\frac{\partial F_t}{\partial\alpha_e}\right|_{\alpha=1}
=a^{l,h}_{ij}\frac{\partial F_t}{\partial a^{l,h}_{ij}}
=\left\langle\nabla_{r^{l,attn}_i}F_t,m_e\right\rangle.
\]

r^{l,attn}_i 表示 attention 在该位置写入残差的支路。也可在 W_O 之前计算：

\[
o^h_i=\sum_j a^h_{ij}v^{g(h)}_j,
\qquad c_e=a^h_{ij}\left\langle\nabla_{o^h_i}F_t,v^{g(h)}_j\right\rangle.
\]

因此不必保存每条边的 d_model 维消息，也不必逐头删除再运行模型。
c>0 表示局部增大这条消息会提高选定 margin，c<0 表示降低，|c| 表示局部敏感程度。
它不是删除效应、Shapley 值，也不是“事实为真”的分数。
源于无关词面的消息也可以强烈支持错误 token。

一次 forward/backward 得到**一个标量目标**的全部 head/消息归因。
对整段 logp 求和后反传，得到的是整段目标的混合归因，不能冒充每个 token 独立的归因。
逐 token 评价需要多次 VJP/反向；句子级可以定义整句目标并在句末检测，须单列延迟。
批量 VJP 也不等于免费；先测实际模型、长度下的显存和时间。

一阶梯度只给出 c。真正的非加性交互来自二阶及更高项：

\[
F(1+\delta)\approx F(1)+c^T\delta+\tfrac12\delta^TH\delta.
\]

所以本轮可观察同向、竞争及串联路由，不把它们直接叫因果协同。
若这种模式已经产生检测增量，再对少量预选头组用 Hessian-vector product 检查局部交互。
不先恢复全量逐头消融或全 coalition Shapley。

## 3. “从 prompt 一路支持”分成两个可检验问题

**连续计算上的相关性。** 完整重放前缀，保存每个位置 inputs_embeds 的梯度。
对 prompt 位置 j 记录 embedding 门控敏感度：

\[
r_j=\langle e_j,\nabla_{e_j}F_t\rangle.
\]

它包含该输入位置经过模型后续所有连续计算路径的局部响应，包括经过历史位置隐藏状态的路径。
按来源单元同时保存 Σr_j 和 Σ|r_j|，保留逐 token 记录，避免正负抵消被误读。
这只是 embedding 幅度方向，RMSNorm、方向正交等可令它很小；
另存 ||e_j||₂||∇F_t/∇e_j||₂ 作为相对输入扰动球的局部敏感度上界诊断。
二者都不是语义支持量，零门控梯度不能证明来源没有被使用。

**内容上的适用性。** 保持值及词汇尽量相同，只交换实体、关系、否定或范围条件，
检查预测和上述消息模式是否随适用性改变；再做只换值、同义改写、无关条件的对照。
只有这种对照能帮助判断当前显著来源是否是回答实际需要的来源，而不是碰巧相关的词。

不能沿层相乘 c_e 来造“支持流”：每条 c_e 已含到输出的梯度，乘起来会重复计入下游影响，
也不满足守恒。root 与 edge 分数同样不能相加成总贡献。
路径连通图只负责定位，连通不保证一路传递的是同一项语义内容。

历史生成 token 在重放时是给定输入；梯度不能穿过此前离散采样决定。
若有生成时的逐步归因记录，可另存来源关系的历史记录，但它不是可微因果链。
使用 detached KV cache 会进一步切断 prompt 的连续梯度路径，因此审计重放不能这样做。

## 4. 只引入有明确意义的结构先验

|先验|表示方式|需要防止的误用|
|真实计算依赖|节点用 layer、position、sublayer；attention 跨位置，残差和 MLP 支路单独表示|同层 heads 是并行写入，不画成 h1→h2；MLP 不因不跨位置就被忽略|
|来源及条件绑定|文档/字段/子句为单元，记录实体、关系、value、否定/范围的跨度及解析来源|地址不是内容；隐藏状态会混合来源，不能由 key 位置直接继承纯粹的内容血缘|
|有符号、可追踪的多头消息|先保存逐 head、来源、query 的 c，再按需要作读出|attention 大不等于作用大，统计 z 的负号不等于抑制，正 c 不等于真实支持|
|位置和持续性的对照|特殊 key、self、相邻历史、远历史、prompt 分开记录；因果历史窗口|不把所有局部头当噪声，不要求每步重新回看 prompt，不把正常复述当幻觉|

特殊 token 从“证据来源”统计中排除，但不修改原模型 forward；保存其诊断质量及归因。
旧压缩 attention 的零是阈值后的观测值，不能据此断言原始连接或贡献为零。
主检测的头范围继承既有中间层设置，不能根据标签挑选；根到输出的反向计算仍需经过完整模型。
若只保存部分层，明确这是部分路由图，不能声称恢复了完整支持路径。

自动抽取语义条件仍是待验证组件。优先使用数据集原有字段、文档边界和文本跨度；
未知绑定标成 unknown。人工角色仅用于机制审计，不进入自然样本 detector FIT。

## 5. 相关方法各借什么

- [Information Flow Reveals When to Trust Language Models](https://openreview.net/forum?id=vd8HzoFZ7v)
  的主要贡献图用去除来源向量后隐藏向量的 L1 距离变化，
  取非负并归一化，再跨层组合。它提示从输出反查有用路径；但已聚合 heads，
  且最终方法使用外部相关性排序和训练的置信度模型，不是现成的无监督 token 检测器。
- [ALTI-Logit](https://aclanthology.org/2023.acl-long.301/)
  中的 head/source Logit 分解（Eq. 8）将 OV 消息投影到输出 logit 方向，
  可作为 forward 型代理；这里借用的是该分解，不等于完整 ALTI-Logit 的跨层混合传播。
  直接 logit 分解不能代替后续 attention/MLP 重写后的总效应。
  本轮优先实现并核验一次反向，若其成本不可接受再评估这一代理，避免同时铺开两套未经验证的检测器。
- [RAUQ](https://arxiv.org/html/2505.20045v3)
  把 token 置信度与前一 token attention 的递推结合，应作为持续性思路的对照。
  原方法按完整答案选 head、输出回答级分数；在线 token 版本须改成 FIT 固定或仅用前缀选头，
  并明确它是因果改写版，不能偷偷使用未来 token。
- [Decoupling Positional and Symbolic Attention Behavior](https://arxiv.org/html/2511.11579v1)
  用位置与内容变换区分行为。借用证据子句的位置交换及语义保持改写，
  检查候选信号是否只追逐距离/词面；不据此给模型所有头永久贴角色标签。

这些工具辅助确定观测与对照，不自动提供“幻觉越混乱”的结论。
目前不需要先引入黎曼几何或训练大 GNN；结构对照若没有增量，换更复杂读出不能解释其有效性。

## 6. 实验顺序及否决条件

### A. 先解释已经得到的检测收益

读取 cross_terms review 中的冻结分数，不重新加载 LLM：做来源 bootstrap、答案内排序、
onset/continuation、匹配正常重复 span 和告警延迟。QA 的 raw+因果平滑成为强制基线。
Data2txt 同时保留旧 moment；任务分别汇报，不混合掩盖退化。

### B. 先验证显著性计算，再看自然样本

小模型验证 attention-gradient 与 head-readout-gradient 两种 c 计算一致；
用少量预固定 gate 的微小扰动复核导数，而非重新逐头删除统计贡献。
同时覆盖 t−1 对齐、GQA、特殊 token、因果 mask、hook 清理及 FP32 累积。
完整前缀与截断到目标位置的计算应一致；未来 token 不得改变当前归因。
整段目标归因与逐 token 归因明确分开，保存目标、真实 query 和所选竞争 token。

在实际 checkpoint 上先做少量目标的时间/显存试运行，结果只用于确定可运行规模，
不按标签选择“效果最好”的目标。不能由小模型测试宣布自然幻觉机制成立。

### C. 条件交换审计：头的作用是否随该用的条件改变

每个来源固定同一个问题和回答前缀，预先指定两个语义候选；改变的是 prompt 条件，
不再用两条不同生成历史的相同绝对位置冒充相同语义决策。
构造 value × applicability 的配对条件：只换值、只换适用实体/范围、同时换、都不换；
再加同义改写、证据位置交换、长度/词面匹配的无关条件变化。
每个变体的正确关系须在看模型结果前审核；缺少语义可对齐候选的例子报告排除原因。

检查 margin、逐头逐来源 c、root 敏感度是否响应必要条件而非无关条件，
并对比正确与错误选择、正常重复与错误持续。固定候选方向，不按正确答案翻转后混合平均。
多 token 候选保存逐 token 与长度归一化读出，不只报告首 token 或总和。
配对合成题验证能力，自然 RAG 样本验证是否有相同现象，两种结果分开报告。

按 source 而不是 token/edge 数统计有效样本量；先跨来源复现再讨论可泛化机制。
如果正负消息及条件响应在正常和错误决策中没有可复现差别，停止把它当检测先验。

### D. 有稳定现象后，冻结最小图读出再评价

按同一来源划分、参考预算和读出比较：

1. 旧 self 向量及其因果分数平滑。
2. 各 head 的有符号输出相关消息，暂不加入来源绑定。
3. 同一消息增加来源单元/条件绑定，仍不使用层间连接。
4. 同一消息及来源增加真实层间路由；用只破坏来源/连接的匹配空模型作结构对照。

每一级必须在代码及实验登记中冻结具体维度、归一化、参考距离和成本，
不能把“加入图”留作随结果改变的自由选项。当前尚无证据支持选择某一种完整图神经网络。
首轮保留既有无标签 FIT 近邻读出，目的在于隔离表征变化；罕见不自动等于错误仍是其限制。
语义角色无法自动可靠取得时，不宣称第 3/4 级已成为无监督检测器。

结构空模型只用于冻结表示的事后检验，不当作模型真实反事实，也不以伪造 message 训练分类器。
保留符号/头身份的对照，以及位置、长度、置信度匹配，避免只是额外容量或高置信度差异。
若结构版不能超过强时间基线，或打乱来源/连接后成绩不降，停止声称检测依赖支持路径。
确认性结果需要新的来源划分；当前反复查看过的 TEST 只报告探索性结果。

## 7. 工程边界与拟实施接口

复用 teaching 的 Dataset/Answer、ModelAdapter、Target、GQA 映射和已有评估，不另写一套模型封装。
现有 capture 会 detach 到 NumPy，部分入口处于 inference_mode，不能直接从旧 NPZ 反传。
需单独增加保留计算图的入口；模型参数冻结，inputs_embeds 保留梯度，不进行权重训练。
使用 model.eval() 关闭 dropout，但保持 autograd 开启；冻结参数本身不会关闭 dropout。

以下为实现职责规划，不是已存在的 API：

|位置|职责与最小接口|
|state_audit/capture.py|保持原无梯度采集；新增独立的 gradient capture 生命周期，复用 ModelAdapter.bind|
|state_audit/analysis/attribution.py|纯张量计算 message_saliency(attention, values, readout_gradient)；source_sensitivity(embeddings, gradients)|
|state_audit/analysis/routes.py|带类型的节点/边、来源跨度映射和裁剪；不在此做标签判断|
|experiments/head_interactions|固定目标/条件、运行审计、保存结果及来源级报告|
|head_geometry|读取冻结特征，沿用 FIT/evaluate；不导入模型反传逻辑|

保存 outputs 下的 settings、targets、source_units、nodes、edges、source_scores、controls 和 report。
每条 edge 至少含 layer/head/query/key、来源单元、attention、signed attribution、目标 ID。
Q/K 决定寻址，OV 消息是载荷；当前边图主要解释载荷门控，不能称覆盖完整 QK 因果电路。
残差/MLP 如未计算门控归因，数值应为空而非写成零。

大张量按层/位置分块计算；完整统计先于稀疏裁剪。
按 |c| 保存主要边及丢弃的绝对归因质量，不能沿用 attention 阈值把弱注意力强梯度边丢掉。
特殊 token 诊断质量单列。图缺失、未保留与真实零分开表示。
当前 adapter 使用 eager attention；如要引入 SDPA 或重算 attention 的优化，
先验证 mask、RoPE、GQA、缩放及数值等价，不把尚不存在的省显存方案算作已实现能力。

交付次序：先接口骨架和数值校验，再填充 live capture，最后接审计与报告；
不提交未实现的空方法作为可运行功能。本轮交付的是结果解释与这个可执行研究计划。
