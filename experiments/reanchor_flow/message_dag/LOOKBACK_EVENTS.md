# 从内部回看事件出发的消息 DAG 审计

研究对象是模型从近邻读取转向远处特定来源的事件。远处来源可以是 prompt，也可以是之前的回答位置。
回看位置与之后被标错的位置分开；不以句号、标注错误段首、H/N 标签定义事件。

已有真实 V3 图显示总体匹配 H 更局部、同一 head 跨相邻 token 的 TV 更小，标注段首往往反向。
上排包含起始位置，不能称为纯非起始统计。303 和189是独立 source 数，7097和259才是目标/事件数。
这些是结构关联，尚不证明较远来源包含正确约束，也不证明错误来自闭环自强化。

## 算法对象

1. 对所有样本、所有物理 layer/head、所有可用生成位置扫描完整 attention 行。
   对当前 query b，以相同源坐标集合 R_b={s:b-s>W, s非特殊} 比较当前与上一行；
   不能各用一套移动窗口，否则一个 token 仅因越过 W 就会被误报为回看。
   默认上一步至少一半普通 attention 在当前近邻集合，远处质量增量至少0.10。
   保存连续量；阈值是明确的操作定义，不是学到的语义边界。
2. 每个读取点 e=(b,layer,head) 的远处读取束是实际消息
   m_e=sum_{s in R_b} A[b,s] W_O_head V[s]，不平均 heads。
   prompt 和旧回答都参与。完整束参与传播，最强来源只用于文字展示，不代表唯一事实来源。
   同一位置b的读取点共同构成一次回看事件，各头消息在各自原层的加法处注入，保存全部参与head身份。
   这利用线性响应的可加性，不平均heads；避免将同一回看位置误当成数百个独立事件。
   保存逐层实际注入范数与多头向量抵消率，源attention求和仅供展示，不是概率或独立事实来源证明。
3. 在原计算的该层 attention 加法之后注入无穷小方向 epsilon*m_e，
   按捕获点的局部 Jacobian 传播。包含 RMSNorm 分母导数、Q/K-softmax、V/O 和 SwiGLU 导数。
   这与原DAG的冻结attention/归一化及对MLP乘积做任意可加分摊不同。
4. 按事件后严格跨位置 attention 次数分成0、1、2+跳；不同物理层满足因果顺序。
   0跳仅在原载体内部更新；1跳直接转给后继；2+跳先经过其他回答载体。
   分组在每个原生算子内部维护，三者相加还原完整切向响应。无需枚举指数级路径。
5. 同时计算完整路径、固定QK路径、无MLP分支路径。后两者不改变原前向值，
   仅选择Jacobian DAG中的路径；full-fixed_QK表示至少经过一次Q/K分支的局部作用，
   full-no_MLP表示至少经过一次MLP分支的作用。两组差值有重叠，不能彼此相加。
6. 最终读出使用原 observed-vs-runner 的 logit 差导数，包含最终RMSNorm导数。
   它表示该消息如何支持当前候选，正负都不是事实真值。允许为明确事实提供独立候选对。
   各token的候选方向不同，不将其曲线下降解释成同一事实信息丢失。

## 为什么需要 DAG

同一个远处读取束进入真实残差后，通过逐层的同位置变换和跨位置读取影响后续输出。
0/1/2+跳不是几种互不相干的特征，而是同一响应的互斥路径分解。
同样的attention拓扑下，V投影或MLP可以让传递作用截然不同；
相同来源质量下，直接读取和经过多个载体的作用也可以不同。
本实验检验这些差别是否与后续标注错误相关，不预先给出幻觉判定器。

## 覆盖与可解释边界

- 默认所有任务、所有split、所有已满足请求范围的样本和事件；没有8样本或每样本6目标的隐藏预算。
- label只在事件构建和消息传播完成后加入报告；未知标签保持未知，正常无事件样本仍计入覆盖。
- 事件与所有实际可用后续token对应，末尾缺少未来不能填0当作无影响。
- 主要报告按source等权，保留每个head；同一样本多个head事件不是独立重复实验。
- 保存的切向状态模长是表示响应，不是信息比特或事实可解码性。MLP方向抵消也不是自动的语义覆盖标签。
- 此处注入的是真实读取束，不是已解耦的事实方向。要声称限定条件丢失，仍需独立条件/候选定义。
- BF16缓存上使用浮点解析导数，是围绕所存舍入状态的平滑局部模型；不把它称为BF16离散舍入函数的导数。
- 先用真实小Llama的内部消息微扰核对有限差分，再使用真实8B缓存。不能用小模型测试冒充8B机制结果。

所有事件扫描与传播都可复用原生缓存。扫描无需模型权重；传播逐层加载权重、按事件分块，
不建立新的GNN、不更新模型参数、不重新自由生成答案。成本随事件数增长，运行时报告实际覆盖与耗时。

## 直接运行

在仓库根目录运行，模型目录默认读取原 audit 的 index.json：

```bash
conda run --no-capture-output -n research \
  python -u -m experiments.reanchor_flow.message_dag.event_run \
  --audit experiments/reanchor_flow/outputs/attention_audit_v3 \
  --completed-only --device cuda:0
```

默认全 split、全 task、全样本、全事件。`--completed-only` 仅明确排除原生缓存缺失项，
不会把 train 当 test，也不改变事件阈值。要强制全部计划样本完整，去掉这个参数。
`--event-batch 2` 和 `--query-chunk 8` 只控制计算分块；增加事件块可减少重复层加载，显存也会增加。
程序显示每组完整/计划样本数、每样本事件位置数和原生读取点数、逐层传播与未完成事件。
`--model /实际权重目录` 可在首次运行时覆盖原 index 路径。需要 bias-free Llama 的 safetensors 权重。
依赖沿用仓库 requirements；当前用 transformers 4.57.6、torch CPU 验证。

先全量扫描并复核结构统计，不加载模型权重，在同一命令末尾加 `--phase scan`。
扫描只要求 `.npz + .qk.npz + .history.npz`；完整传播还要求 `.states.npz`。
`.audit.npz` 或 top-k attention 无法替代这些原生文件，程序不会用近似路径悄悄补齐。
`--list-available` 只列覆盖，不计算、不写输出。扫描后去掉 `--phase scan` 即可续跑全部事件传播。

默认输出 `AUDIT/lookback_events_v1/`：

| 文件 | 内容 |
|---|---|
| `index.json`、`summary.json` | 请求范围、缺失缓存、每样本事件数、实际传播完成数、未知标签数 |
| `samples/<split>/<task>/<id>/scan.npz` | 全部 layer/head/位置连续结构量、读取点坐标、原始 token 与 mask |
| 同目录 `event_<b>.npz` | 一次内部回看位置 b 的原生读取点及所有后续目标的消息响应；b为绝对位置 |
| 同目录 `labels.npz` | 单独保存的事后标签，未知保持 -1 |
| `cohorts/*_heads.npz/png` | 全H、已知N→H、已知H→H，逐物理head的同回答匹配差及source区间 |
| `cohorts/event_outcomes.csv` | 回看后各偏移/区间的N/H响应、路径家族、独立source数与实际观察对数 |
| `cohorts/candidate_states.csv` | 当前候选差M，以及M<0且消息局部增益C>0的source等权比例 |
| `gallery.html`、每样本 `preview.html` | 原始文本、读取head、来源token、跳数响应、逐层转换与多头抵消 |

预览选择每个样本最早完成的事件，不按 H 或响应幅度挑选。其余所有事件都已保存，按绝对位置打开：

```bash
python -m experiments.reanchor_flow.message_dag.event_view \
  --sample experiments/reanchor_flow/outputs/attention_audit_v3/lookback_events_v1/samples/train/QA/11871 \
  --position 610
```

610只是命令格式示例，必须替换为该样本实际检测并完成的回看绝对位置，不能当作已发现事件。
界面各图可悬停查看 token 坐标与数值，读取 head 可切换。
只重做离线报告，不需要原模型或大缓存：

```bash
python -m experiments.reanchor_flow.message_dag.event_run \
  --phase evaluate --output experiments/reanchor_flow/outputs/attention_audit_v3/lookback_events_v1
```

扫描/传播期间每个样本和每个事件独立保存；重复原命令跳过已完成事件。
事件阈值、模型、候选对或请求范围改变时换 `--output`，避免混合不同实验。
同一输入 token 序列的原生状态文件应保持不变；该流程不对巨大状态缓存建立内容哈希。

## 正确／错误候选与后续判别

`--contrasts candidates.json` 可提供独立定义的单 token 候选对：

```json
{
  "train/QA/11871": [
    {"target": 611, "positive_id": 123, "negative_id": 456}
  ]
}
```

这些数值同样只是格式示例，须用实际 tokenizer 与目标语境验证。target 是被预测 token 的绝对位置。
positive/negative 的事实身份由外部证据定义；不能从模型当前输出或 H 标签自动推导。
默认 observed-vs-runner 与明确候选在报告中分开，不能混成一个“真实性方向”。
这只检验固定前缀上的单 token 候选 logit 差；多 token 事实需另外设计相同问题的序列对比。

事件文件同时保存参考候选差 `baseline_margin`：M=z_positive−z_negative，
以及增强读取束的局部作用 C=dM/d epsilon（完整路径的0/1/2+跳之和）。
M<0且C>0直接区分“增强消息有正向作用”与“正候选已经占优”。
只有独立证据确定positive/negative的真值，才能把该状态联系到“正确候选仍然输给错误候选”；
它不证明已解耦出纯事实方向，也不保证有限幅度增强的作用与无穷小导数一致。
BF16上M与C均指所存状态的平滑参考计算，不能将极近零的差值当成精确离散判决边界。

先检验以下可证伪问题：

1. 回看之后的正常／错误目标，其远处读取束是否经2+跳继续发生可测读出作用？如果没有，则“中继强就一定传到了输出”不成立。
2. 同一事件的真实多头消息在原层合并时是否抵消？这种抵消是否与最终候选响应同向变化？
3. 明确正确候选的完整响应为正，但较固定QK或无MLP分支路径更弱时，哪个路径家族产生了相反作用？
   局部 MLP 余弦可定位待查层；还不能仅靠它给某一层定性为“覆盖事实”。
4. 回看后较长时间不再触发该阈值，同时旧消息经多跳继续支持错误候选，是“持续复用、低新增远处读取”的候选现象。
   阈值以下仍可能接收外部信息；要声称拒收新证据或自由生成闭环，还须验证新证据敏感性和生成分叉。

新图的远处定义包含 prompt 与旧回答，mask补入漏标控制token，增量采用固定源集合。
新统计对三个 H 子集使用同一两侧匹配规则；旧起点图还要求正常完整窗口。
这些口径变化均可能改变数值，因此新结果不是原图逐像素复现。
全部H与起点两组平均值不能直接拼接成同一样本“远看→局部自强化→出错”的因果轨迹。
当前审计的作用是逐事件、逐后继目标检验该轨迹，而不是预先命名一种幻觉机制。

## 已验证结果与真实数据覆盖

2026-09-08复核用户提供的 `reanchor_evidence_20260908.zip` 中两个真实统计表，
下表计数是原保存 BY q<0.05 的物理 head 数；每组共有32×32=1024个head。
不把这些计数当独立样本数，也没有在本环境重新跑原8B前向。

| 原指标 | 总体匹配H：增加 / 减少 | 标注起点：增加 / 减少 |
|---|---:|---:|
| local_history_share | 998 / 7 | 34 / 366 |
| far_history_share | 151 / 634 | 646 / 9 |
| distance_clip10 | 37 / 927 | 370 / 46 |
| change_tv | 7 / 928 | 192 / 18 |
| prompt_share | 87 / 700 | 80 / 349 |

`far_history_share` 是旧回答远处历史，不能称作 prompt 约束。起点的 prompt_share 仍有更多head下降。
原上排7097个匹配H、303个独立source；原下排259个起点事件、189个独立source。
原上排有6704个非起点，占94.46%；这只是组成比例，绝不意味着错误默认发生在起点。

实现测试：

```bash
python -m pytest -q experiments/reanchor_flow/message_dag/tests/test_events.py
```

已通过实际 tiny Llama 内部消息 ±epsilon 微扰与解析响应的一致性（包含GQA、RMS分母与QK）；
0/1/2+分解闭合；合并读取点等于逐点响应之和；事件块互不污染；固定源集合排除窗口老化假事件；
六组全范围入口、缺失覆盖、续跑、标签隔离及删除模型/原缓存后的离线报告。
另有参考前向完全相同而SwiGLU消息导数相反的明确反例，说明纯attention标量路径不足以区分传播作用。
测试小模型为随机权重；六组入口测试复用同一捕获并使用合成标签，仅验证程序，不提供幻觉经验结论。
在提高Q/K幅度以增强路由敏感性的实际tiny Llama中，解析总响应与独立autograd参考的最大绝对差为
4.66e−10；epsilon=0.03的原生消息有限差分最大绝对差为7.40e−7。
该例完整路径与固定QK路径的最大响应差为3.21e−4，因而数值核对不是在QK作用为零的特例上通过。
autograd仅用于小模型测试的独立参考，生产审计不调用模型backward、不训练参数。

本环境可读的真实11871上传包仅含主 `.npz`、旧 `.audit.npz` 与 labels；
缺少新扫描/传播所需的QK、完整history与states，亦无原8B权重/GPU。
因此本次完成代码与数值/流程验证，没有声称完成新的8B全量事件传播或发现可泛化幻觉判定器。
