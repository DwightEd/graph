# 八目标 pilot：修复前后的可核对结果

输入为用户提供的 `message_dag_review.tar`，两条 train/QA 回答（11859、16857），各四个目标。
八个目标全部标为正常，两条完整回答也均无 H 标签；因此不存在正常／幻觉的可比较样本。
包内只有派生图、metadata 和标签，没有 `.history.npz`、`.qk.npz`、`.states.npz`。

## 可在现有结果上核对的修复

旧 special mask 每条回答漏掉六个 header 控制位置：

| 回答 | 补入 special 的绝对位置 |
|---|---|
| 11859 | 1, 3, 32, 34, 242, 244 |
| 16857 | 1, 3, 32, 34, 372, 374 |

目标出口可以用保存的 `root_position_credit` 核对。令这些位置的入口贡献之和为 c，则
`other_prompt_new = other_prompt_old - c`、`special_new = special_old + c`。
这是原条件算子下的来源重分类；总目标贡献保持不变。

11859 的目标 292 原本看似得到 `other_prompt` 的负向贡献，正确分离控制 token 后该组变为正向。
因此旧来源图中的此类结论不能继续沿用。材料根在此例中未与漏标位置重叠，其出口净贡献不因这次分组更改而变化。

这个出口核对**不能恢复每层来源向量、逐 head 贡献和重新筛选的展示边**。schema 2 必须从原生缓存
重新做所选样本的来源与目标传播，不能只修改旧 NPZ 的名称或 mask 就宣称整张图已修复。
真实 tiny Llama 回归测试已经验证：完整重传播的出口变化与上述根贡献重分类相符，内部来源分量也随之改变。

## 目标选择修复

旧均匀四目标选择包含套话、功能词、空格、标点及词内片段；首页又只展示首个目标，无法检查有历史的中继。
新配对模式使用词法内容词／数字的首 token，明确跳过上述展示问题；它不声称自动识别了事实。
例如 11859 的电话号码三个片段可选位置为 267、270、272，重复电话号码为 285、288、290。
`Butcher` 的首 token 为 260，旧目标 261 的 `cher` 是同一词的后续片段，不符合新的词首策略。

新筛选在 11859／16857 分别找到 13／68 个内容目标，但 H 数均为零。
对这两条回答重复增加正常目标，依然不能产生正负比较。新入口对全正常范围会在加载权重前报告覆盖不足。

## 已有结构与接下来的比较

16857 的旧空格目标 523 存在“prompt 引用编号 → 先前回答的引用编号 → 当前预测位置”的带符号材料来源路径。
L11H5 与 L11H23 对该载体的同材料来源贡献分别为 +0.048524 与 -0.062407；两者方向相反。
这是条件归因下的复用与抵消案例。reader 包含整个材料单位的分量，不能把它全归给先前选中的单条入口边；
也不能由空格读出认定事实正确性被约束。这条回答是正常回答，本例本身不能作为幻觉特征。

下一批固定比较：全正常回答、含幻觉回答中的 H 内容目标及同回答 N-H-N 对照。
主看来源×层×head 的同目标传播与配对差异，保留缺失、零效应和反向案例。
样本按标签富集，仅用于寻找可复现的结构差异；不输出总体 AUROC/AP，也不将小批差异命名为已经证实的幻觉机制。
