# 原生计算模式：发现、归纳与审计

更新：2026-09-07。本文对应已实现的 `discover` 入口。旧四桶检测、监督读出和有限 target 审计见
[METHOD.md](METHOD.md)。当前任务是从原始生成轨迹发现显著的内部变化，不预先要求其符合重锚定。

## 1. 研究对象与结论边界

观察同一个生成位置中，逐 head 信息写入如何聚合，MLP 如何改变状态，以及这些写入在实际输出方向
上的贡献；再研究这些计算模式如何随生成位置变化、能否跨样本复现，以及正常／幻觉之间的差异。
来源选择差异只是辅助视图。新流程直接采集原模型运算，不用四桶比值代表全部信息。

| 可以定位的计算表现 | 还不能直接赋予的解释 |
|---|---|
| 多个 head 写入方向不同、净和抵消 | 它们在争论两个事实候选 |
| MLP 更新使固定输出候选差改变符号 | MLP 正确整合了事实，或注入了错误先验 |
| 联合 head／MLP 模式在某位置显著变化 | 这是新事实边界，或本来必须重锚定 |
| 中层与末层的直接读出偏好不同 | 证据先被整合，随后被覆盖 |
| 某模式在匹配位置的幻觉 token 中更常见 | 该模式造成了幻觉，或可直接部署成检测器 |

head 的语义角色可能混合；attention 一致、写入同向或稳定复用都不能单独区分正确与幻觉。
此前“未进入／未整合／被覆盖／读出沉默”四种解释仍是待验证假设，不由程序强行分类。

## 2. 一个计算模型贯穿采集

记 r[l,q] 为 attention 前残差，query head h 对应 GQA 的 KV head g(h)：

\[
c_{l,h,q}=\sum_{s\leq q}A_{l,h,q,s}v_{l,g(h),s},\quad
 o_{l,h,q}=W_O^{l,h}c_{l,h,q},\quad
 r^A_{l,q}=r_{l,q}+\sum_h o_{l,h,q},\quad
 r_{l+1,q}=r^A_{l,q}+f_{l,q}.
\]

`NativeTraceObserver` 复用公共前向 observer，在真实 attention／MLP 运算处采集。
head 轴始终存在；上式求和是模型本身的聚合运算，不是先平均 head 再分析。
q 的读出预测 q+1；首个 response token 也覆盖。teacher forcing 分析给定历史下的计算，
不是一次自主生成的反馈实验，也不据此声称发现了吸引子。

为避免逐 head 展开 4096 维消息，全流程共用固定的残差空间正交投影 P[D,R]：

\[
X_{l,h,q}=P^\top o_{l,h,q},\qquad
R_{l,q}=P^\top r_{l,q},\qquad F_{l,q}=P^\top f_{l,q}.
\]

同一模型下跨样本、层、head 使用相同 P，默认 R=16、seed=2026。投影是线性的，因此保留
投影内的加性运算与方向相消；**不保证保留全部语义或完整空间几何**。NPZ 保存 P 和实际全向量范数，
可检查投影保留的能量。`--save-head-codes` 另存完整 c，结合模型 W_O 可以重建净写入，
但不能据此无损重建所有 source 边。

第一次无梯度前向冻结每个位置的 observed token y、最高非 observed 候选 b 和 raw final residual。
第二次采集全部 head 与模块，不为每条路由重跑。输出解释方向固定为：

\[
d_q=\gamma\odot(U_{y_q}-U_{b_q})/\operatorname{RMS}(r^{final}_q),
\qquad a_{l,h,q}=d_q^\top o_{l,h,q}.
\]

同一 q 跨层共用该方向；不同 q 的 y、b、d 不同，不能用 a 的跨 token 突变单独定义机制切换。
它是原生轨迹的直接 logit 记账，不是梯度、删掉 head 的总效应或事实支持度。
BF16 的 head 聚合、残差加法、最终归一化和输出舍入显式保存 remainder；报告同时给出原始偏差
与加上 remainder 后的闭合。后者是数据契约检查，不是独立的机制证据。

来源边用 a[l,h,q,s]=A[l,h,q,s]·d[q]ᵀW_O[h]v[h,s]。所有来源参加净向量与完整统计；
只为展示保留绝对贡献最大的 K 条，另报未展示部分的带符号总量、绝对总量和聚合舍入。
净遗漏接近零可能只是正负抵消。边标的是本层读取的载体位置，不自动追溯多跳语义来源。

## 3. 从全部 head 的向量中归纳模式

`NativePatternModel` 每个 token 的输入是按固定次序拼接的全部 X[L,H,R] 和 F[L,R]。
不输入幻觉标签、候选 logits、四桶比例或人工挑选的 head。

1. 在 train 来源上构造有上限的拟合行集合。排除与 test 重叠的 source；各 source 均衡配额、
   source 内近似均衡样本配额，再按固定随机种子抽取行。保存全部 source 与行坐标。
2. 用 train 中每层共享的 RMS 缩放 head block，MLP 使用自己的每层 RMS，保留层内 head 相对幅度。
   不按 token 归一化；缩放会定义学习度量，属于方法假设。
3. 联合 randomized PCA（默认 8 维）学习写入组合，再用 KMeans（默认 6 个模式）归纳重复状态。
   保留正负向量与全部 head 坐标；保存原单位的模式中心和逐 head 分量载荷。
4. 冻结模型后，转换 train/test 全部采集行。保存模式、连续坐标、相邻坐标变化、最近中心距离及
   重构误差。首行／缺少相邻前行时不定义转移，不借助未来 token 定位当前变化。
5. 模型、预测和选图名单写盘后，才打开测试标签。图中的高变化窗口只用于检查，不影响全量分母。

模式数量、线性压缩与欧氏聚类是可检验的归纳选择，不是新机制本身。既不要求某个 head 单独突出，
也不把“罕见模式=幻觉”作为研究前提。默认拟合最多 4096 行是计算预算，**所有 token 仍被转换与审计**；
若模式重构不足，应增加预算或研究更适合的表示，不能宣称少量主成分天然保留关键事实。

## 4. 如何用结果审计机制

先打开 `summary.md`、`mechanism_cohort.png` 和 `mode_writes_ALL.png`，再检查样本图及同名 JSON。

1. **定位重复行为。** 看模式覆盖的 source／sample 数、联合坐标和模式转移，检查改变涉及哪些
   head／层和 MLP。模式编号本身无语义，不能仅凭聚类给它取“事实 head”等名称。
2. **回到同一位置的运算。** 对照逐 head 正负写入、attention 前后状态、MLP 更新和最终 margin。
   读取具体来源 token；检查显示预算的遗漏量。方向相消与 MLP 反转是可见运算，事实解释另需内容核查。
3. **比较正常与幻觉。** 对每个模式，计算同一样本、同 log2(response_index+1) 区间中 H−N
   出现率差，依次平衡区间、source 内样本和 source。所有模式都报告，不挑最好看的 head 或模式。
4. **检查复现与混杂。** 看来源成簇 bootstrap 95% 区间和 source 符号翻转检验；全 task×mode
   家族做 BH 校正，包括 ALL 与缺失模式。跨任务相同 source 在 ALL 中先合并。符号交换与 BH 的依赖
   条件是推断假设；粗位置匹配也没有消除词类、任务难度、回答长度等全部混杂。
5. **再形成可证伪的语义解释。** 例如发现某种“多 head 分化后 MLP 反转”在多个来源复现，再
   检查具体内容是否涉及限定条件，以及内容变化是否真正影响后续输出。不是先设四种故障再把样本塞进去。

只有同时存在 H/N 的匹配区间参加该配对效应；纯正确、纯幻觉和未知标注的样本仍计入覆盖和
无标签模式描述。区间是对冻结模型的条件区间，不包含重新拟合模型的不确定性。

## 5. 检测结果与未验证假设

`detection_report.json` 对全部有标注的测试 token 给出 AUROC、AUPRC（average precision）、
source bootstrap 区间及基线。固定诊断为最近模式距离、模式坐标变化、负 observed margin、位置。
这几项用于检验所学模式是否带来直接可读出的检测信息，不是已验证的新检测器；不按 test 选符号。
最终可靠的检测评分应来自复现的机制差异。需要与旧 routing／位置／置信度基线比较增益，
不能把聚类可视化或显著性本身当成检测效果。

尚待真实 8B/RAGTruth 数据验证的核心假设：

- 低维联合写入存在跨来源稳定的计算模式，且不仅对应词法、位置或数值尺度。
- 不同 head 的协同／抵消、MLP 改变状态和跨层读出变化中存在正常与幻觉的可复现差异。
- 差异涉及信息的选择、整合与使用，而不仅是与标签相关的表面因素。
- 由这些差异构造的冻结评分能超过已有基线，并在新来源保持。

现有 test 已多次参与研究设计，后续结果属于探索性；确认性结论需要新的独立来源。
本轮已在真实小型 Llama 的 FP32/BF16 路径验证采集与记账，不等于已获得真实 8B 的发现或检测增益。

## 6. 语义与因果确认的后续接口

原生审计先确定值得研究的具体位置、head 与模块。若要称其承载事实证据、置信度或语法，需要与
该解释对应的内容对照。例如证据绑定×查询对象的四格对照，交换绑定后事实偏好应随之改变；
另设不改变事实的改写和无关编辑，控制词面因素。置信度另需自己的输出目标。

对已冻结的少量位置进行状态交换或下游阻断，才能检验调用；有信息可解码不等于原模型实际使用。
原生代码没有实现通用四格构造或这些确认实验，不把观测式直接贡献称作因果效果。
这类确认是后续对具体发现的检验，不取代在原始正确／幻觉样本上发现机制的主流程。

## 7. 代码与资源

- `native_trace.py`：`FrozenReadout` 冻结读出；`NativeTraceObserver` 按当前层采集，CPU 保存结果。
- `native_patterns.py`：`NativePatternModel` 只负责表示、拟合、转换和模型存取。
- `native_report.py`：`NativeCohort` 按 source 流式归纳，绘图不反向影响发现。
- `discover.py`：读取旧输入索引、采集／续跑、冻结、标签连接和输出编排。

共享现有 GQA 前向、数据集、原子 NPZ 保存及检测指标模块。没有复制模型 forward，也不建立新的
手工四桶特征运输链。分析阶段释放 GPU 模型后在 CPU 拟合；没有逐 token backward 或逐路由消融。

默认浮点 sketch、来源边和余项在 32 层×32 head 的模型上约为每个 response token 0.1 MiB 量级，
全量几十万 token 可达数十 GiB（未压缩），不能承诺很小。完整 head code 为 float32，另增
32×32×128×4=512 KiB/token。模型只加载一次，长 prompt 的注意力仍有计算成本；query chunk 控制
临时 attention 矩阵，无法让全量 8B 审计成为无成本的旧缓存分析。
