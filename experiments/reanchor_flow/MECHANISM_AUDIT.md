# 一条主线：中间状态怎样形成，随后怎样被使用

更新：2026-09-07。本文更正此前把来源统计、向量聚类与机制发现混用的研究定位。
现有代码是测量与基线工具；目前没有经过验证的机制驱动检测算法。

## 1. 唯一研究问题

**在原始生成轨迹中，被后续位置复用的中间状态如何形成；正确与幻觉生成的区别，是否在于这个状态对当前输入约束的响应与后续使用之间发生了失配？**

这是待检验的问题，不是已经发现的机制。中间状态可以位于 prompt 或 response；不预设它一定是
重锚定 token，不要求每次复用前都有一次新检索，也不把局部注意力或稳定复用本身视为幻觉。
已经形成的正确状态完全可以持续被复用。

分析对象是一段可以在实际计算图中对齐的过程：来源被读取，写入在某位置经 attention／MLP 更新，
该位置的状态又被后续位置读取并参与输出。所有观察、统计和确认都必须回答这同一个问题。

## 2. 为什么已有方法没有回答这个问题

| 现有部分 | 实际回答的问题 | 缺失的关系 |
|---|---|---|
| 四桶来源范数 | 当前预测直接从哪些位置类别收到多大幅度的消息 | 桶内具体来源、方向抵消、经过哪个载体传来 |
| 监督 probe／head report | 哪些统计能区分现有标签 | 分类器贡献不等于原模型的信息使用 |
| PCA／KMeans／模式距离 | 哪些净写入组合常见，哪些偏离中心 | 压缩和罕见性不自动对应状态形成与调用 |
| observed−runner 直接读出 | 各模块在当前候选差上的加性贡献 | 该方向没有预先定义事实内容，也不是总因果效应 |
| 目标级 route graph | 在给定预算中哪些路径连通，少量干预怎样作用 | 不能代替自然样本中的重复形态及内容作用验证 |

这些工具有各自用途，但把它们串接起来不会自动产生一条机制证据链。
已有约0.835的监督AUROC属于四桶线性读出，不是DAG或多跳机制带来的检测成绩。
`pattern_distance` 也不再被定位为拟议机制方法的核心评分；它仅是探索性对照。

## 3. 从参考论文借鉴论证结构

[Attention Illuminates LLM Reasoning，§4–5](https://arxiv.org/html/2510.13554v2#S4)
把矩阵中的局部分块和远程列结构，与向后读取、后续复用两个方向的观测相联系，再检验耦合并应用于RL。
这给本项目的启发是：指标必须对应同一个可观察过程，应用必须对应验证过的作用。
其注意力规律不能直接当成本项目的幻觉机制；本项目也不以论文分组均值替代逐head数据。

## 4. 用实际计算关系组织数据

节点是 (layer, token_position, stage)，stage 区分 attention 前、attention 后、MLP 后。
边是特定 head 的 source→query 写入，残差连接和MLP更新分别记录：

\[
m^{\ell,h}_{j\to q}=W_O^{\ell,h}
\left(A^{\ell,h}_{q,j}V^{\ell,h}_{j}\right),\qquad
r^A_{\ell,q}=r_{\ell,q}+\sum_h\sum_{j\leq q}m^{\ell,h}_{j\to q},\qquad
r_{\ell+1,q}=r^A_{\ell,q}+f_{\ell,q}.
\]

GQA 保留 query-head 与 KV-head 的实际对应。向量求和是模型本身的运算，不能用逐边范数之和替代。
有限精度余项是数值检查项，不是语义或机制指标。不能把attention连乘或反复累加跨层贡献当成完整语义传播。

必须分清两个时间索引：位置 b−1 的logits预测token b；token b 输入后，形成位置 b 的各层状态。
未来位置 u>b 读取的是后者各层的K/V。不能把生成token b 的预测状态与token b 后来作为载体的状态合并。
在固定teacher-forced轨迹中，第ℓ层读取的K/V来自载体该层attention前状态；该层新写入及MLP更新后的
信息，只能通过更后层的读取传给其他位置，不能把同层的列关注当作对该层新整合内容的调用。

一个候选过程围绕载体位置 b 展开，记录它在何层从哪些位置收到写入、MLP如何更新，以及哪些后续
位置在何层读取了它。允许多head互补、多个载体和持续复用，不要求只有一条胜出路径。
DAG在这里用于保留这些具体关系；最终若再次只输入四桶份额，图的关系就又被丢掉了。

## 5. 先看真实形态，再冻结定义

首先在预先抽取的训练来源上，展示未经事件对齐的原始逐head attention矩阵。隐藏幻觉标签，保留
真实token、prompt/response分界、query/source坐标。完整回答用于发现，不能先截取最高变化窗口。
可以按无标签的回看跨度排列head方便阅读，但不能用监督系数筛head，也不能跨head平均后取代原数据。

同一矩阵的行回答“当前位置读谁”，列回答“这个位置随后被谁读取”。先寻找跨样本重复的结构，
例如读入来源发生变化后，同一载体开始被后续位置持续读取；这只是候选例子，不能强制数据出现它。
对角分块、竖条、重访或相位关系都应在原图中可核查，不能仅在降维后出现。

看到重复形态后，才定义相应事件／关系，并在训练来源冻结识别规则。直接展示完整轨迹及无事件
样本作为分母。匹配位置、局部性和词类的对照，以及保留曲线自相关的分块错位，用于检查位置结构与偶然对齐；
这些替代对照属于统计零模型，不能当成实际生成轨迹。不能只打乱全部token，破坏背景结构后得到过于容易超过的基线。

如果只能在事后挑出的两个head或少数test窗口看到，应报告探索性线索，不报告普遍机制。
如果没有找到可重复形态，应止于“该自然机制未被观察到”，不要自动换一个异常评分掩盖这个结果。

## 6. 同一候选过程的三层证据

| 需要回答的问题 | 对应检验 | 不能替代它的量 |
|---|---|---|
| 是否存在反复出现的形成→复用关系 | 在独立来源上复现冻结的行/列关系、层位置与时序，对照位置和局部性 | 某峰很高、一个聚类存在、两个群体均值不同 |
| 被复用的状态是否承载并使用有关内容 | 对冻结的少量自然案例改变相关事实/限定条件，核查状态响应和固定事实判断；匹配的不改事实改写作对照，必要时交换状态验证调用 | 消息大、余弦高、可解码、observed-token margin大 |
| 正常和幻觉是否在相同过程上不同 | 在来源独立、位置/内容类型可比的样本中，比较上述过程的形成和使用；保留失败、无事件、无响应案例 | 按幻觉起点对齐后看到区别，或按test标签挑head |

内容对照必须核查事实关系，不能假设自动删去一段prompt就只改变了证据。保持可比历史前缀与坐标；
若后续原回答在编辑输入中变得不相容，明确这是给定历史下的条件实验，不能混称自然纠错。
先定位自然过程，再对少量冻结位置验证；不对所有路由穷举剪除，也不因确认失败临时换节点。

状态交换可能同时带入词法等内容，需有对应对照。只改变最终判断仍不足以断言效果经过某一hub；
要作路径结论时才检验该已定位通路的传递。单个节点无效也不能排除分布式冗余。

只有这三层证据连起来，才可以给过程命名。证据未进入、未整合、被覆盖、读出沉默是不同解释，
不得从一个模长、相似度或聚类编号直接判定；也不先要求数据必须支持其中一种。

## 7. 第一份应交付的机制图

每个真实案例使用同一组token坐标，联动展示三个视图：

1. 逐head原始attention：完整时间轴上的行读取与列复用，标出具体token和保留的head身份。
2. 同一个载体的逐层运算：attention写入、聚合、MLP前后状态；向量方向与读出目标明确标注。
3. 下游使用：后续位置实际从载体读取的边，以及少量已完成的内容响应/调用验证；未验证的边明确标记。

总体图统计的是这种过程在多少样本/来源/head中复现、时间关系的分布和匹配的正常/幻觉差异。
单样本图是审计依据，不能替代总体统计；总体均值也不能掩盖逐head差异。

后续复用天然涉及未来token。它可以用于事后机制发现；如果检测器使用未来H个token，必须标注
至少H个token的检测延迟。即时检测只能用当前可用前缀，不能把未来影响量混入即时AUROC。

## 8. 机制验证之后才确定检测算法

在现象成立前，不再注册route+MLP+stability的任意加权分数，也不把离聚类中心远当成研究结论。
机制若显示“同样的复用结构中，内容约束未有效进入被调用状态”，检测函数就必须反映这个具体差别；
若该差别无法从自然输入的可用观测中读出，则机制研究尚未转化为无监督检测器。

最终评价覆盖全部已标注token，不只评价选中的事件。事件之外如何产生分数必须写入算法定义。
与位置/置信度/四桶基线比较AUROC、AP和来源级区间；训练用于发现，冻结后复现，再评估检测。
现有test已经参与多轮设计，只能用于探索性分析，确认性结论需要新的独立来源。
