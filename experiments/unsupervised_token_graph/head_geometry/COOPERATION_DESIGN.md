# 在回看节点研究多头协同：任务约束怎样改变消息的作用

2026-09-21。本文区分已经完成的代码、自然数据结果和拟开展的实验。
本次已实现分任务报告与中间层入口，没有执行下面的新原生干预，也没有新的检测成绩。

## 2. 为什么先不增加黎曼几何

窗口二阶矩是 SPD，可以研究不同矩阵距离。但因果交互矩阵一般有正有负，未必半正定，
不能加大 ridge 后就把其符号与方向当作无关信息。head 的编号也不是天然的流形坐标。
当前 log_moment 还包含白化、矩阵对数、投影和逐维缩放，不能称作精确黎曼测地距离实验。

普通 moment 包含 Cov(z) + mean(z) mean(z)^T；它的收益可能来自持续偏移、单头能量或交叉项。
先比较同一观测定义下 window=1/16，以及未取 log 的严格无交叉项对照。
不能在完整白化后只取对角，再声称完全移除了头间关系。

[Smith 等，Data Analysis using Riemannian Geometry](https://arxiv.org/abs/2203.12471)
研究 SPD 矩阵在过程监测等任务中的表示和距离；这提供数学工具，但不提供 LLM head 功能协同的证据。

## 3. 核心研究对象：带来源、时间和输出方向的条件作用

候选时刻先由无标签回看规则产生。正常回答也可以触发；回看定位不要求直接区分真假。
记录具体 query、来源位置、层和 head，再把标注作为事后审计信息。
从回看前、回看当步到后续若干 token 连续测量，不把标签 span 起点冒充模型决策点。

同层同一 query 的各头并行读取，各自消息通过输出投影相加。一个头不能在同一层直接改变另一头
已经计算的 Q/K/V；它们可能在后续非线性层发生功能交互，也可能通过更早层影响更晚层的读取。
因此需要区分同层联合效应、跨层有向中介和跨 token 持续，不能只算一个对称相关矩阵。

对来源 s 到 query q 的消息保存：

    m[s,q,l,h] = W_O[l,h] (a[q,s,l,h] * v[s,l,h])

v 是实际上下文化 value，包含模型对应的归一化与 KV-head 映射；不以单独 W_O W_V 范数替代。
分别保留 attention mass、消息向量/能量与输出作用。高 attention 或高能量不自动等于支持正确答案。

### A. 先定义每个头的功能，而不是由相关系数命名

在已审核、同问题的对照上分别改变：值、对象/阶段/范围、来源位置。
保持候选值不变时交换适用条件，检验哪些头的作用随关系改变；保持内容不变时换位置，检验位置行为。
用独立对照给头分配暂定功能：值敏感、约束敏感、位置敏感、history 敏感；同一头可有多种功能。
角色以任务/位置为条件，不假设某个物理 head 永远是“事实核查头”。

[Decoupling Positional and Symbolic Attention](https://arxiv.org/html/2511.11579v1)
通过块置换比较位置不变性与内容等变性，可用于定义位置/内容行为对照；
不能据此删除全部位置型 head，也不能由 symbolic 分数直接判定它在传递适用约束。

### B. 四条件联合干预

固定同一输入前缀、目标位置、两个候选答案及所有其他 head。选择两个头或头组 A、B。
1 表示保留原生消息，0 表示替换成事先定义的参照消息。先做零删除，再用匹配 donor 重复验证。
参照、位置和向量尺度必须记录；替换参照改变，效应含义也改变。

令 F_ab = log p(y_supported | prefix, gates=a,b) - log p(y_rival | prefix, gates=a,b)。
单 token 候选时该式就是 logit 差。多 token 候选分别 teacher-force，明确求和/长度处理，
不能将一个 token 的分数冒充完整事实支持。正确/竞争答案在审计前由来源核验，不能从干预结果挑选。

    A_effect_with_B    = F11 - F01
    A_effect_without_B = F10 - F00
    interaction       = F11 - F10 - F01 + F00

interaction 非零表示 A 的功能依赖 B 是否在场。还必须同时看四个 F 和两条单头效应：
正号是相对于指定参照的超加性，负号可能来自冗余或竞争，不等于自动发现“好协同/坏抑制”。
小于预定实际效应阈值的不作功能命名；按 source 配对 bootstrap，探索性多头结果标记多重比较限制。

核心候选对象是“值消息 A 与约束消息 B 的联合效应是否随适用条件变化”：

    applicability_interaction = interaction(适用) - interaction(不适用)

它比“头一起变大”更贴近烹饪阶段/穿衣范围的实例。若值运输成功，但约束组不能改变最终选择，
可以进一步测试绑定或下游利用；单靠这一差值仍不能宣布是哪一种原因。
这是本项目待检验的研究设想，不宣称现有文献从未做过或已经发现普遍机制。

### C. 区分补偿、抑制和传递

删除早层 A 后，先让后续层自然计算，再把晚层 B 的消息恢复为原生基线，比较两次结果。
如果自然变化的 B 缓冲了 A 删除的影响，支持补偿；若抵消恢复的证据作用，才进一步检查抑制。
同样需要同层同能量随机头、相同距离的普通来源和不改变适用性的 donor 对照。
完整前缀重算与仅对齐一个下游站点的 patch 分开记录，不能用后者冒称完整路径已追踪。

[The Hydra Effect](https://arxiv.org/abs/2307.15771)
发现删除一层后其他层可能补偿，同时晚层 MLP 可能降低最大似然 token 的优势。
因此“删除某头没有效果”并不能单独证明它没有作用，必须检查干预后的下游变化。

## 4. 怎样把协同表示成图

每个节点是 (query 时间, LLM 层, head, 来源角色)，附实际消息及其对候选答案的作用。
同一上下文的二头交互作为带符号关系；跨层恢复得到有方向的中介边；三头以上的联合效应可作超边。
图以单个回答为单位保留，再比较同问题的支持/不支持轨迹。跨回答只做对齐后的统计和训练，
不让跨回答近邻取代实际消息关系。起初用 COO 表和 NPZ 保存即可，不需要先训练 GNN。

新的研究方向是检验“约束条件改变时，值相关协同能否转向正确来源，并维持到输出”。
需要分别看到来源选择改变、消息内容改变、输出作用改变，才能排除只有句法或位置变化。
如果先只看到持续状态而没有条件作用，停止把它称为绑定机制。

## 5. 最小实验和成本

1. 三任务分别采集审核样本，先用已有穿衣/烹饪配对调通；两个来源不能作为总体结论。
2. 每个回看节点先选 4–8 个中间层功能候选；选择依据来自独立来源或预先定义角色，不按本例结果挑。
3. 8 个候选全部单删和双删，复用同一基线只需 1+8+28=37 次模型前向；
   donor、关系反转、其他时刻和其他输出候选另计。不能声称不需要重新运行 LLM。
4. 单/双删无法识别只在三头同时存在时出现的交互；先对选定 4 头枚举 16 组作为高阶检查。
5. 按任务、来源、正常/幻觉、回看相对位置汇报效应及置信区间；检测分数的无标签训练另立协议。

[Shapley Head Pruning](https://arxiv.org/abs/2210.05709)
提供按不同 head 联盟分配贡献的已有方法；Shapley 单头贡献是联盟平均，不能替代具体二头交互矩阵。
[Towards Best Practices of Activation Patching](https://arxiv.org/abs/2309.16042)
显示干预参照与评价量会改变解释结果，因此零删除、匹配替换与输出量必须分开验证。

## 6. 代码现状和下一步实现边界

- `run_middle.sh`：中间层、三个任务、独立输出目录；复用旧 attention，不重跑 8B。
- `reporting.py`：任务×生成器明细、任务汇总、缺任务状态、实际 layer/head。
- `teaching/state_audit/.../experiments/interventions.py::factorial_interaction`：
  已有任意两组操作的四条件交互，当前读出为指定回答 token 的 log p。
  可用于软件级演示，但尚不是上面完整的“支持答案−竞争答案”实验。
- 完整新实验仍需：审核候选答案和语义对照、按两个候选重算目标分数、保存自然/恢复的下游消息，
  以及跨来源统计。现有阈值压缩 attention 无法还原未保存的 V、残差或干预后的输出。

自然标签可用于机制审计及诊断；最终检测若使用这些标签选头或拟合，必须披露其监督依赖。
如用程序生成的值/关系配对学习功能，对应的是程序监督，不能声称整个流程完全没有监督。
