# 研究依据、改进和可证伪点

2026-09-20。本实现响应“均值没用，先重构进行无监督检测验证”。不添加跨 token 历史均值向量或风险平滑器。训练统计量的中位数、尺度、矩阵参照仍须从无标签参考来源估计。

## 为什么选择这个表示

既有监督读出：layer_mean 0.697610、head_contrast 0.841358、full 0.842735；layer_block 0.817908。
这些结果支持保留 head 身份和相对强弱，不证明任意无标签密度读出都能成功。原双高斯已经用过全维白化，因此本次新增量必须来自二阶关系描述及矩阵变换，不能只把旧白化改名。

上一版方案提出滚动协方差与历史均值。本轮改成“固定 FIT 参照下的二阶矩＋当前完整向量”：
如果多个头在整个错误片段中稳定维持一个偏移构型，减去窗口自身均值再计算协方差会把它消掉。
例如每步都是 (2,-2)，滚动协方差为零，但二阶交叉项仍为 -4。当前向量另外保留全局符号，因为 zzᵀ 与 (-z)(-z)ᵀ 相同。

## 明确公式

对实际缓存中一行 attention，先排除未来 key 和 tokenizer 所有特殊 key，在已保留的普通 key 上归一化。
提取 query-self 与 total-prompt 的逐 head 质量。稀疏缓存只描述已保存部分，未知尾部不会补零后冒称原始完整分布。
预测词 t 对应 q=P+t-1；q 自己是前一输入词。输出的特殊 token 不参加覆盖和窗口。

每层、每一种信号保留所有 head，减去同层该信号的共同分量：

    r[l,h,t] = x[l,h,t] - mean_h(x[l,h,t])
    z[l,t] = (r[l,t] - FIT_median[l]) / FIT_IQR[l]

第一行是投影到头间相对空间，输出仍有全部物理 head 坐标。它没有把 head 平均成一个检测值。
IQR 下限固定 1e-3，只避免近常量 head 的数值除零，不根据标签调节。
如选择 self+prompt，先各自去共同分量，再按 head×signal 顺序拼接，每层 64 维。

窗口只使用同一连续可观测片段的最近 K 个位置，截至当前；刚开始时使用已存在的短窗口。
缺测即断开，不跨缺口压缩时间，也不按 gold span 重置：

    C[l,t] = (1/n_t) * sum_s z[l,s] z[l,s]^T + ridge * I
    G[l]   = second moment of sampled FIT z[l] + ridge * I
    W[l,t] = G[l]^(-1/2) C[l,t] G[l]^(-1/2)
    T[l,t] = logm(W[l,t])

默认 K=16、ridge=0.1，均冻结。这里 C 是对固定 FIT 原点的二阶矩，不是减去窗口均值的协方差。
二阶矩须汇总交叉乘积；没有把历史均值单独当成信号或直接平均历史风险分数。

方法的输入为：

    raw          = 原当前 x 的 FIT 标准化向量
    contrast     = 当前完整 z
    moment       = [当前完整 z, vech_sqrt2(W-I)]
    log_moment   = [当前完整 z, vech_sqrt2(T)]
    log_diagonal = [当前完整 z, log(diag(C)/diag(G)) 的对角矩阵展开]

vech_sqrt2 对上三角非对角项乘 sqrt(2)，对应对称矩阵 Frobenius 内积。
log_diagonal 完全不使用 C/G 的交叉项，避免用完整白化后再取对角而偷偷保留头间关系。
矩阵对数保留矩阵坐标；不只取谱、行列式或总距离。当前向量保留交叉乘积无法区分的整体符号。

默认仅二阶部分用固定双哈希降到 256 维，物理 head-pair 坐标在变换前保持明确。
三种二阶对照使用相同投影，同一个层在全层和分段中使用相同 seed。
该投影可丢失信息；`--dimensions 0` 关闭它。当前所有 head 向量始终完整保留。
参考库的列中位数/IQR 标准化和近邻距离复用既有 fixed_graph 代码。它会改变原流形度量，因此只称 SPD 切空间特征检测，不称精确 affine-invariant 测地线检测。

## 训练与评价隔离

prepare / fit / score 不读取 NPZ 标签字段；原 metadata JSON 可能包含标签，但只取身份白名单。
从官方 TRAIN 按 source 拆分参考/校准；同来源不能跨 TEST。参考样本不按真假筛选，不用已知幻觉占比。
normalizer、G、近邻库来自参考组，阈值来自混合无标签校准组。分数方向固定为更少见更高，不用 TEST 标签翻转。
完整 TEST 冻结到 predictions 后才调用 evaluation.py 读取标签。没有监督探针混入主成绩。

表示设计受既有标签辅助审计启发；这点明确披露，不能声称整个研究过程从未见过标签。
默认全层主方法不按过去测试结果裁成中层，同时报告四个等宽层段；不按本次成绩挑选主结果。

## 可以推翻方案的结果

1. log_moment 不优于 contrast：本表示的二阶扩展没有检测增量。
2. log_moment 不优于 moment：没有证据支持矩阵对数的价值。
3. log_moment 不优于 log_diagonal：没有证据支持头间交叉项的价值。
4. 只在长续错提高、恢复正常明显变差：记录持续性与退出代价，不包装成首次事实错误预警。
5. 同宽层段没有中层优势：先前冻结监督读出的中层贡献不能转化为这条无标签读出优势。

统计关系不等于因果消息协同。当前只用 attention 标量，没有 W_O V 载荷或独立来源适用性标签，不能判断“关注的内容恰好是回答所需证据”。本阶段先检验表示增益，不再以完整机制识别作为检测实验的前置条件。
