# 2026-09-29 强基线上的消息约束修正：两轮实测

## 结论

已经把旧强来源/路由基线完整接回，补齐自然配对和GSM的来源观测，完成两轮修改及同边权分布的头打乱控制。代码和小样本实验完成，但整体检测优化目标未通过，不替换默认。

第二轮在旧阈值下134个官方错误token检出19→23，1353个正常token误报58→57；但AUROC .808717→.796963、AP .279095→.258838。净增加4TP并不等于总体区分度提高。GSM .634921→.650794、首错仍0/3；后者仅追平同六答旧单层attention AUC .650794。自然配对局部18个错误全漏。头结构匹配控制几乎相同，不能声称信息流正则获得机制优势。

本轮还给出明确的可达性反例：若|s−b|<=.1且b+.1<=阈值，该位置无论使用什么图都不可能报警。官方115个基线FN中21个满足；自然18/18错误和GSM3/3首错均满足。因而受限局部修正不能作为覆盖全部错误的完整主线；不是缺少某个高分起点，而是当前评分族本身排除了这些报警。

## 统一的建模分工

1. 来源约束观测：保留原有来源local/full logp差的单元均值，作为强基线锚点；它是来源依赖，尚非约束正确执行的判断。
2. 信息路由：原生A×||W_OV||提供来源/历史相对写入，保留旧16token窗口分数；本轮只尝试恢复窗口丢失的局部变化。
3. 输出采纳：原生g=d(z_actual−z_competitor)/d gate保留head/key/sign身份，测消息对当前选择的影响；不按其正负定义真假。
4. 局部推断：读/用消息重合只控制局部修正的共享程度，以凸优化连接观测与最终分数；没有错误起点要求、没有只升分的max传播。
5. 决策审计：冻结分数后检查排名、补回/丢失TP、新增/消除FP、步骤首错、修正可达性及匹配控制。

这是完整可运行的观测—推断流程，不是已经成立的“所有错误可检出”理论。第三项到事实约束执行之间仍缺可靠读出，不能用TV或JS替代。

## 第一轮：直接恢复逐token来源与路由

b=.75 R_pair(S_unit)+.25 R_route(R_window)。v=.75 R_pair(S_token)+.25 R_route(R_raw)，u=v−b。同一冻结秩参考。求解

    min_(|r|<=.1) 0.5||r−u||² + .05 Σ_i w_i |r_i−r_(i−1)|,
    s=b+r.

w由全部物理头内attention地址和signed native消息地址的Bhattacharyya重合、实际作用量权重形成。它不是语义边界或跨token总因果效应；公式与对偶说明见README/model.py。

## 当前根本问题与后续边界

- 局部定位问题与整段事实选择错误不同。有限残差可以修复部分邻近阈值的位置，但本轮的可达性检查已否定它覆盖全部案例的可能。
- 来源依赖、原生消息作用、相似状态持续均缺事实方向。错误答案可以高度依赖来源中出现的值；正确推导也会转用历史中间结果。上一轮“正确24误作下一次基数”的反例仍成立。
- 当前自动竞争词往往反映词法选择；相邻query的margin方向还可能不同。头/地址相似不能直接识别数值的操作数、结果、参照值角色。
- 仅更换平滑或放大权重没有证据解决这些问题；第一轮未截断token观测28TP/194FP已展示其代价。不能通过继续在暴露案例上调阈值包装成成功。

保留旧强基线为正式入口，本模块保留为局部修正与可达性审计实验。下一项独立研究应补充能够检验当前值/属性的适用关系的观测，并在正常推导、错误绑定、正确引用之间做同值对照；自动角色读出当前未实现。没有完成这项观测前，不把现有流程称为覆盖所有错误的理论。
