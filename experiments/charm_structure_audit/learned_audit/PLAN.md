# 已训练 CHARM 的多头与邻域审计

不训练新的 CHARM，不重采 attention，不改 checkpoint、旧预测、阈值或 train/test 划分。
目标是解释当前 QA charm_out（用户报告 AUROC 0.884927 / AP 0.538455），不是把审计变成新的检测成绩。

## 问题 → 实验 → 文件

1. 首错是否只反映熵：保留每个 layer/head 的图输入熵、自注意力与 RP/RR 质量。
   用原 fit/selection 训练仅预测 CHARM logit 的解释模型；test 检查拟合误差、残差排序。
   features.py / explain.py。解释模型不使用幻觉标签训练，不调整原检测阈值。
2. 多个头是否共同关注同一邻居：在 target、RP/RR、距离带内部重排权重。
   vector 同步重排全部通道；layer 每层同步重排 heads；head 各通道独立重排。
   三者保留各头权重多重集、熵、质量、节点属性、消息槽位和原分母。
   layer→head 的额外变化才更接近同层多头配对；vector→layer 测跨层配对。
   positive_head 只重排各通道正权重，保持每个 head 的非零位置，辅助排除稀疏形状改变。
   controls.py。记录实际改变比例、全零槽位、熵误差与多头重叠，不把空扰动当阴性证据。
2b. 是否实际存在并使用头间联合项：在fit的熵-logit关联中预选最多两个同层头对；
   在实际消息MLP中计算 M(full)-M(A=0)-M(B=0)+M(A=B=0)，再只去掉该项。
   每个GNN层单独干预，测最终logit，不把消息范数当成贡献。零是声明的参考值，
   存在非加性不等于幻觉语义机制；两对头的阴性结果不排除其他头。messages.py。
3. 首错后利用了什么邻居状态：只在一个 GNN 层的消息 MLP 入口替换来源状态。
   group_mean 消除同组来源个性；same_label 与 other_label 用相同合格边集合，
   仅替换 RR 来源的状态，不改变目标状态/边属性/分母。来源标签只用于事后干预。
   messages.py。每层分别运行，允许干预向后续计算传播；不是互相独立的逐边因果效应。
4. 哪一部分改善首次错误、后续起点和续写：每个控制均分角色报告原/控制排序，
   原阈值召回、方向性 logit 差与 source 等权置信区间；不从子集差减全量基线。
   report.py，复用 diagnose_saved 的角色定义与旧输出。

## 研究边界

熵来自 CHARM 实际保留图（含对角线）的归一化权重，不是原始完整 softmax 熵。
同层 head 配对控制也会改变边向量非零组合；拓扑槽位固定不等于新 attention 可由 LLM 产生。
干预的是检测器，不是 LLM 的事实推理。可说明它依赖什么，不能直接断言幻觉发生原因。
source donor 限同答、target之前、同粗 lag、相同 token 表面类别与 copy 状态；
两个 donor 类型都满足条件才干预。相近 mean entropy/self/degree 是粗匹配，不是语义等价。
无匹配要报告覆盖，不扩大范围。原 out-degree 全程固定，未来结构作用沿用旧 prefix 报告。
重用原 fit/select/test ID；不重分数据。test 已反复查看，所有新增结果均为探索性。
先核对真实模型重新推理与旧分数一致；不一致即停止，不能用错误 checkpoint 做解释。

## 实施顺序

先写本计划和函数骨架；再实现纯特征与受控变换、实际模型钩子、报告与入口；最后验证。
测试：熵精确不变、分组/维度不混、单头退化、合成多头交互见证、钩子移除、
同标签/异标签使用同一边、原模型无干预等价、旧分数校验、CPU端到端与续跑。
自然数据与高分模型只在用户服务器存在，本地测试不能称为真实机制发现。
