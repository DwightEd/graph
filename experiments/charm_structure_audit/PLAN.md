# CHARM 审计重构：一个 main，三个独立问题

2026-09-17；基于 graph/main @96cc93f。只改 CHARM 审计，不改其他实验和用户数据。

## 研究问题
1. 错误词检出在片段的什么位置？对已有 tokens.csv + spans.csv 复算，不运行神经网络。
2. 正常片段也聚集时还能区分吗？复用已锁定 pairs.json，所有模型和消融在同样配对上比较。
3. 哪个模型模块支持区分？分开报告冻结删除的敏感性和独立重训后的性能，不能混称因果贡献。

## 代码组织（先定接口，再实现）
- main.py：列出消融名字，明确选择 report / ablate / train / match。
- data.py：只读原 prepared 图、原训练划分、原预测/表格；写紧凑分数。
- model.py：原 CHARM 投影 → 逐边消息 → 聚合 → 节点更新 → readout；参数名兼容旧 checkpoint。
- ablations.py：删消息、删边属性、删来源状态、删角色标记、删残差、删prompt/history、禁中继、头/端点对照。
- train.py：同一原 fit/select/calibration 来源划分；BCE、selection AP、calibration 阈值；不碰 test 调参。
- evaluate.py：总体/同答排序、固定阈值命中、每一对的真假分数差。
- positions.py：不重叠片段映射、首/中/末、相对三等分、长度分层、逐词表。
- matching.py：原配对协议收拢到一个文件，仅用于配对，不把统计特征送入模型。

删除多套 deep/learned/cluster 的旧运行入口及大段特征/探针传输链；旧实现可从96cc93f读取。
不迁移旧的代理回归器、头对筛选和大规模表征导出；这些不是当前模块删除消融的必要步骤。
旧结果仍可读。原 prepared 图无需重建，原模型无需重训；不把重构声称为新实验成绩。

## 保持不变
head通道顺序、post-token_i→label_i、原消息MLP/残差/ReLU、官方/来源划分、阈值严格大于。
原配对只合并重叠标注、不合并相邻标注；同回答等长、相近位置/重复、同首词表面类、同此前错误状态。
所有结果只在共同token/完整配对上比较。长短片段、缺对照和校准分母明确保存。

## 本次额外可直接检验
纯时间平滑是否主要改善段内延续？节点属性、边向量、邻居身份、多头同端点组合必须分开。
重连同时报告边槽位变化与真正邻接集合变化，不能以槽位置换冒充新拓扑。
所有冻结图删边保留原归一化分母；独立重训按变体图重新计算分母。
no_relay发送源节点的自身更新状态，不冻结源节点的深层MLP变换；一层时与完整模型一致。
