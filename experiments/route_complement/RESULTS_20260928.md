# 继承有效路由，保留完整逐头消息：实测与下一步

2026-09-28。本轮使用 research-lit、experiment-plan、run-experiment，先冻结方法再采集和评分。已完成真实 8B FP32 的 48 答、6463 token 新增 V/逐头向量采集；原完整注意力、门导数及残差响应复用并对齐。不是旧2700答重跑。结果未达到检测改进门槛，不替换默认、不启动全测试。

## 哪个旧方法有效，缺陷是什么

QA 官方 test 的 token AUROC：raw_route .787109；offline16 路由 .814420；来源条件 pair 单元均值 .878533；**预先固定的 .75×来源秩＋.25×路由秩 .890665**。最后一项确为无标签固定组合，即使开发选择碰巧也选中它，不能把固定候选误称监督选型。这里“最强”限定现有无监督 QA 基线，不覆盖旧监督模型。

来源单元均值在单元内部排序恒为 .5；路由在混合单元内部 .831193；固定组合 .831074。因此简单融合有效有具体原因：来源条件似然提供单元尺度，路由提供局部排序。不能只看总体 AUROC 就否定或夸大其中一项。

固定组合原冻结阈值的 QA 正常 token FPR=.0170074，错 token recall=.2550733；各错段起点 recall=.1385281，每答第一个错 token recall=.0875；正常回答至少一次误报=.1054054。它对短错、起点、来源错误绑定和局部语义限制不够敏感，且16离线平滑可能跨越边界。

## 本轮具体改变了什么

原头消息定义为 m[l,h,t,j]=A[l,h,t,j] W_O[l,h] V[l,j]。原路由先将消息范数相加，再比较 history 与 source，最后平均层。它丢失向量方向，也丢失物理头的联合模式。

新保存：GQA原生 V[32,8,key,128]；原 attention[32,32,query,key]；来源/历史/其他prompt三组的原生头合成向量[32,3,32,query,128]；完整跨头 Gram[32,3,query,32,32]。128是原模型头宽，与原 W_O 可恢复4096维输出向量，不是降维。三组只是索引视图；A、V、W_O保留每个key消息。没有按标签挑头，没有压成rank8。head_features只是派生视图，原始数据不丢弃。

定义 C=1-||sum_j m_j||/sum_j||m_j||，度量组内抵消。net_route 用每头合成消息的范数替换原消息范数和，其余来源范围和offline16窗口相同。同时保存逐头 source 条件 attention→payload JS、payload→|原生门导数| JS、跨头夹角。正向门导数表示推动被测输出，不表示来源事实正确。

检测评分/校准不读真假标签。12fit、12dev参考来源与8回归、16自然采样来源互斥；每任务4dev的无标签混合95分位阈值。混合分位数不等于保证5%正常FPR。自然样本来源似然缺缓存，保留NaN，不把整答当正确。

## 正负内部状态的具体差异

自然头饰、洋葱对照分别从token35、126开始，同对起点相同；措辞、长度、历史前缀不同，仍有混杂。标签仅用于以下事后诊断。

|同一物理头的来源消息抵消率|头饰正确局部|头饰错误局部|洋葱正确局部|洋葱错误局部|
|---|---:|---:|---:|---:|
|L14H2|.394291|.498333|.432624|.519800|
|L18H9|.367067|.514061|.362998|.488356|

这说明注意力读到了来源仍可能携带不同的方向结构；但不能据此认定错误因果。尤其跨两题source_cancel高局部AUROC的共同头42个，按每层头数条件置换的期望35.625，尾概率.1034：漂亮个例不足以确认通用头集合。

更值得保留的是**历史消息的两种相反逐头模式**。两题均“错误侧抵消率更大”（局部AUC>.75）的共同头53个，条件置换期望39.3125，12项Bonferroni后p=.0410；均“错误侧抵消率更小”（AUC<.25）的共同头31个，期望16.40625，调整后p=.000260。该检验只回答物理头身份的重合是否超过逐层随机交换，不把token当独立样本，不证明跨数据集普适或真假因果。

用独立12个无标签fit来源描述两组头：历史内部最近4词attention占比分别.3798与.2557，全头均值.4269。两组功能确有差别，但两者都比全头均值低，不能简单叫“局部头”和“证据头”。分组本身是标签辅助发现，**绝不能将53/31名单塞进最终无监督检测器**。

该结果支持继续保留物理头与关系结构，不支持“所有错词都少看prompt、高熵或更自洽”。全头平均抵消率变化很小，并把相反方向混合；简单net标量因此不是完整的逐头方法。历史因果形成与当前query敏感性也须分开。

## 如何组合成下一轮方法

1. **保留固定来源＋路由作为检测骨干。** 在其条件下检验新增读出的增量，不能只与弱单一标量比较。来源支持是模型的条件似然依赖，不是逻辑蕴含；错误绑定仍可能强依赖来源。
2. **读取模块：** 保存所有头的source地址分布、每token长度控制及payload，采用source条件JS定位读取地址/载荷的变化。reanchor只是待解释的信息选择事件，不是必然危险位置；所有token仍评分。
3. **整合模块：** 保存各头source/history向量、头内抵消和跨头Gram，利用谱/拓扑方法描述“哪些消息协同，哪些冲突”。不得用一个谱熵或全头均值取代原矩阵；本轮显示相反方向的历史头群可能被平均抹去。
4. **采纳模块：** 用原生门导数、残差/FFN与Fisher输出响应测量哪些消息真正影响当前候选。JS比较“读到的地址”与“影响输出的地址”，不是独立真假分数；负写入不自动算反证。ContextCite式贡献核验可用于少量强响应边，额外前向成本单报。
5. **持续模块：** 在完整头状态上检验从读取→整合→采纳到下一token的条件变化；只有精确历史消息干预能进一步支持传播作用，不能把图相邻自动等同错误继承。

下一主假设是**头功能条件下的联合状态转移偏离**，而非重建误差。先只用无标签fit轨迹的来源/历史分配、距离分布与向量关系定义头功能参考，保留每个物理头；在相近长度、位置、旧路由/来源分数、预测置信度条件下，比较当前完整头状态及前后转移与参考轨迹。可以用完整头轴上的核距离/条件经验分布评价联合偏离，不能以标签学习头方向或将二维局部成功硬编码。

数学对象为 Z_t={A[messages], C_source, C_history, Gram, JS_read/use, signed_output_response}_{l,h} 与 P_ref(Z_t | Z_{t-1}, position, length, baseline, confidence)。条件参考必须来源留出；高维参考稀疏和罕见正确生成是实际风险。偏离分数不是幻觉后验，不能标成P(hallucination)。实现时先与单头独立、打乱头身份、仅长度/置信度、仅原骨干对照，再在独立来源下固定误报预算判断是否值得融合。

这部分条件联合检测器尚未实现；本轮已实现的是完整采集、net/JS固定候选及事后逐头机制诊断。使用本轮标签发现模式后，即使检测器训练无标签，也必须称标签辅助机制开发，并用新来源检验。稳定错绑可能内部平稳且强来源作用，现有观测没有“必检”的理论保证。
