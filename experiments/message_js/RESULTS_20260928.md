# JS、原生残差传输与选择作用：三轮实测

## 结论先行

已找到并复用论文启发的算子，完成新代码、真实 8B 测量、三轮无标签读出及正负对照。
**原生算子适合作为信息作用与传播的测量工具；三轮检测均未达到全错词检出且减少误报的目标。**
不把工程通过包装成方法成功，不替换现有检测默认值，不启动成本更大的全测试。
这些是历史已暴露样本上的探索性回归，不是未见测试确认。

第一轮重算 84 答/12,234 token；第二轮重算 48 答/6,463 token；另对 16 条自然采样
执行真实历史消息干预。第三轮直接复用第二轮完整算子，没有再跑旧监督模型。
本轮无自然标签训练、挑头、选权重或阈值搜索；标签只用于历史先验、冻结后评价与机制诊断。

## 1. 原项目里是什么方法

- `experiments/native_support/observable_run.py` 与
  `teaching/state_audit/src/state_audit/observable_transport.py`：原生残差/FFN pullback、
  Fisher 响应、条件 Gram。旧版随机 rank-8、来源组和角色聚合；四答条件核 AUROC .6794，
  低于 raw .7554 和离线均值 .7846，不能把它称为已经有效的检测器。
- `experiments/decision_risk_flow/`：后来加入窗口、层带、图量和监督读出。
  旧八答新拓扑仅 19/134 错词、61/1353 误报，答内 AUROC .6209。
- 用户给出的 D/R JS 在 `experiments/unsupervised_token_graph/`。
  旧 219 个训练回答的部分诊断中，全错词 AUROC .4600、打乱 .4599；起点 .5897、打乱 .5851。
  不是 2,700 答测试结果，也没有充分支持真实拓扑收益。

## 2. 论文理论适用到哪里

[原论文](https://arxiv.org/html/2605.14258v1#A2)的局部实验使用孤立单 token、无 KV 的 block；
图节点是残差坐标，相关边来自跨样本激活，累计算子还有 rank-512 近似。
不能直接把它的谱量解释为本项目的完整上下文 token 信息图或幻觉概率。

可迁移的是：沿真实计算轨迹量化 Jacobian、残差直通、FFN 变换与输出响应。
[ALTI](https://aclanthology.org/2022.emnlp-main.595/)及
[DecompX](https://aclanthology.org/2023.acl-long.149/)也支持纳入残差、归一化和 FFN；
它们不替本项目证明检测增益。详细原文审阅见 `OPERATOR_LITERATURE_CHECK_ZH.md`。

对 attention 后状态 u 与 h=u+MLP(N(u))，令 B 为同一个输出目标的梯度：

\[
B_u=B_h+J_{\mathrm{MLP}\circ N}^{\top} B_h,\qquad
g_m=\underbrace{m^\top B_h}_{\text{残差直通}}+
\underbrace{m^\top(B_u-B_h)}_{\text{FFN 变换}}.
\]

目标是实际词与自动最强竞争词的 logit 差。上述恒等式可解释消息怎样推动选择，
但正号不能解释为事实支持。跨层作用之和也不是互不重叠的事实贡献账本；
本轮求和仅表示同时缩放这些门时的方向导数。

输出空间采用完整词表 Fisher，三个明确门方向 P/H/M 分别缩放 prompt 消息、历史消息、MLP 写入：

\[
K_{ab}=(Jd_a)^\top[\operatorname{diag}(p)-pp^\top](Jd_b).
\]

保留完整 4096 维归一化最终状态和三个完整切向量，无随机 rank-8。
**这是三个指定方向的精确响应，不是完整消息门 Jacobian；组内相消仍可能存在。**

JS 与该算子在同一输出字母表上的联系为：

\[
\lim_{\epsilon\to0}\frac{\mathrm{JS}(p(g+\epsilon e_P),p(g+\epsilon e_H))}{\epsilon^2}
=\frac{K_{PP}+K_{HH}-2K_{PH}}8.
\]

这里用自然对数。原 D/R JS 则在 prompt 地址分布上计算，保留原分支质量与缺测 mask；
二者不能混为同一个量。有符号 Jacobian 不是概率转移矩阵，不能借数据处理不等式证明语义正确。

## 3. 可复用的方法论与实际实现

1. **读取地址**：保留每层、每头、每个 query 与 key 的 attention 和选择门导数。
   计算原地址 D/R JS、分支质量、相对 JS 与读取/作用地址错位。
   同头 ancestry 是代理连接，明确不冒称真实跨层来源守恒。
2. **整合和输出使用**：逐消息拆残差/FFN，保存正负作用及抵消，再用完整输出 Fisher 度量。
   不先将原始层、头、key 合并成窗口或 rank-8。
3. **历史传播**：在历史中的一个真实消息处施加 1±.01 门控，原生重算后续所有位置。
   保存完整未来状态差与输出 JS；原文字固定，不声称跨离散采样或自由生成修复。
4. **无监督检测假设**：分别检验异常组合和有符号候选竞争；全部规则先冻结，
   用来源隔离的无标签混合 dev 分布固定阈值。最终 scalar 读出仍会聚合，原始数组继续保留。
5. **独立评价**：官方字符标签重新映射；分别报每个错段、正常词、自然配对与打乱连接。
   不把“有读取”“有影响”“有持续”自动升级为“能辨真假”。

自然样本来自同一模型的原采样文字，本轮 FP32 重放冻结 BF16 权重，不是原 BF16 轨迹逐位复现。
RAGTruth 的其他生成器回答属于 observer 测量。prompt 没有预标实体、证据或约束；
prompt 总读取也包括指令和其他上下文，不能声称都读到了适用事实。

第一轮原先使用每任务 8 个 dev 来源时，主候选为 40/134、130/1353；

第二轮三项异常规则分别是低读取/低作用、强读取/抵消或错位、地址分歧/历史占优；

## 5. 自然正负采样究竟有什么差异

16 答全量测量，但仅两题四处局部声明有审阅标签：18 错词、13 正常词。
其余区域保持未知，不伪标正确。以下是逐 token、逐头原始量的展示摘要，不改检测器：

| 局部片段 | 正确头饰 | 错误头饰 | 正确洋葱 | 错误洋葱 |
|---|---:|---:|---:|---:|
| token 数 | 10 | 11 | 3 | 7 |
| 熵 <1 bit 的词数 | 5 | 7 | 2 | 5 |
| prompt 选择方向导数为正的词数 | 7 | 10 | 2 | 3 |
| prompt 读取量：每词头中位数，再平均 | .833 | .857 | .790 | .800 |
| prompt 有符号门导数均值 | .432 | 2.504 | .588 | −1.367 |
| 历史 Fisher 能量占比均值 | .491 | .355 | .446 | .378 |
| prompt FFN 抵消：每词头中位数，再平均 | .335 | .320 | .333 | .349 |

错误头饰不是“不读取、普遍高熵、历史更强”的实例。它有强且方向一致的 prompt 选择作用，
但选择的内容仍错误。洋葱有方向不同的信号，但也非所有错词一致。
正确和错误候选本身不同；这些是局部观测，不能据数值直接断言具体 prompt token 具有正确语义。

第一、二轮在固定阈值下均漏掉全部 18 错词。第三轮仅检出洋葱 1 词，误报正确头饰 1 词；
第三轮配对 AUROC 头饰 .2273、洋葱 .7619。局部排名改善不构成整段解决。
**这否定目前统一高熵/少回看/历史占优的充分判据，不证明完整内部表征没有可区分信息。**

## 6. 真正的历史传播与数值核验

16 答各按无标签 JS 事件选一条中层 prompt 消息干预；16 条均在后续状态产生非零影响。
每条干预都保持之前状态不变；当前位置有限差分对原门导数最大相对偏差 .005576。
未来响应存在不代表未来错误。事件并非人工幻觉起点，两个回答所选事件未做语义匹配，
所以本审计不声称错误比正确具有更长传播半衰期。

第二轮 48 答重放状态最大相对误差 1.65745e−5；残差＋FFN 对旧总门导数
最大相对偏差 4.59863e−6。三个全状态 JVP 的小扰动校验相对误差均约 .0002。
Gram 的微小负特征值 −4.93e−7 在 FP32 误差预算内，不强行解释成负 Fisher 能量。
18 项针对性测试通过，覆盖完整词表 JS 二阶系数、因果方向、末层不能传播到未来和门缩放不变性。
三轮 240 组官方逐例 AUROC/AP/报警计数与 90 个无标签阈值另行复算；这是同执行者数值核验，不冒称独立外审。

原始 confidence 的熵单位是 nat。初次展示误标 bit，已除以 ln(2) 后修正上表；
错误单位的初始诊断文件保留，评分、阈值及检测指标未改变。

## 7. 后续应改变哪一层假设

保留当前原生算子作为共同测量层，停止把谱强度、图连接或 JS 高低单独包装成真假规则。
下一项有意义的假设是**候选与具体来源地址的关系是否匹配**：同样读取很多 prompt，
错误候选可能利用了相同主题词却错误绑定范围、阶段、否定或数值。需要比较完整的
“来源地址 × 物理头 × 候选响应 × 后续接收位置”，而非再次只加入一个异常标量。

不预标实体；自动竞争候选也不能固定等同正确候选。可在无标签参考中学习来源内相容关系，
通过保持词项但交换绑定的自监督任务发现可用方向，然后固定后在自然样本验证。
伪任务方向是否迁移必须先检验；构造任务准确不冒称自然幻觉检测成功。
旧项目已有关系交换和 probe 工作，下一步须先复用其缓存、反例和失败记录，不能重命名再做。
这部分是下一阶段设计，**尚未实现或得到新 AUROC**，本报告不把它算成本轮成果。
