# Sequential choice feedback pilot

Measures a single source-attention event through native cached decoding, fixed text, first-token replacement and greedy continuation. Four prefixes come from two exposed GSM responses. This is an explicitly selected mechanism diagnostic, not a new hallucination detector.

Every step retains the newest K/V column for every layer and GQA KV head, final hidden state, emitted token and the fixed logit(24)−logit(20) contrast. All descendants run natively. The fixed contrast is interpretable at aligned number choices; it is not a factual score at arbitrary intermediate tokens. The relation repair (`new`→`original`) is a manual, single-token intervention, not an automatic binding readout.

From the graph repository:

```bash
export PYTHONPATH=.:teaching/state_audit/src
export OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 MKL_NUM_THREADS=4
research_python=/share/home/tm902089733300000/a903202310/lys/conda_envs/research/bin/python
"$research_python" -m unittest experiments.choice_feedback.test_native -v
"$research_python" -m experiments.choice_feedback.run --output outputs/choice_feedback_new
```

The output must be fresh. Model and prior manifest are local and unchanged; model weights stay BF16 with FP32 execution. Source logit doses are 0/±0.5, a one-event source-odds change. All three cached trajectories are checked against full-prefix recomputation with margin tolerance .005. The neighboring source control is not attention-mass matched. A forced first token changes later inputs, not the prediction preceding it. Greedy output is limited to 32 tokens and is not a complete-answer accuracy evaluation.

The fixed head L17H27 was selected in a prior exposed wrong-answer diagnostic, then reused across the four prefixes. The two answers share one problem. They were originally generated by a different model; the new intervention runs use an 8B observer, not the original generation process. No natural generalization or detector improvement can be inferred from this small sample. The original detector remains unchanged.

After the run, use `python -m experiments.choice_feedback.analyze --output outputs/choice_feedback_new` to produce the summary and plot. The optional, separately frozen balanced controls run with `python -m experiments.choice_feedback.controlled --output outputs/choice_feedback_controlled_new`: 128 constructed prompts and 256 forward passes, with no training or detector evaluation.
