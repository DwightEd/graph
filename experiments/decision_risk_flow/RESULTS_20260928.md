# 新 Fisher 响应拓扑方法：8 答实测结果

已经实际运行新代码、8B 前向及消息梯度、训练和冻结评价；不是旧 2,700 答复跑。**首版未达到检测目标，不能替换普通 probe。**

68 个完整回答共 10,702 token：36 fit 来源、24 dev 来源、8 个已暴露回归来源，来源两两无交集。指定 8 答共 1,487 token，9 个官方错误区间含 134 token。全部 8 答及同来源其他回答排除训练、开发。监督拟合只使用 fit/dev 自然标签；回归标签在冻结全部预测后读入。

主候选是置信度/位置、来源 OOF probe、有符号消息响应、Fisher 核统计与无向功能图的 99 维 logistic 读出。所有位置都测量，不用熵或 reanchor 规则预筛。核测量无标签，最终读出有监督。尚未实现风险 probe 消息梯度及完整历史形成路径。

## 逐段检测

各任务阈值来自 dev 正常 token 的 95% 分位数，严格 score > threshold。下表是报警错误 token / 官方区间 token；至少一个词报警不等于识别了该片段的关键错误。

| 样本与错误 | 普通 probe | probe＋响应核 | 再加入拓扑（主候选） |
|---|---:|---:|---:|
| 养老金 5% 税率 | 0/15 | 1/15 | 1/15 |
| 烤架高温预热 | 3/15 | 2/15 | 1/15 |
| 烹饪及静置时长 | 3/53 | 14/53 | 11/53 |
| 否认折被说明 | 3/13 | 0/13 | 0/13 |
| for four days | 0/3 | 0/3 | 0/3 |
| 9022 营业时间 | 4/13 | 3/13 | 2/13 |
| intimate | 0/3 | 0/3 | 0/3 |
| WiFi | 3/3 | 1/3 | 2/3 |
| 7305 每天营业时间相同 | 10/16 | 3/16 | 2/16 |

主候选 6/9 段有任意报警，**0/9 段完整覆盖，首错 token 仅 1/9 检出**，错误 token 总召回 19/134 = 14.18%。折被否认、时长限定、intimate 三段仍完全漏检。

养老金只在 `taxed` 报警，关键 `5%` 没有报警；预热段只在 `unspecified` 的 `un` 词片报警；7305 只在冒号和 `PM` 报警。因此不能把“片段内有一个高分词”包装成解决语义错误。

两个官方无标错区间的正常对照：11907 为 0/206，12015 为 0/145；普通 probe 和去拓扑版本也都是零。所有 8 答的正常 token 主候选误报 61/1353 = 4.51%，正常对照以外仍有误报。

## 同批对照

以下 AUROC 是六个含错误回答的逐回答 AUROC 算术均值，不是全测试 AUROC，也不是独立泛化估计。

| 方法 | 六答平均 AUROC | 错误 token 检出 /134 | 正常误报 /1353 |
|---|---:|---:|---:|
| confidence | 0.6250 | 11 | 61 |
| probe | 0.7718 | 26 | 73 |
| native | 0.6017 | 31 | 86 |
| kernel | 0.5985 | 25 | 61 |
| topology | 0.5409 | 21 | 71 |
| probe_kernel | 0.6834 | 24 | 64 |
| new_method | 0.6209 | 19 | 61 |
| shuffled | 0.5684 | 22 | 70 |

在包含 probe 的直接对照中，加入图量后六个含错回答的 AUROC 全部下降；平均从 0.6834 降至 0.6209，错误 token 检出从 24 降至 19。普通 probe 为 0.7718、26 个错误 token。当前小样本实验不支持拓扑增益。随机方向对照 `shuffled` 不含 probe，只能与 `topology` 直接比较；不将其与主候选差异都归因于图。

整答正常 max 的 95% 分位阈值另存于 calibration.json，不能用 token 5% 阈值声称整答 5% 误报保证。主候选在整答阈值下仅 12219 整答出现报警，而它的官方错误区间仍完全漏检：报警在该答标注正常的位置。这不构成正确检测。

## 数值验证与实现边界

- 初次 BF16 分块重放在 12045 失败；完整失败产物保留在 archive_bf16，没有混入当前分数。
- 保持冻结 BF16 权重，以 FP32 做前向和输入梯度；68 答所有位置相对完整前向最大 logit 偏差 0.000723958、状态相对偏差 0.0000239666，均低于事前固定容差。
- 自动选定一条 prompt 消息的 2%/5% 有限扰动与投影导数相对偏差 0.00010013/0.00003304。
- 单边 Fisher 能量 8 维估计约 0.030385，完整有限差分约 0.019667，16 维约 0.020862；低秩估计有明显抽样误差，不能宣称完整谱或拓扑稳定性。
- 新响应采集 840.17 秒，GPU 峰值 19.49 GiB；68 答及全部有效 token 均完成，没有截断或跳过。
- 8 项针对性测试通过；直接从官方字符区间复算 72 组指标（包含 AUROC/AP/计数），与冻结结果一致，开发阈值和来源隔离也复核通过。这是同一执行者的独立数值实现，不冒称 fresh 外审。
- 所有状态属于 Llama-3.1-8B observer 重放，保留固定过去 K/V。节点将头/层池化成两个深度带与窗口，不是完整逐头图，更不是完整历史传播图。

失败说明本版特征聚合与读出没有兑现检测收益；不能据此推断大模型内部不存在可区分信号。也不据这 8 答事后调整模型、阈值或取最优候选来改写结果。
