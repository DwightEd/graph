# 逐 token 片段维持状态：评分前方案

状态：IMPLEMENTING。复用18答既有全32层×32头attention与原生局部消息导数；不重新采集模型。范围为8官方RAG回归、4自然配对、6GSM配对；均为已暴露开发案例。无自然标签拟合、选头、参数搜索。原缓存和默认检测器不改。

问题：局部历史复用、读取地址稳定、缺少额外prompt读取是否形成可量化的维持状态？它是否只捕获所有生成共有的近邻偏好？同质标签不是语义单元标注。

每头保留两个历史分布：绝对地址、相对生成距离。对当前分布与此前递推原型计算Bhattacharyya重合；固定地址复用与平移续写分开保存。prompt新读取定义为相对此前prompt读取原型的正增量总量；只叫地址刷新，不叫新语义信息。

连续系数 c = max(绝对重合,相对重合) * (1-prompt刷新)，无历史时为0。系数不是校准概率。每头有效年龄 N_t=1+c_t N_(t-1)，原型按此前权重c_t N_(t-1)与当前权重1更新。头之间不先平均；记录1024头全部轨迹。

隐式片段成员权 B_(t,j)=prod_(u=j+1..t)c_u，无硬标点/长度切分；以实际历史attention计算成员内读取量。保持距离桶质量的端点交换期望单独计算，纯lag1必须超额复用为0。没有足够可交换质量时明确报告控制识别力有限。

原生导数正负分开记录prompt/history作用量与模式稳定性；其目标为当前实际词对候选的margin，跨词目标不同，因此不将符号稳定直接解释为同一语义内容或参与状态系数。当前缓存没有完整根来源/跨时间因果重算。

算法验证：前缀一致、无未来key、纯lag1距离超额为0、固定远锚点与平移前词模式区分、刷新引起状态降低、风险统计显式权重等价、正负作用不相消、头随机置换对照。

冻结比较：原raw route、causal16、offline16、状态加权统计、实际attention×成员权加权统计。旧fixed基线独立保存；新组合只比较去单元平均的token来源与上述路由，另存来源/路由共同状态统计。新分数沿用旧秩参考只作尺度受控探索，不能把阈值变化叫相同FPR。
