# 原生来源支持检测：统一定义

2026-09-22。实现对应 `experiments/native_support` 与 `state_audit/native_forward.py`。
用户要求检测不以消融、完整因果机制解码或人工判断来源适用性为前置条件。
本协议替代此前“先选回看点，再定义正确候选，再求下游梯度”的检测提议；旧机制审计保留。

## 问题与假设

检测单位是每个已经观察到的回答 token。只知道 prompt、回答前缀和当前实际 token，
不知道正确答案、幻觉标签或正确来源。teacher forcing 每个预测位置的可见输入严格止于
当前 token 之前；离线分块前向可含后续行，但原生因果掩码禁止当前行访问它们。

检验一个具体假设：相对模型自己的竞争输出，错误 token 的 prompt 净支持可能较低；
后续 token 若以相似的逐头写入模式正向读取这些历史 token，可能延续这种来源支持不足。
因此统一问“当前选择得到多少直接来源支持，又继承了多少此前的来源支持”，
而不是把熵、注意力、梯度任意加权，或预设每个错误都存在 local→远处转换。

这是无标签、免训练的候选检测器。公式有明确运算意义，不意味着已证明能区分幻觉。

## 唯一计算底座：观察到的残差写入账本

对实际 token y_t，使用原生 logits 最大的另一个 token 作为比较词 c_t。
两者都不来自正确/错误候选表。不改变模型分布，不额外生成回答。
读出方向为：

\[
d_t=\gamma\odot(W_{y_t}-W_{c_t})/s_t^{final}.
\]

这里固定当前运行的最终 RMS 分母，只用于事后数值分解，不替换任何层的 norm。
逐层、逐头、逐源的消息与写入为：

\[
m_{\ell h j\to t}=a_{\ell h tj}W^O_{\ell h}v_{\ell h j},\qquad
b_{\ell h tj}=d_t^\top m_{\ell h j\to t}.
\]

每条边保存 attention、b 和实际投影后消息的平方范数。
后者通过 W_O 的 Gram 矩阵计算，不显式保存 [层,头,来源,残差维度] 巨型张量。
FFN 写入 f_l、初始残差、bias、重建误差和浮点加法误差单独记录；加总可还原最终 logit gap。
账本是加性记账，不是下游因果效应或语义适用性证明。

预算 B_t 是所有边 |b|、各 FFN |f|、初始残差投影绝对值及各 bias/数值项绝对值之和。
不把多个头先平均或先抵消，再计算预算。B=0 时支持记为中性 0。

## 直接项与历史项由同一预算定义

普通 prompt token 的直接支持：

\[
a_t=\frac{\sum_{\ell,h,j\in prompt}b_{\ell h tj}}{B_t}.
\]

普通 token 排除 tokenizer 定义的特殊 token。prompt 包括问题和说明，
所以这里必须称为“prompt 来源支持”，不能改称“适用事实证据”。

对每个 token 构造一个功能模式 f_t：依次保存每个物理 layer/head 下，
prompt/history/special 三种来源的正写入量和负写入量，展平后作 L2 归一化。
没有平均头、随机投影、挑选事后高分头或用标签训练表示。

当前 token 与历史 j 的模式相似性、历史边权为：

\[
C_{tj}=\max(0,f_t^\top f_j),\qquad
W_{tj}=\frac{\sum_{\ell,h}[b_{\ell h tj}]_+}{B_t}C_{tj},\quad j<t.
\]

只沿正向支持当前选择的历史边继承。负向历史写入可能涉及纠正，不自动复制其旧风险。
相似性保留层头身份及正负模式；attention 形状相似本身不触发风险。
这仍然是“功能模式相似”的代理，不证明两个 token 表达同一命题。

统一递推：

\[
S_t=a_t+\sum_{j<t}W_{tj}S_j,\qquad
R_t=-S_t=\underbrace{-a_t}_{direct\_risk}
+\underbrace{\sum_{j<t}W_{tj}R_j}_{inherited\_risk}.
\]

R 越高代表来源净支持越低；负分不是错误，0 不是判定阈值，R 不是概率。
所有 token 都评分，不通过回看、高熵、词性、金标 onset 或固定窗口挑选位置。
既往支持良好的历史也能降低当前风险；新 prompt 支持能抵消旧的负支持。
没有“首个告警之后全部标错”或“标注末尾自动清零”。

因为 |a_t|+sum_j W_tj <= 1，从空历史开始有 |S_t|<=1。
W 严格下三角，按时间顺序一次完成。也可写成 S=a+WS，
但实现不求逆、不展开随机游走、不另外训练 GNN。
它是根据原生写入建立的检测图，不是 Transformer 的精确跨 token 因果归因。

FFN、初始残差和特殊 token 占据预算，但不获得未经验证的来源身份。
不能把 FFN 正向等同于正确，或把 FFN 负向等同于幻觉。
正负 FFN 同等幅度只改变支持预算的尺度；其作用方向保留作解释字段。
高 FFN 占比可能使分数趋近中性，不能据此宣称识别了参数偏置。

## 回看与熵的位置

回看是解释层：每个头寻找 prompt 中质量最大的连续 8-token 区域，
比较该同一区域在此前至多 3 个已观察 query 中的平均读取量。
增加 >=0.1 的头计作读取增强。它可以是远处→另一个远处片段；不要求 local 占优。
首个 query 缺少历史比较，输出 NaN/空值，不补成“没有回看”。
窗口不代表语义子句或已确认适用证据；这些参数不进入 R。

熵、实际 token 惊讶度、prompt 读取量、FFN 正负写入、总抵消程度和残差层轨迹
都作为解释量。高熵不是种子，低熵不会关闭检测，强冲突不直接判错。
首错是评估标签定义；检测输出连续分数，不把首次高分重新定义为真实首错。

## 研究分析的一致顺序

1. 每个 token 都产生原生写入账本，先冻结 R、direct_risk 和 inherited_risk。
2. 小样本查看高读取时 direct_risk 是否仍高，以及哪些层/头/来源形成这个值。
3. 仅在真实已生成后续存在时，查看 inherited_risk 是否延续，以及新来源支持是否使它下降。
4. 需要评价时，单独运行 evaluate 后才读取标签，分别报告所有错误、每答首错、span 起点和延续。

registered 主分数是 R，对照是直接项 -a。不是运行多种组合后挑最高 AUC。
两者共享全部 token 和输入。未设标签校准阈值，默认只输出排序分数。
实际自然数据没运行，就不报告检测成绩。用户本轮要求不全量测试。

## 不能由本方法保证的内容

- 不适用来源可能强烈支持错误内容，因此“有 prompt 支持”仍可能漏检。
- 原生竞争词可能是语法或措辞替代项，输出方向不是纯事实维度。
- 直接 logit 归因不是因果归因。已知后续擦除可误导 DLA：
  https://arxiv.org/abs/2310.07325 。本方法读取完整账本，不声称解决了来源级擦除归因。
- 来源支持弱的正常语法词可能分数偏高；自然数据验证前不能宣称有效。
- 相似头模式可能只是正常语法延续。只有先前分数通过正向来源边进入历史项；仍需正确续写对照。
- 只有 attention 的旧缓存不能重建 W_O A V 写入；旧审计的固定未来候选投影也不是本方法输入。

## 软件及样本边界

复用 teaching 的 ModelAdapter、native_hooks 和 KV replay；批量 GPU 投影与原
projected_messages/residual ledger 逐项核对，原机制审计保留原入口。
新采集显式 with_grad=False，并在 no_grad 中执行；没有 autograd.grad、backward、删边或替换消息。
默认每次前向 8 个连续 query，逐 token 保存当前行的 attention，并裁掉被因果屏蔽的后续列。
KV 只前进；缺失目标之间的已有位置仅 prefill。投影后的来源 value energy 随 KV 增量缓存，
不对每个 query 重算所有旧来源。完整残差、逐头残差向量和 FFN 中间激活不搬到 CPU，
只保留所需投影及原有 head/source/group 标量字段。默认 NPZ 不压缩，压缩是可选的存储参数。
query chunk 与压缩方式不进入科学设置的续跑身份，实际值写入缓存/计时；允许复用已有逐步结果。
float32/bfloat16 软件核对覆盖分块数值误差、块内无未来泄漏及混合缓存续跑，不声称逐 bit 一致。
默认提供 4 个原始自然前缀，322 个已观察回答 token，不拼接任何候选续写。
这些前缀在此前审计的决策词之前截止，不能据此证明真实首错或错误后的传播。
实际完整回答可以直接通过同一 token manifest 输入。

## 官方标签评价接入修复

`--dataset` 读取官方完整回答，复用 teaching 的 Example、encode_prompt、span 验证和 token_spans。
原回答按 observer tokenizer 做 teacher forcing；字符标注按同一次编码的 offsets 对齐。
模型输入单独写入 `input.json`，真实标签单独写入 `annotations.json`；评分函数不读取标签。
分数落盘后自动评价；`--stage evaluate` 直接寻找输出目录的标签文件，不重跑模型。
缺标签明确返回 unavailable，不造标签，也不覆盖原来有效的 evaluation.json。

默认只取 4 个匹配官方 ID；`--balanced` 是显式的标签分层诊断选择，
各取 2 个带错误标注/无错误标注的完整回答，不属于盲选总体测试。
这种选择用到了评价标签，但不训练检测器、不调整参数或选头；结果记录选择协议和阳性比例。
不能把这个小样本 AP/AUROC 称为整个 RAGTruth 的成绩。
官方标注的相邻但不重叠 token span 保留各自 onset，特殊/空 offset token 不计入评价。
