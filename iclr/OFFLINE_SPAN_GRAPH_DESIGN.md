# 完整回答上的无监督片段图异常检测

状态：设计稿与接口骨架，尚未实现算法。日期：2026-09-16。
项目：DwightEd/graph；目录：experiments/unsupervised_token_graph/offline_span/。

## 1. 问题与这次改变

输入是 RAG 的原材料、问题、完整原回答，以及冻结观察模型的一次 teacher-forcing 观测。
输出是回答中每个 token 的异常分数及多个可能的错误区间，不要求生成时实时报警。

本方法允许使用目标位置之后已经生成的内容，包括后文对前面词的读取、同一事实的继续
表达、否定、纠正和转题。它们用于离线判断，不宣称模型生成早期词时看到了未来。

核心假设：一段内容可以在内部高度连贯、相互复用，却与它应当依赖的证据条件不相容。
连续聚集帮助定位范围；是否异常仍要由证据与片段的对应关系判断。正确片段同样连贯，
单词级错误也应保留。聚集性是待检验的结构假设，不是由标注片段直接生成的训练规则。

目标不是再给熵、prompt占比、图密度各分配一个手工权重，也不是训练边/节点重构器。
目标是学习一个关系评分器：这组证据、这个选择、这段复用内容是否相互对应？

## 2. 严格区分三种图关系

### 原生运算边

节点保留 token 位置、层和计算阶段。attention 边表示来源输入状态到当前 head 写入，
残差边和 FFN 写入单列。每条 attention 边保留物理 layer/head，不先平均。

    m[j → q, layer, head] = attention[q,j] * W_O[head] * value[j,head]

使用原始 post-WO 消息时必须由实际 V 和 W_O 计算，不能把 attention 标量或向量范数
冒充消息。跨多次读取的路径遵守层序；缺失的 prompt 内部边不能由同层随机游走补造。
不将残差或 FFN 统称为参数知识，不预设任何路径只传递真假信息。

### 材料上下文关系

另存原记录、句段、相邻限定词与值的关联。它们是材料结构，不是原模型因果边，
也不代表自动完成了命题抽取。同句并不必然共同支持一个事实。

被模型忽略的限定仍应留在检测视图中：不能只保留最大attention词，再让检测器判断
它漏读了什么。证据候选可以结合原读取、相近记录与原始文本检索；后两者不是原生读取。

### 离线后续读取关系

索引“后面哪些位置读过这个词/中继”，将这些后续状态提供给检测器。
原生边的方向不改；反向查索引、双向分析消息都是检测端操作，不能解释成未来影响过去。
未来位置自己的隐藏状态仍由原模型的因果前向产生；不需要重新生成或改掉原回答。

## 3. 基本单位是一段，而不是一个风险种子

对候选区间 I=[a,b)，构造四个视图：

    E_I：相近来源记录及限定上下文，包含可能被忽略的条件。
    B_I：回看或其他选择候选位置，以及其逐层状态。
    R_I：I 内部的实际读取、复用和内容表征。
    D_I：I 之后读取或提及该选择的节点，包含可能的纠正和切换。

第一版在指定长度预算内提出所有连续区间，必须包含单token区间和所有合法起点，
不以高熵、回看或已有异常分数作为唯一门槛。计算预算是 max_length，不是真实幻觉最长
长度的先验；更长区间覆盖与候选召回必须单独报告。后续再以固定、无标签规则减少候选。

熵是预测位置的属性，不是片段标签。后文也不是独立真值证据：同一错误被复述十次，
不能作为十份外部支持；共享来源/根的后代按同一依赖组汇总，保留复述次数作控制变量。

## 4. 唯一可学习主模块：EvidenceSpanScorer

分别编码来源侧 E 和回答侧 (B,R,D)，交互发生在明确的来源—选择—片段关系上：

    evidence_state = encode_evidence(E_I)
    response_state = encode_reuse(B_I, R_I, D_I)
    compatibility = compare(evidence_state, response_state, relation_attributes)

编码器使用关系类型、层/head及原生消息；输出前可以学习汇总，但不能先把不同head
的读取向量无条件平均。不要求先得到纯指针、不训练新SAE或完整自然命题提取器。

第一版采用两个小型关系编码器和一个匹配评分头；参数共享于所有片段。
固定两轮检测端关系聚合用于开发，不把“两层检测器”等同于“两跳真实推理”。
允许真实路径的选取与检测器的邻域汇总不同，但必须分别记录。

原始位置、来源ID、缓存文件名只用于组图和评价，不进入配对判别器。进入模型的是局部
角色、粗相对距离、关系类型和内容，不让模型靠绝对索引知道哪条连线被重接。

原 LLM 完全冻结。训练的是上述小模型，不修改原生消息计算、不把loss反传回大模型。
低维表示可以为检测服务，但在经功能干预确认前，不把某个维度命名为真值或纯指针。

## 5. 学什么：有条件的关系错接，而非伪造“坏图”

每张无标签原图产生两类配对对照，两类等量采样：

| 对照 | 改动 | 保留/匹配 |
|---|---|---|
| 来源—选择错接 | 给同一回答视图配另一相近来源上下文 | 同材料、主题/角色、节点数、来源质量、head和粗距离 |
| 选择—复用错接 | 给同一后续链配另一相近选择根 | 链内节点、边、词项复现、长度和局部集中程度 |

只重接检测器的视图对应；不改写保存的原生Q/K/V或残差，再让网络靠运算不闭合识别。
对照类型、原始/重接标志、真实来源ID都不能作为模型输入。

同时约束：仅重编号或改变存储顺序、而不改变实际对应关系，输出必须不变。
正常复制和话题连贯不能本身就是负例；困难对照优先取同材料而非随机跨话题。
不存在合适对照时跳过这项训练配对并报告数量，不删除该样本的测试位置。

用 s_theta(G) 表示配对相容logit：

    L = mean[softplus(-s_theta(observed)) + softplus(s_theta(reconnected))]

训练标签仅区分“观测配对/人工重接”。原始数据允许含错误，不能将原始图称为全正常；
重接也不一定违反真实语义，必须称为结构对照。学习到这个任务不保证获得幻觉检测能力。

关键风险：常见的自洽错绑也可能得到高相容分；只靠主题或原词复现也可能完成对比任务。
若统计匹配对照、来源留出与自然评价不支持增量，应否定这一学习代理，而非叠加更多损失。

## 6. 信息论的准确位置

在平衡的二分类对比训练达到理想最优时：

    s*(G) = log p_observed(G) / p_reconnected(G)

这是对指定重接分布的密度比，不是正确/幻觉的似然比。
仅当负配对确实来自 p(E|Z)p(R|Z) 时，条件形式才对应：

    log p(E,R|Z) / [p(E|Z)p(R|Z)]

其在真实联合分布下的期望才是条件互信息。这里的定制重接通常不满足该精确条件，
因此默认报告“匹配logit/关系异常”，不将它称为已估计的MI或丢失的事实bits。

Z用于匹配熵、长度、距离、话题、复现等常见差异，目的是检验关系在这些条件之外的增量。
将自然对数改成log2只改变单位，不构成创新；率失真理论不保证这一模型检测有效。

## 7. 聚集性进入片段推断，而不是事后抹平分数

先对整段图评分：a(I) = -s_theta(G_I)。在独立、含未知比例幻觉的校准来源上，
按长度等条件确定参考中心/尺度及异常预算。不能筛选“正常校准回答”。

然后为候选区间定义势：

    U(I) = length(I) * normalized_anomaly(I) - boundary_penalty

在互不重叠的区间集合上比较总势；未选中的token作为背景，允许空集合与单词片段。
拟采用区间动态规划获得最优区间，采用同一加性能量的前后向求和获得连续token边际分数。
它是检测器定义的结构分数/边际，不是经真值校准的幻觉概率。

边界代价仅表达不要无依据地到处碎裂，不学习金标span长度。长度校准用于防止长段天然
累积分数；同样连贯的正确片段必须作为对照。内部集中性已经在R_I编码，不再叠加一个
手工“越密越假”奖励。相邻被选区间的合并规则和最大长度预算需在实现阶段写清并冻结，
同时报告未合并结果，不能利用真实边界选择合并方式。

关键区别：对每段重新评估其证据关系，而不是将某个入口风险向邻居扩散。
一个较晚的矛盾、纠正或新来源可以改变早期片段的离线定位，但当前还没有保证能读懂它。
必要消融：同一套局部异常分数仅做平滑，对比真正的整段关系编码。

## 8. 现有数据、缺口与成本

已读取 graph@39d7549 的 ResponseCache/iter_channels：现有adapter支持逐头CSR、原始
token和offset；ResponseCache.load 当前没有加载hidden，而是将该字段设为None。
因此不能承诺旧attention缓存已经包含全部语义状态或post-WO消息。

先做字段清单：

| 内容 | 策略 |
|---|---|
| 原始token、prompt分区、逐头attention、offset | 优先复用当前cache和既有index/研究数据接口 |
| 原始材料与完整回答文本 | 按已有source/response ID接入，不根据幻觉标签筛选 |
| 隐藏状态、logits熵、V与FFN写入 | 确认是否已有缓存；缺少时由reanchor按明确小预算补采 |
| 金标 | 不进Sample/TokenGraph；最后由evaluation单独读取 |

不能从attention伪造缺失隐藏状态。只有attention的版本明确叫routing-only对照，
不与rich版本悄悄混用。原生query q对应预测位置q+1；缺失首个预测等情况报告覆盖，
离线使用后文不能修复不存在的原生观测。

24GB单卡：按样本加载，逐物理channel处理，稀疏边不扩成[L,H,N,N]。
不保存每条边的完整d_model向量；需要消息时共享V、保存索引与标量权重、复用W_O，
在小批内部形成或投影消息。后续保留边的预算只使用无标签参考确定并报告舍弃质量。
不枚举全部路径，不执行每个token的JVP或反事实前向，不先一次性采集全量高维状态。

## 9. 验收与停止条件

正式划分按source，训练/校准/测试互斥；所有任务用同一流水线，分任务报告后再合并。
先保存冻结分数，再加入标签。既有反复使用的test是探索集，不能称为全新确认结果。

最小消融：
1. 只节点 / 真实关系 / 相同属性的重接关系。
2. 前缀视图 / 完整回答视图（两者使用相同来源划分）。
3. 单token / 整段编码 / 单token分数事后平滑。
4. 单次读取 / 层序多次读取；含/不含后续读取索引。
5. 复制词项、熵、位置与长度基线；有序来源身份不进入模型的对照。

评价：token AUROC/AP、首错与延续、严格首错后；片段精确匹配与IoU匹配F1分别报告；
边界偏差、span结束后正常token误报、正常回答任意报警、短错误及高置信错误。
离线首次错误定位不是预测提前量。source bootstrap中同source所有token和span成组。
阈值、head、长度预算不根据test金标修改，不丢未覆盖token来提高指标。

判定：真实关系不胜无边/错接，则尚无图增量；整段不胜相同分数的平滑，则聚集性只是
平滑收益；后文不改善停止/边界，就不为它增加成本。不得因为对比loss下降而宣布成功。

## 10. 文献分工与引用

下列仅提供局部设计依据，不证明本设计有效：

- Propositional Probes：内容与绑定分开讨论。https://arxiv.org/abs/2406.19501
- Language Models Use Lookbacks to Track Beliefs：引用、地址、内容的功能验收。https://arxiv.org/abs/2505.14685
- Llama See, Llama Do：词项复现是一种竞争解释，不直接等于错误延续。https://arxiv.org/abs/2505.09338
- Latent Concept Disentanglement：提醒多跳要有可验证的概念身份。https://arxiv.org/abs/2506.16975
- ParamMute：检查FFN竞争，不将全部FFN视为先验。https://arxiv.org/abs/2502.15543
- RAGLens：内部特征可进入独立可学检测器；不沿用其有标签训练设定。https://arxiv.org/abs/2512.08892
- Causal Abstraction：机制图的功能验收留给小规模离线干预。https://jmlr.org/papers/v26/23-0058.html
- CoLA：节点/子结构对比不是新概念，贡献应来自RAG的配对对象与对照设计。https://arxiv.org/abs/2103.00113
- Semi-Markov CRF：借鉴段级评分与结构推断；不声称本文原来的监督训练就是无监督。https://papers.nips.cc/paper_files/paper/2004/hash/eb06b9db06012a7a4179b8f3cb5384d3-Abstract.html

当前没有新增AUROC/AP、没有自然机制成功结论。先审查设计，再逐模块填实现。
