# 幻觉检测的已有先验、证据边界与模型使用方式

日期：2026-09-24。目的：冻结已经获得的信息，使后续检测设计不再重复同一轮机制探索。
本次只记录结论与设计约束；没有实现新检测器、训练模型、重跑大模型或产生新 AUROC。

## 1. 研究目标与当前边界

目标仍是无自然标签训练的 token 级幻觉检测，允许使用未来 token。
不要求先穷尽实体关系、证明所有因果机制，或为每个样本人工标注证据类型。
机制读出服务于检测设计；机制尚未完全解释不应阻止比较已有检测方法。

当前已有反复出现的排序信号：来源—历史路由差异、时间连续性。
当前没有获得可稳定泛化的“FFN 在语义上支持/反对某条事实”的自动读出。
v3 修复了原始数据采集，不等于完成了语义解耦或提升检测效果。

用户的核心判断须作为显式研究假设保留：
- FFN 可能整合上下文、组织语义与逻辑、调节表达，不只是增强/削弱来源。
- 熵峰可能位于组织下一段语义之前；它不必与实体输出或金标首错重合。
- 低 prompt 新读取可以对应正常的信息保持；正常生成也可能具有连续、低熵的历史复用。
- 幻觉可能表现为缺乏有效新证据修正的状态延续；状态稳定本身不证明错误。

以上不是普遍定律。特别是“高熵必然组织语义”和“负向 FFN 必然负责措辞”都没有被证明。

## 3. 已有先验如何用于检测

| 编号 | 可用信息 | 当前证据 | 对检测模型的约束 | 不能声称 |
|---|---|---|---|---|
| P1 | Passage 与回答历史的路由分配具有排序信息 | B4/B32 raw route 均明显高于随机；见下表 | 保留 raw route 及逐头来源分配作为基线和观测 | 少读 prompt 就一定幻觉 |
| P2 | 连续性可提高整体排序 | B4/B32 均值平滑提高 AUROC；AP/高分精度不总改善 | 模型应表达保持；独立对比简单均值，不直接丢掉基线 | 收益来自已经证明的错误自锁机制 |
| P3 | 起始选择与后续延续需要不同观察尺度 | B32 entropy 首错 AUROC .7712、延续 .6022；route 延续 .7117 | 组织/更新/展开作为生成阶段，真假风险另行判断 | 熵峰就是金标首错 |
| P4 | 普通生成也有组织信息、引用来源、历史沿用的过程 | 用户假设、A 的正常对照、L 的 preplan/anchor 观察 | 在相近阶段与位置比较；不能用正常规律直接做风险 | 所有正常回答严格按固定阶段循环 |
| P5 | 功能方向与关注强度不是同一个量 | A 的逐头关注差异与敏感性差异不同 | attention 地址读取与消息响应分开保留 | 关注了来源便采纳了正确约束 |
| P6 | FFN 负向敏感性不能直接当反证据 | A 的负导数/正端点增量并存；B4 opposition 失败 | FFN 作为条件转换观测；保留方向结构与 RMS 变化，取消符号真假标签 | 所有负向 FFN 都是语法或都有利 |
| P7 | 来源正向作用缺口比简单反对量更值得保留作候选 | B4 local_source_deficit 优于 opposition，AP略优 raw | 独立候选与主基线并列，不能直接继承为语义真假 | 正向原文概率作用等于支持事实 |
| P8 | 物理头身份及其联合模式可能重要 | C 的 head_contrast 接近 full，layer_mean 较弱；A 头间方向混合 | 保留 layer×head×source，允许头的作用不同 | 协方差相关就是因果协同 |
| P9 | 位置、篇幅、来源数是强混杂因素 | B4 route 与位置高度相关，支持缺口相关较弱；C 的位置基线 | 在参考分布中控制这些条件，报告 within-answer 和前后半段 | 跨两个远隔位置的差值就是时间转移 |
| P10 | 机制更复杂未必排序更好 | B4 joint-state、继承、support-graph；B32 transport 对均值未占优 | 新组件必须有同样本 AUROC/AP或其他明确收益，失败候选降为诊断 | 图/HMM/更复杂结构本身构成创新或性能保证 |

正常生成的预期应明确进入参考模型：一次来源读取后，可以连续产生多个语法词/内容词，
不需要每一步重新读取 prompt；引用不同来源、熵上升或中间层冲突也可能是正常组织过程。
幻觉风险要观察这些过程与来源条件是否失配、失配是否持续。
“来源条件失配”仍是待实现的统计读出，不能直接把任一现有标量换名字当作已实现。

## 5. FFN：当前能判断什么，不能判断什么

常见 pre-norm 解码器中，attention 先把上下文聚合到 u，FFN 再逐位置变换：

    u_next = u + F(N(u))

FFN 可改变当前残差中用于后续预测的概念/关系/表达信息，也可调节置信度。
同一层已经算完的 attention 不会被事后改变；后续层的 Q/K/V 可以因残差改变而变化。
因此 FFN 的作用不能归结为改变全局/局部关注比例。

需要区分三种问题：
1. 读取：当前 query 是否读了来源块？
2. 功能传递：这些来源相关的变化，经 FFN 和后续层后是否影响输出分布？
3. 事实支持：这种影响是否保留了适用于当前断言的正确约束？

现有 attention / native sensitivity 分别提供前两类的部分观测。
第三类需要合适的语义目标或独立依据，不能由原文 log p 的正负号代替。
检测方法可以使用前两类的联合模式，不以完整解决第三类为启动条件。

“信息还可解码”“来源可辨认”“相似度更高”“梯度更大”也都不自动等于事实支持。
FFN可能将同一来源信息换一种表示，直接余弦减小不能自动判信息丢失。
跨层读出应考虑坐标变化；不把未校准 logit lens 的漂移当作语义改变的确定证据。

## 6. 应如何进入下一版检测：设计约束，不是假称已实现的架构

先保留当前已有效的 raw_route、同窗口均值和 local_source_deficit 作为独立比较对象。
当前 support/transport/state 中已实现的概率或图分数不重命名成事实错误概率。
当前 transport-functions 继续作为采集工具，不承担候选有效性筛选或真假标签生成。

观测保留 layer×head×source 的读取模式、来源消息响应和历史依赖；
FFN/residual/RMS 通道保留为上下文转换信息，不用固定符号决定风险。
熵、熵变化、来源集中变化用于描述生成阶段，不强制“熵高→高风险”。

后续统一模型应区分两个概念：
- 生成阶段：信息组织、状态更新、稳定展开。这些名称首先是解释假设，
  不能把无标签聚类编号直接当作已识别的语义阶段。
- 来源依赖状态：当前表达怎样依赖 prompt 与已有历史，新的读取是否伴随状态更新。
  这个状态同样不是天然的真假隐变量。

可考虑的统计目标是“给定阶段、位置和历史时，当前多头来源状态有多异常”，
例如 -log p_ref(X_t | C_t, X_<t)，而不是 -log p_LM(y_t | prefix)。
X 为保留结构的观测，C 为阶段/位置等上下文；这是下一步候选目标，尚未实现/验证。
无标签参考集可能混有错误，不可直接称其为全正常分布；异常也不等于幻觉。
阶段变量不能包含自然错误标签；使用未来信息须记录 offline 范围。

这一架构方向至少需要满足：
- 正常语义组织带来的高熵不应单独升高风险。
- 已被证据约束的状态可以在缺乏新读取时正常延续。
- 来源注意力峰只表示一次读取事件；只有观察到后续状态响应，才能称更新候选，
  也不能仅因出现峰就自动清除风险。
- 可疑依赖持续时允许风险保持，新来源信息出现时允许重新评估；
  不把前一次 token 的正向作用原样当作当前命题支持。
- 不强制所有物理头同向，模型需要容许角色差异。
- 不为“创新”再堆一个未经验证的状态模型；先冻结一个候选与同样本基线比较。
  joint_state 已退化的事实不能因换个名字而被忽略。

可以先测检测排名，不要求新增消融或每条关系的人工注释。
仍需同时看 AUROC、AP、top-rank误报、onset/continuation、within-answer、
前后半段及任务/生成器，避免把位置效应和延续多数类收益包装成首错突破。
这些是检测是否有效的必要评价，不是要求重新完成所有机制证明。

## 7. 不再重复的解释和流程

- 不再把 FFN 负值、来源反向作用、熵高、来源多杂单独定义为幻觉。
- 不再把词分布熵说成来源熵或语义熵；三者对象不同。
- 不再把高熵节点、标点边界、标注首错直接设为同一个事件。
- 不再把“正常也有连续性”忽略掉，只解释错误 span 的内部聚集。
- 不再以全部头平均或整句概率的单个标量替代信息读取、传递、保持三个问题。
- 不再生成语义候选并用自我判决决定原文是否值得测量。
- 不再为没有机制结论而阻止检测迭代；也不为继续迭代而宣称未知机制已被证明。
- 本次不更改分数、不加训练、不全量测试；后续实现另行标注版本和新结果。
