# 检测证据、可识别边界与下一阶段模型

本记录汇总 `choice_state_v2` 的四答审计，提出下一步可检验的检测架构。
方法实现见 [CONDITIONAL_CHOICE_STATE.md](CONDITIONAL_CHOICE_STATE.md)，

## 2. 支持和抑制，哪些能分、哪些不能分

指定上下文、目标词 y、竞争词 c 和分解规则后，可以计算来源 g 的相对作用：

\[
d_g(y,c)=\langle W_U[y]-W_U[c],v_g\rangle.
\]

这里 v_g 指已按当前分解映射到最终读出空间的来源分量。
当前方法固定 attention pattern / RMS scale，采用 SiLU 割线和乘法等分；
它是值路径分解，不是包括 Q/K 路由改变的完整因果导数。
归因求和接近原生 margin 只说明账本重构，不自动证明分解唯一或因果忠实。

**d<0 能说明相对选择受到抑制，不能单独说明目标 logit 被压低，更不能说明事实被反驳。**
例如来源对 (y,c) 的作用分别为 (+1,+3) 或 (-3,-1)，两者 d 都是 -2，
但前者仍提高了目标 logit。给候选作用同时加常数不会改变任何差值。

现有缓存可以从 (0,-d_1,-d_2,...) 重建候选集合内的中心化相对作用，
不能恢复唯一的绝对共同分量、未捕获词表的作用，或自动给每个方向贴事实/语法标签。
`group_choice_factor` 正是相对选择因子的归一化，并非来源单独生成该词的原生条件概率。

负向 FFN 作用也可能来自竞争词增强、词形收敛或事实选择。
此前逐头审计中的末八层 FFN 均值在正常/错误 token 上均为正；
“FFN 在两类回答上都负，因此只负责语义收敛”并非当前结果。
FFN 已计入 root attribution，不应再加一遍，也不应统一剔除其负值。

进一步区分内容，需要明确对比问题：

1. 事实对比：相同语法框架，替换实体、数字、范围或否定关系。
2. 表达对比：保持事实，改变词形、同义表达或句法实现。
3. 分别记录相同来源、头和 FFN 对这些对比的作用向量；检验对比改变时结论是否保持。

多 token 对比要使用声明清楚的序列评分与对齐，不能把单 token 的候选排名当语义身份。
候选可自动提出并筛选，不要求逐样本手工标注证据类型；自动候选也可能含错，
应在小规模机制样本上核验并报告覆盖率。现有 top-3 竞争词不能保证都是有效事实对比。
即使这些控制成立，也只是相对于这些对比的分离，不是非线性网络中唯一的“纯抑制内容”。

## 3. 下一步应检测条件关系异常，而非孤立负值

可用异常检测，但“稀有”不是“错误”，常见幻觉也可能被无标签参考模型学成正常。
目标应从孤立分数改成：**在实际读取模式和当前生成条件下，来源作用是否异常不足，以及这种偏离是否维持。**
这是待验证的模型假设，不是本轮已实现或已提高 AUROC 的方法。

### 3.1 保留三类数据，不先压成一个标量

- A：当前层×头×来源块的读取分布、读取量、历史地址及覆盖率。
- B：层×头×来源块×实际候选的正负相对作用；同时保留 root 来源作用及 FFN 诊断。
  层内消息诊断与 root 分解各自使用，不能跨层当独立贡献加总。
- C：位置、可见长度、来源块数量、词形、候选概率和未观测质量等条件。
  条件熵只是观测之一，既不是来源熵，也不是真假不确定性。

保留物理头身份；来源块和候选在不同回答中是局部集合，不能对齐 block 编号或候选排名。
读取地址与根来源也不同：读到某个 history key 的 value 可能已包含 prompt 信息。
因此不直接把同下标的 attention 与 root 作用相除称为“转化效率”。

### 3.2 条件作用模型

以 source-disjoint、冻结的无标签参考集拟合 p_1(B|A,C)，另拟合背景 p_0(B|C)。
一个可比较的条件不相容量是：

\[
s_t=\log p_0(B_t\mid C_t)-\log p_1(B_t\mid A_t,C_t).
\]

它衡量读取信息加入后，对所见作用模式的解释是否变差；不是下一词 surprisal，
也不是幻觉后验。背景密度可减弱共同的稀有性影响，但不能保证消除混杂。
两侧异常还可能包括“比预期更多的支持”，必须保留偏离方向，
单独报告正向作用不足与过量，不能把所有高 s 自动判为错误。

首个实现可使用共享来源/候选条件映射、分层正则化和带收缩协方差的 Student-t 残差模型。
共享映射处理来源数量变化，物理头参数保留差异；协方差处理相关头，
不将每一维当独立观测。拟合能力由独立参考集规模决定，不用这四答估计巨大协方差，
不以 SVD 压缩或更复杂模型本身作为创新。最初先检验条件残差是否优于匹配读取量后的基线。

拟合不用自然真假标签；参考集可能含幻觉，不能称为 clean calibration。
位置有可能携带真实风险，需同时报告原始与条件校正结果，不能为了降低相关性强行移除。
不同候选集合的密度比较还须控制维度和尾部覆盖，缺失值不能补成零证据。

### 3.3 用条件状态描述引入、维持和更新

若局部条件关系得到独立验证，再引入输入驱动的切换状态模型：

\[
p(Z,B\mid A,C)=p(Z_1)\prod_{t>1}
p(Z_t\mid Z_{t-1},A_t,\Delta A_t,C_t)
\prod_t p(B_t\mid Z_t,A_t,C_t).
\]

Z 表示读取—作用关系的行为状态，不预设等于正确/幻觉。需要显式持续时间时，
可使用半马尔可夫扩展；离线前向后向推断可以利用未来 token。
比较简单条件模型后再决定是否需要这些状态，不能只凭结构完整而采用。

- reanchor 候选：新或重新集中的来源读取，加上对当前可比选择发生的作用改变。
  不要求 local→远处；只有集中注意力不够。它也可能引入干扰，不能自动降低风险。
- 首错候选：来源/候选作用关系改变和选择分歧；来源熵、选择熵、模型后验熵分开记录。
- 维持候选：偏离状态持续，期间没有观察到能改变当前相关约束作用的新来源读取。
  需要与正常连贯 span 比较；重复头模式或没有新读取本身不是错误。
- 历史影响：保持原生历史作用与统计状态转移分开。不同 token 的事实约束没有建立可比性时，
  不把之前正向来源状态自动作为当前支持；也不跨不同候选将负号相乘。

潜在 insight 是“读取—作用耦合的条件失配及其持续”，而不是“路由大就是幻觉”。
该名称只是研究问题；独立数据上击败 raw/均值、排除主要混杂后，才有资格形成方法主张。

## 4. 当前缓存能做的审计与仍缺的数据

优先使用已捕获数据，不全量重跑：

| 问题 | 要比较的结果 | 当前包是否足够 |
|---|---|---|
| 读少，还是读到后作用弱 | 匹配读取量、位置、词形后的逐头正向作用分布；未匹配样本明确缺失 | 可以开展描述审计，样本很少 |
| 为什么 12219 退化 | raw/local/lineage 的逐 token 排名变化、正负候选作用、来源与历史根文本 | 足够 |
| AP 和最高分为何分歧 | 固定 top-k 的交并集、正常高分 token、每答 PR/AUC、答案内/跨答案配对 | 足够 |
| 递推是否错误继承支持 | 候选实际 ID、直接根作用、history kernel、local/lineage 差值 | 足够审计；不能直接认定跨词事实相同 |
| 多头是否协同 | 各头差异、条件相关、独立参考下的联合模型相对独立模型收益 | 当前可描述，统计协同不等于因果交互 |
| 完整注意力路径 | 所有历史 key，而不仅 top-8 | 紧凑包不足；有 dense 原缓存才可补 |
| FFN 是否删除事实而保留表达 | 匹配语义候选、FFN 前后来源分量、相同读出或校准读出 | 当前不足，需有针对性的额外捕获 |
| 泛化效果 | 同格式独立 source 的冻结样本；标签只在全部评分完成后用 | 当前四答不足 |

首先需要独立的、相同 `value_transport` 格式的样本，而不是再次拟合四答。
旧 32 答预算图分数为 transport 0.7181/0.1912、raw 0.7116/0.1857、mean 0.7317/0.1868；
那是另一套捕获/读出，不能从旧 detached-KV 缓存补算当前完整根归因。

评价固定保留 AUROC、AP、Precision@k、答案内/跨答案、每答、位置分段、首错/续错及覆盖率。
当独立 source 数量足够后，再做 source 级配对 bootstrap；当前两答含错不支持稳定区间。
不按这四答选择符号、权重、层头或窗口；不要把标签后验挑选的组合写成无标签方法。

## 5. 评估后自动打包

`main.py transport-state` 默认评分、评估后写入相邻的 `OUTPUT_review.zip`。
已有结果无需重新评分：

```bash
git pull --ff-only origin main
python -u main.py transport-state --stage pack \
  --input outputs/native_support_ragtruth4 \
  --output outputs/native_support_ragtruth4/choice_state_v2
```

输出 `outputs/native_support_ragtruth4/choice_state_v2_review.zip`。
`--input` 也可指原 `transport-pack` ZIP；必须对应产生结果的同一设置和捕获协议。
已有同名 ZIP 不覆盖，另用 `--archive` 指定新文件。

包内包含评估、排名/状态审计、逐 token 分数、状态、来源文本与分组、协议、
标注快照、原始基线，以及所有 token 的逐头正负作用、FFN 作用、输入根候选作用。
新评分把实际使用的外部标注复制成快照；单独打包不能用另一份标注替换该快照。
旧结果没有快照时仍可指定原标注位置，manifest 明示是否存在评估快照，不能追溯保证外部旧文件未改。

完整 attention/value-energy 转为组统计和历史 top-8 地址，另保留完整历史总量与被保留量；
这不是完整注意力图。输入根候选作用仍保留全部已捕获位置。
没有捕获的语义对比、残差向量和 FFN 前后来源向量不会由打包自动恢复。
`review_manifest.json` 列出文件、缺失结果、保留字段和数据边界。

真实四答打包验证：836 个 token，875 个 ZIP 成员，约 485 MiB；
CRC 检查通过，四答评分文件与原结果逐字节相同，附件评估指标相同。
不加载模型，不重新评分，不修改现有缓存或评估。打包失败也保留已生成结果，可重试 pack。

## 6. 与成熟研究的关系

- [Interpreting Language Models with Contrastive Explanations, EMNLP 2022](https://aclanthology.org/2022.emnlp-main.14/)
  强调对比问题区分语言模型的不同决策因素。启发我们控制事实对比与表达对比；
  不提供完整语义解耦的保证。
- [Explaining How Transformers Use Context to Build Predictions, ACL 2023](https://aclanthology.org/2023.acl-long.301/)
  ALTI-Logit 将上下文贡献联系到输出，并分析 MLP 中的语法接受性信息；
  提醒我们不能把 MLP 的负向对比作用直接当事实反证。
- [Likelihood Ratios for Out-of-Distribution Detection, NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/hash/1e79596878b2320cac26dd792a6c51c9-Abstract.html)
  展示背景统计会干扰密度检测，并在其任务中使用似然比。此处条件读取—作用比是拟议迁移，
  不是该论文已验证的幻觉检测算法。
- [Information Flow Reveals When to Trust Language Models，作者实现](https://github.com/rxu0112/RAG-information-flow)
  区分来源相关性与模型使用/贡献。其管线还使用额外相关性模型等组件，
  不能把我们的 attention 或正向归因直接等同于它的外部相关性信息。

这些研究提供分解、对比和统计建模依据；本项目的条件状态假设仍需独立验证。
