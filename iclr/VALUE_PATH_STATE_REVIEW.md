# 当前值路径方法：实现、缺口与下一步

本文件区分已实现代码、用户提供的结果和待实现方案。新增的
`main.py transport-pack` 只打包现有缓存，不改变检测分数，不运行模型。

## 1. 熵到底使用什么信息

`teaching/state_audit/src/state_audit/value_path_capture.py::target_choices`
在 query=P+t-1 上使用最终 hidden state，经 lm_head 得到**完整词表**概率，计算
`H=-sum(p*log(p))`，单位为 nat。不是只对保存的几个候选计算熵。
输入包含 prompt 与此前真实回答 token；当前目标 token 不在自己的输入中。
这里是观察模型的预测不确定性；Llama-3.1 观察 Llama-2 回答时，不能把它称为
原生成模型当时的置信度。

输出熵与来源集中度是不同对象：

| 量 | 概率的对象 | 能说明什么 |
| --- | --- | --- |
| 输出熵 | 完整词表的下一个 token | 输出分布是否集中，不直接表示事实不确定性 |
| 来源注意力熵 | 某层某头的来源地址或块 | 读取是否分散；须同时报告来源总读取量 |
| 当前 source_entropy | 原始来源块的正负归因绝对量之和，经候选加权、来源内归一化 | 归因作用是否分散；不是语义熵，也不区分支持和抑制 |

关注证据既可能排除候选、降低熵，也可能削弱原有的强延续偏好，或允许多个正确措辞。
因此不能从“回看与高熵同时出现”推出“回看造成了更多错误选择”。现有缓存未提供这种
因果结论。来源条件熵还受来源块数影响，不应跨样本直接解释为语义冲突程度。

## 2. 主分数在哪里丢失信息

`experiments/native_support/transport_readout.py` 保留原始头和候选归因，但读出压缩为
history 与 source 的有符号净作用之差，再除以总作用绝对量。
候选按观察模型的替代候选 logits 加权；这些词不必对应不同事实。

- `root_route` 是当前主分数；不是幻觉概率。
- `direct_choice_route` 在层内汇总头，再平均各层，不能识别不同头的持续协作。
- `source_entropy`、`source_profile_shift` 是诊断量，未进入主分数的状态更新。
- 输出熵是独立基线。历史 joint_state 曾用它做状态分段，但没有显示优于均值对照。
- `root_route_mean` 和 `route_offline_mean` **已经实现**：当前词、前7词、后8词，边界截断。
- 跨前缀的值路径归因不等于跨 token 的检测隐状态；当前主分数没有保持、更新、修复模型。
- 候选排名不是跨 token 稳定的语义坐标，不能直接比较两个 token 的第 k 个候选方向。

用户提供的新四答结果（836 token；仅2个回答首错）：

| 方法 | all-error AUROC | AP |
| --- | ---: | ---: |
| root_route | 0.589551 | 0.131582 |
| root_route_mean | 0.753888 | 0.178251 |
| raw_route | 0.754934 | 0.199525 |
| route_offline_mean | 0.784400 | 0.193617 |

这些数值支持检查时间聚合，但不证明错误具有独有的重复机制。
正常回答同样需要稳定延续。较高 AUROC 也没有保证较高 AP。
真实缓存 max_abs_ledger_error=0.251721，应结合 margin 大小检查相对误差与符号；
不能只用 bfloat16 或小模型验证解释过去。

## 3. 中间层消息如何影响最终生成

某层某头从位置 j 向当前位置写入的向量为
`m = W_O[head] (attention[t,j] * W_V[head] x_j)`。
其针对目标 y 与候选 c 的作用，是该向量经过后续网络的值路径传递后，
在 `W_U[y]-W_U[c]` 方向上的投影。

此处的后续传递采用当前指定的 attention 固定、RMS 原生尺度固定、SwiGLU 分配规则；
不是完整原生 Jacobian，也没有识别 Q/K 改变路由的因果作用。
最终效果受写入方向、后续 attention/FFN、残差、归一化与输出矩阵共同决定。
FFN 与早期写入反向，并不等于降低正确候选的最终 margin。

中间层 attention 差异较大，只能表明读取差异较大。贡献须核对
`head_positive/head_negative` 与 `ffn_choice`，并保留候选身份。
不同层的局部贡献属于不同切面，不能跨层当作独立项直接相加。

## 4. 待实现：来源更新驱动的状态保持

目标是区分“历史继续携带已有来源约束”和“没有有效来源更新的自延续”。
高历史份额、稳定或高熵中的任何一个，都不能单独定义错误。

下一阶段观测保持层、头、来源块身份，分别保留读取量、正向作用、负向作用与来源变化。
在这些稳定坐标上建模潜在状态 Z，而不是先把它们压成每词一个风险数。
可检验的状态空间形式为：

```
Z_t = F_t Z_(t-1) + B_t E_t + process_noise
X_t = observation(Z_t) + observation_noise
```

- `F_t` 表示历史状态保持；用实际历史读取地址约束传播，不要求所有头同步。
- `E_t` 表示当前来源的新增作用；读取集中且有效来源作用改变才是更新证据。
  已有证据重读可能强化同一状态，不应被硬编码成状态重置。
- reanchor 对应来源作用重新增强或组织方式变化，无需先发生 local-to-distant 切换。
- 输出熵、来源作用分散度、正负冲突分别作为观测；熵对噪声和转移的影响需检验，
  不能预设“熵越高越错”或“熵越高观测越不可靠”。
- 离线推断允许未来观测回传；传播应受来源更新边界约束，而非固定窗口一视同仁。

这里仍需明确观测映射、转移参数的约束和估计方法；上述方程是设计规格，**尚未实现**。
未用标签拟合的状态后验不是幻觉后验，也不能自动解决事实可识别性。
若要跨 token 比较候选的语义冲突，需要额外的共同语义坐标；当前候选排名不够。

先用新打包数据审核正常与错误片段的头级持续性、来源更新及恢复，再决定状态结构。
不再在四答上自动选择超参。验证时保留相同缓存的 raw、mean、root 对照，分别报告
AUROC、AP、首错与延续；独立来源上的结果才能支持推广。审计不要求消融或全量重跑。

## 5. 采用的研究依据与边界

- [DecompX, ACL 2023](https://aclanthology.org/2023.acl-long.149/)：跨组件传播分解表示，
  支持把 FFN 与最终输出读出纳入归因；不直接证明本项目的幻觉检测效果。
- [Transformer Feed-Forward Layers Build Predictions by Promoting Concepts in Vocabulary Space,
  EMNLP 2022](https://aclanthology.org/2022.emnlp-main.3/)：FFN 更新可在词表方向上解释；
  不能把反向残差写入一律视作错误或反证据。
- [Detecting hallucinations in large language models using semantic entropy,
  Nature 2024](https://www.nature.com/articles/s41586-024-07421-0)：区分措辞与意义的不确定性。
  当前只计算 token 熵，未实现该论文的语义聚类、多回答采样方法。
