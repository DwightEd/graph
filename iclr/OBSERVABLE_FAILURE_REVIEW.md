# Observable v1：四答退步与审核记录

2026-09-24。只分析用户提供的数据，并改进结果打包；未改变评分公式、拟合标签或重跑8B。
输入为四答评价 JSON、reference_fit JSON，以及 high_risk_normals、transitions、operators
三份用户上传 CSV。评价数字来自用户运行，下面的描述统计由上传 CSV 重新计算。

## 1. 有效经验没有完整进入候选评分

| 已有经验 | v1 实际实现 | 缺口 |
|---|---|---|
| 来源—历史路由的方向性有排序信息 | raw/observable route 独立输出，默认 risk 保持 raw | conditional 的高分定义是稀有，不是来源依赖不足；两者没有等价性 |
| 时间连续性改善整体 AUROC | 均值仅作对照；前驱只修改参考权重 | 没有跨多 token 的保持状态、证据记忆或持续失配读出 |
| 物理头差异值得保留 | 全部头的联合 Gram | 保留维度不保证保留检测相关几何；也不证明因果协同 |
| 熵可能反映组织阶段 | 熵/熵差作为参考上下文 | 没有识别语义阶段；条件化不能保证消除输出分布形状差异 |
| 集中回看是待检验假设 | concentration 保存；来源块相干求和成一个角色 | 主核丢失来源块身份，集中变化没有进入状态更新规则 |
| FFN 不可按正负判断事实 | residual/FFN 响应分行保留 | 内部抵消/措辞变化仍可能占据距离；不是事实支持读出 |

“没有把先验用于评分”是设计缺口，不是数学推导证明 Fisher/VJP 错误。
原生可观测性测量与幻觉风险排序是两个问题；测量更完整不必然提高后者。

若每层 Gram 的归一化未触发数值下限，d_G=1−平均层 Gram 内积。
相邻距离接近 .9 表示归一化响应重叠很小，不能解释成真实语义每词都重置。
在当前等权距离中，相邻响应项远大于读取项；跨参考配对仍须看 neighbors 的实际距离。
带宽约 .5 不是单独的 bug 证据；分数集中也不数学地导致 AUROC 下降，因为 AUROC 只看排序。
待核查的是：参考距离是否普遍接近带宽，以及邻居排序是否能区分相关状态。

## 4. FFN 与尺度：不从符号推断真假

operators：26,752行=836 token×32层。
before/after/FFN 的能量恒等式相对误差最大2.19e−7，未见这项账本有明显计算错误。
全部240个低熵(<.01) token 的跨层 pullback_energy 中位数 .002166；
其余596个为1.736963。这是不同 token 集合的观察差异，不是控制变量后的因果效应。
熵与 pullback_energy 的 Spearman：第0层 .860310，第15层 .954331，第31层 .954733。
Fisher 度量随输出分布改变，不能把能量变化本身当作来源证据变化。

当前按响应 Gram 归一化，会去掉消息响应总体强弱；弱响应仍可获得相同比较权重。
这提示检查小尺度响应的方向稳定性，但仅凭 pullback_energy 不能证明消息响应低于噪声。
需结合保存的 response_scale/原始小样本响应才能定位，不能凭此自动设熵阈值过滤 token。

第22–31层 pullback_alignment 的汇总中位数 .930460，高于第0–10层的 .780126。
这是 before/after 导数方向的描述，不是“后层FFN支持事实”或“中间层决定真假”的证据。

## 5. 下一版应遵守的约束（尚未实现新检测器）

- 方向性来源依赖应进入候选读出，而不是只有“与其他答案不同”一个异常目标。
- 表示先能区分正常持有/展开与新信息更新，才用它建立跨 token 状态递推。
  不要求每个 token 重新读取来源，也不把稳定性本身当作正确或错误。
- 同答来源块身份保留用于回看与保持；不同回答的块编号不强行对齐。
- 总输出响应、FFN 的条件变换与总体尺度分开审计；不把内部反向量当事实反对票。
- 简单均值、raw route、局部来源缺口保留明确版本的对照；新方法须同时检查 AP、
  高分正常词、首部和延续，而非仅整体 AUROC。不要在四答上事后调权重选最高数值。
