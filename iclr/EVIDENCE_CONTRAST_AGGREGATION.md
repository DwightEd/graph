# 四条件读出的片段聚合复核

2026-09-24。基于用户上传的 `evidence_contrast_v1_review.zip`，4 个来源、4 答、
836 token、81 标错 token、3 个标注错误区间。观察者为 Llama-3.1-8B-Instruct，
回答来自 Llama-2-7b-chat，QA test。原 cohort 使用标签选取四答，是已经反复查看的探索集。
这次只复用四条件概率及原分数，没有新的大模型前向或新来源实验。

## 为什么继续改这里

预先指定的 `source_pair` 逐 token AUROC/AP 为 0.626065/0.147850，低于原始路由
0.755425/0.199692。原包中的 `source_pair_span` 达到 0.893582/0.372711，
说明需要在完全相同的片段上聚合所有方法，再区分片段间识别与片段内部定位。
不能把逐 token 候选失败写成成功，也不能遗漏已经存在的片段级信号。

新增 `transport-contrast --stage analyze`，独立写新目录，保持原观测、原公式及默认 risk。
保留完整历史、局部历史及对称平均三路；本四答不用于拟合权重、修改符号、选择新的默认方法。

## 同单位、同样本结果

对每个已保存文本单元 U，所有方法都采用 `mean(score[t] for t in U)`，
再把相同均值回填到 U 内所有 token。使用原来的标点和 token 上限分段，不按标签重分段。
以下仍然是 token 加权的 AUROC/AP，不是把41个片段当41个等权样本的指标。

| 方法 | 原逐 token AUROC / AP | 同片段均值 AUROC / AP |
|---|---:|---:|
| 完整历史来源作用 `source_full` | 0.609558 / 0.135924 | 0.823171 / 0.310212 |
| 局部历史来源作用 `source_local` | 0.622680 / 0.146458 | **0.914856 / 0.451496** |
| 对称来源作用 `source_pair` | 0.626065 / 0.147850 | 0.893582 / 0.372711 |
| 原始路由 `raw_route` | 0.755425 / 0.199692 | 0.770746 / 0.228008 |
| 可观测路由 `observable_route` | 0.753070 / 0.205930 | 0.761475 / 0.221060 |
| 原始 attention | 0.707367 / 0.160656 | 0.726040 / 0.191178 |
| 熵 | 0.580361 / 0.125598 | 0.616123 / 0.300673 |
| 原文 surprisal | 0.579356 / 0.114171 | 0.580051 / 0.140086 |

原16-token窗口的 raw/observable 均值为 0.784580/0.193649、0.797204/0.203436。
局部历史来源的同片段结果也超过这些对照。因此这批数据的收益不只是与较弱的逐词基线比较造成的。

若每个文本单元等权，以“含至少一个标错token”为阳性，共41单元、4阳性：
local AUROC/AP=0.891892/0.402083，pair=0.858108/0.312500，raw=0.770270/0.231277。
token加权与单元等权结果不同，二者均输出，不能混用分母。

## 这批数据无法检验片段内部定位

41个单元中37个全正常、4个全标错，混合单元为0。三个金标错误区间恰好是完整单元的并集。
分段算法没有读标签，但本样本的标注与文本边界高度对齐；高聚合成绩无法检验
“同一句里只有数值/实体/关系错误时，能否找出具体错词”。

`within_unit.json` 只比较同一单元内的正常/错误token对，本数据返回
`unavailable_no_mixed_units` 和空指标，而不是伪造0.5或1.0。
在确有混合单元的数据上，恒定片段均值的内部排序必为0.5；原逐词分数是否有额外定位信息则可实测。
原 token 级 AUROC/AP继续保留，但必须说明片段广播的评价性质。

## 高分正常文本与告警代价

局部来源均值的前5个单元仅1个标错；另外4个是正常标注：

- 12219 [43,58)：无法根据当前 passage 回答的说明；local=0.500576。
- 12045 [84,91)：开始讲烤牛排的标题；local=0.222935。
- 12015 [89,98)：引出答案的过渡语；local=-0.074405。
- 11907 [73,94)：说明材料未提供时薪/薪资范围；local=-0.099423。

这是具体样例的人工阅读，不是已经自动识别了事实/表达/拒答角色，更不据这些样例新增过滤规则。
低来源概率增益确实可能来自标题、过渡或保留性回答；高分不等于错误事实。

新增整单元top10%预算，41单元取ceil(4.1)=5，边界同分全部保留并报告实际数量。
local 的5单元覆盖67 token，其中15个标错，token precision=0.223881、recall=0.185185、
正常token FPR=0.068874；两个全正常回答均有告警。pair 的5单元覆盖70 token，13个标错。
这个预算按单元数量定义，不能直接与旧包top84 token预算作等预算比较。
保留整单元可以避免同分时仅按原始位置截取半个片段，制造虚假的词级定位。

允许离线未来信息，因此片段均值可合法用于离线检测。不过“回填到首词”不是当时已得到分数：
三个错误起点所在单元分别需要再读14、27、12 token才能计算完整均值。
这里记录的是最早可用时间的下界；文本边界识别的额外lookahead尚未计入。
`span_availability.csv` 分别保存回溯覆盖、起点所在单元是否告警、单元末尾和延迟，不冒称实时预警。

## 使用

已有上一轮四条件缓存时，在research环境运行：

```bash
git pull --ff-only origin main
bash experiments/native_support/run_contrast_analysis.sh
```

默认读取 `outputs/native_support_ragtruth4/evidence_contrast_v1`，写入新的
`outputs/native_support_ragtruth4/evidence_contrast_aggregation_v1` 并自动打包。
不需要 GPU、torch、transformers 或再次运行四条件采集；需要原分析依赖与 tqdm。

也可以直接读取审核ZIP：

```bash
python main.py transport-contrast --stage analyze \
  --input /path/to/evidence_contrast_v1_review.zip \
  --output outputs/evidence_contrast_aggregation_v1
```

重复同一分析加 `--resume`。当前分析要求独立输出目录；不能把原采集目录作为输出。
新目录保存原协议副本、新分析协议、无标签分数NPZ、完整文本单元表、token评价、
单元等权评价、同单元内部比较、标签对齐统计、整单元预算、延迟、比较图和审核ZIP。
`--annotations`仅替换评价真值，所有分数先保存后才读取真值。

## 实施决定与验证

当前结论是“来源条件读出在文本单元尺度存在值得复验的信号”，不是已建立泛化的词级检测器。
下一轮在具有混合标注单元的独立来源上运行相同三路与相同基线，才能检验定位能力及误报结构。
不根据这四答把local自动选为默认、不训练学生、不修改已有捕获过程。

CPU测试覆盖：统一分段均值、原分数不变、错位/重叠拒绝、混合单元定位、无混合单元缺测、
平分预算整单元保留、回溯起点与可用时间区分、ZIP完整流程、标签置换不改分数、原包不变。
实际复算了上传包中的全部836 token；本轮未运行新的8B前向或完整QA数据集。
